# 机理计算 SOP

**当前临时限制优先于下文手工路线：** 手动 TS/IRC 提交已关闭，必须通过 `ts_prepare` / `ts_resume` 提交与续跑。普通探索扫描仍可独立执行；扫描峰后的 TS 精修和 IRC 不能手动提交。流程不支持所需情况时报告工具缺口并修补，不改用 `bash` 直接执行引擎。下文引擎与初猜说明保留作为科学参考。

本流程回答四个问题：现在缺什么证据、下一次计算解决什么、什么结果才算成功、失败后是否值得继续。引擎参数分别见 `orca-inputs.md` / `gaussian-inputs.md`；方法知识见 `method-selection.md`。具体反应的坐标选择查 `reaction-class-geometry.md`，再读对应领域文件。

## 1. 先确定任务与证据标准

开始时留下简短记录：**目标量与参照物；物种/原子组成；电荷和多重度；溶剂、温度与标准态等相关条件；允许方法；已有证据；预算**。未知条件写成假设；影响任务定义的缺失信息才需要询问。不要默认所有任务都需要同一套计算。

| 请求 | 应交付的证据 |
| --- | --- |
| 探索候选路径/生成 TS 初猜 | 坐标来源、反应中心、扫描/插值结果及局限；明确尚未验证 |
| 确认一个极小点 | 无约束优化收敛、频率支持极小点、具体结构身份一致 |
| 确认一条普通基元反应路径 | 无约束一阶鞍点、反应相关虚频模式、双向路径与两侧正确极小点 |
| 电子能垒 ΔE‡ | 已验证 TS 与指定参照物的可比较电子能；不加 ZPE/热/熵校正 |
| ΔG‡、速率或选择性 | 路径证据，加统一温度、溶剂、标准态、构象处理与热化学；速率/选择性另查动力学适用条件 |
| 允许方法下不可可信回答的量 | 具体方法边界及依据；明确拒绝该定量结论，保留可成立的局部结果 |

先判断方法是否能描述所需电子态/成键变化。强多参考、态交叉等问题不能靠普通基态 TS+IRC 流程硬套。方法受限时，升级 DFT/CAS 只能是后续建议，不能擅自提交。普通闭壳层有机体系不例行增加稳定性/FOD 作业；有近简并、均裂、异常自旋等迹象再诊断。MLIP 无波函数，不要求其交付轨道分析。

### 用 AgentHub 复用知识和已有工作

**鼓励主动使用 `agent_hub search` 与文献检索**：`agent_hub` 同时检索当前项目的帖子和已接入的本地化学知识库；**科学判断需要外部依据时（标准态/准谐振协议、泛函适用性、能垒是否可信、失败模式的机理解释），再走 researcher / `literature-search` 查原始文献或综述，不要凭记忆拍数。** 规划候选机理、拿不准引擎参数、遇到新的失败而准备重试时，先查是否已有可用知识或同伴结果，再决定计算。查询围绕反应类、方法/引擎和具体问题，避免只搜“计算失败”。例如：

```json
{"action":"search","keyword":"ORCA ExtOpt 数值 Hessian","limit":5}
```

- 同时查看返回的 `posts` 和 `library`；“没有论坛帖子”不等于“知识库没有命中”。`browse` 是项目话题概览，`read` 读取指定话题，二者不代替知识库检索。

- 得到可复用的参数设置、已验证路径、错误物种或失败策略时，用 `post`、`kind="finding"` 记录：**问题/条件 → 结果与适用范围 → 作业/工具调用/文件指针 → 对下一步的影响**。已有同话题时复用话题名；影响同伴正在做的工作时填写 `to_agent` 定向通知。帖子保存在项目论坛，不能声称自动写入了全局知识库。
- 相同问题复用已读结果；出现新证据或诊断方向再检索。没有命中或知识库不可用时，继续用已有 skill、原始证据和需要时的官方资料推进，不把检索变成每次工具调用前的固定仪式。

## 2. 从结构到结论

### 2.1 建立端点与反应假设

候选机理先用 `mechanism_predict` 出假设：给反应物 SMILES（可选目标产物），FlowER ML 网络搜索返回按概率排序的基元步候选网络。**验证或证伪一条已预测的路径比凭空推导机理便宜得多**——从网络中抽出候选边当作待验证假设，逐条走 §2.2–2.5 的证据链。它是 ML 假设生成器，**输出仅供参考**：概率是束搜索分数而非校准置信度——高概率边可能错、缺席的边不代表不存在；**网络输出不是计算证据**，每条边仍须完成驻点/频率/IRC 验证，不替代端点身份核对，也不得把网络当作「可能的机理」向用户呈现。示例：`{"reactants":"C=COCC=C","products":"C=CCCC=O","max_depth":6}`。

用可靠工具生成/提取结构，**先**用 `internal_coordinates` 做结构体检与反应坐标读出（成/断键距离、关键二面角、clash、质子化态、立体化学、异常键长），再决定优化/扫描/构象策略。**不要跳过内坐标直接扫笛卡尔或盲改 XYZ**；几何微调走 Z-matrix 流程或 **`mode="transform"` 内坐标式几何编辑**——绕轴旋转基团、拉伸/压缩键、交换两个取代基分支反转手性中心、切断一根键换掉整个取代基（`replace_group`，拓扑编辑），编辑后工具自动对新几何重跑 clash/异常键角校验，原子序号为 analyze 报告的 1-based 编号。示例：

```json
{"mode":"transform","input_path":"a.xyz","output_path":"b.xyz",
 "operations":[
   {"type":"rotate","axis_atoms":[3,7],"side_of_bond":[3,7],"degrees":120},
   {"type":"stretch","atoms":[3,7],"new_length":2.10},
   {"type":"invert_chirality","center":5,"swap":[6,9]},
   {"type":"replace_group","bond":[3,7],"smiles":"[*]C(=O)O"}]}
```

`replace_group` 规则：切断 `bond` 指定的 1-based 键 a-b（不能在环上），移除 b 侧整个片段，把新基团接到 a 上；`smiles` 用**恰好一个 `[*]` 假原子**标记连接点（`[*]C(=O)O` = 羧基、`[*]c1ccccc1` = 苯基、`[*]F` = 氟），新键级取 `[*]` 键的键级；新基团 3D 几何由工具嵌入并力场优化后沿旧 a→b 键方向对接（取向确定，不做构象采样，交给后续优化）。存活原子保序、新原子追加在末尾——**replace_group 之后的操作一律用新编号**。

典型场景：把某个甲基转到反应构象（`rotate`）、预组织成/断键距离（`stretch`）、修正立体化学错误的中心（`invert_chirality`）、把底物上的取代基换成同系物/衍生物做系列对比（`replace_group`）。初始普通极小点连接正确、无明显冲突即可优化；柔性体系在影响路径/选择性时筛选 reactive conformers，并保留相对参照构象的能量代价。构象谓词能写成距离就写进 `distance_filters`；**二面角/角度约束 `distance_filters` 表达不了**——距离筛近接后必须用 `internal_coordinates` 复核，不满足就换构象，不要在错误预组织上硬扫。

对每条候选边写出成断键变化。`reaction_mapping` 的两个判断要分开读取：

- **身份**：具体 XYZ/mol/sdf 是否与声明端点相符。`mismatch` 时先核实实际连接、原子组成、电荷/立体信息；暂停把该结构当作目标物种的后续计算。错误产物可作为新候选单独保存，不能改写原目标 SMILES 来让验证变绿。若确是声明错误，记录依据后显式修订。
- **原子对应**：用于路径插值的全原子编号是否可执行。两端 identity 都 `match` 而 `binding_status=inconclusive`，可能仅是对称映射不唯一。保留身份结论；依据原子来源/标号/机理选择映射，不能反复用相同输入重跑，也不能把重原子 map 或 `internal_generated` map 用到任意显式氢 XYZ。

`ts_guess interpolate` 需要 `binding_status=complete`、`binding_source=concrete` 的 `atom_map`。传顶层、已转为坐标序号的 `watch_pairs`，不是 SMILES 序号的 `graph_watch_pairs`。映射尚未完成时，身份明确的独立极小点计算仍可继续。

### 2.2 选一个能回答问题的初猜路线

**首选 TS 状态机**：同一路径只 `ts_prepare` 一次，`input` 分为 reaction / conformers / guess / ts_optimization / verification / execution。构象来源和优化、探索扫描、正式 TS 与各项验证方法分别显式指定；缺失则停在点名字段的 checkpoint。成功作业由系统自动续接。用 `ts_inspect` 读取状态、实际方法和证据；用带 run_id/changes/reason/expected_revision 的 `ts_resume` 修订同一个 run；失败后可直接修订或重试，保留失败历史并重新执行科学验证。在途作业不允许修订。`reaction.atom_map` 是含氢全原子的 1-based 产物→反应物映射；结构编号 1-based，ORCA 原生扫描编号 0-based。元素排列通过不能消除具体结构身份或对称绑定歧义；须保留实际结构图、坐标与输入版本。扫描峰仅是候选，正式 TS 无约束精修与频率/双向 IRC/两端 Opt/Freq 仍必需。QST2/QST3 禁令及既有科学验收规则不变。

| 已知信息 | 主路线 | 检查什么 |
| --- | --- | --- |
| **默认**：端点可声明（SMILES + `atom_map`，最好加 `reaction_center`） | **`ts_prepare` 自动流程**；阻塞时按点名修订声明再 `ts_resume` | 用 ts_inspect 只读检查；按所需字段和恢复证据修订同一个 run |
| 流程接不住（声明不齐、需手工耦合坐标） | **柔性（relaxed）扫描**：固定扫描坐标，各点放松其余自由度 | `internal_coordinates` 确认原子序号 → `scan_prepare` → 提交 → `scan_parse`；检查内部峰值、连续性、每帧实际结构；**导出峰帧做无约束 TS**，不要把扫描收敛当驻点 |
| 两端结构可信且全原子对应已绑定 | IDPP 插值；需要时用支持的路径优化方法 | 插值只给几何路径，推荐帧不代表能量最高点；必须实际求能/优化 |
| 两个键变化明显耦合，1D 扫描滑谷/单调 | 先用 `internal_coordinates` 核对坐标与预组织；换坐标/构象，或有依据的耦合扫描/路径搜索 | 写出缺失自由度与预计成本；不直接堆大网格；不要在未复核二面角的构象上重扫 |

粗扫先用能覆盖相关结构的允许方法。一个扫描点通常包含多次能量/梯度评估，不能按“一点=一个单点”估价。可从十几个点定位区域，再局部加密；端点边界的最高点不能直接当作峰顶。低级别路径上的高级别单点仅重评该组几何，不能称为高级别 relaxed scan。

ORCA 的 `ts_guess scan_prepare` **当前只支持一条扫描坐标**；这不是 ORCA 原生能力的上限。需要原生多维扫描/NEB 时先核对安装版本和可用接口。

### 2.3 从初猜精修为无约束 TS

从扫描峰附近或可信路径候选提取 XYZ，建立**新作业**，清除扫描和冻结约束。用引擎对应的 TS 优化与合适 Hessian：ORCA `OptTS`，Gaussian `Opt=TS`；详细参数见引擎参考。跟踪反应中心与梯度，判断是否仍在目标鞍点区域。

验收同时检查：

1. 实际输入、方法和结构一致；没有把 constrained `Opt` 当成无约束 TS。
2. 优化真正收敛；**全自由度梯度**符合所选收敛标准。正常终止不等于优化收敛，受限方向上仍有力也不叫驻点。
3. 在最终几何、同一势能面上求频率，恰好一个反应相关虚频；检查位移模式对应成断键，不能只读虚频数。近零数值模式需要结合梯度/数值精度诊断，不随意删频率。

约束结构即使出现一个很大的 H 转移虚频，也仅是候选。`ts_guess` 初猜、扫描峰、默认 `verify` 都不能替代上述验收。频率可与优化合并；昂贵数值频率可在确认候选收敛后单独做。初始 Hessian 若不在最终几何上，不能当成最终频率证据。

### 2.4 验证连到哪两个物种

从已验收 TS 沿相关模式先做**有目的的短程双向 IRC**，保持方法/基组、外部模型、环境与电荷/多重度一致。Agent 根据需要判定的方向证据、路径拓扑和耦合、计算成本为本次任务选择范围，不设统一步数。保留原生收敛检查，记录两向真实步数、收敛标记、轨迹连续性与最外帧。将两侧最外帧在相同约定模型下分别无约束优化，求频率确认极小点，再核对具体结构身份与从 TS 出发的方向。

**步数上限或 IRC 自身未收敛不自动触发延长。** 若两侧最外帧经优化后已经证明正确的极小点身份与方向，就保留短程路径证据；若 partial 几何仍不能判定方向或端点身份，才有针对性地延长未决的一侧。不能把达到步数上限称为收敛，也不能把短 IRC 单独称作完整路径或动力学证明；如实标注 partial 范围。原生参数与轨迹文件见 [ORCA IRC](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/irc.html)。

`ts_guess mode=verify, strict=True` 检查双向外帧与两侧 optimized endpoint 的方向关系；`pass` 不是整条机理的真值判定。端点提取**支持 Gaussian IRC 日志与 ORCA 原生端点/轨迹**（`*_IRC_F.xyz` / `*_IRC_B.xyz`，缺失时回退 `*_IRC_F_trj.xyz` / `*_IRC_B_trj.xyz` 末帧；见 `orca-inputs.md`）。ORCA 仍须保留主日志与轨迹文件作原始证据。解析失败应报告工具限制或补交缺失文件，不能重跑相同计算“直到通过”，也不能伪造 strict pass。

当前 `log_parser` 的 IRC 字段（点数/收敛/端点能量）只是信息字段；`short_irc` 阶段绑定的 harness 闸门是**几何方向区间证明**（与 `ts_guess verify strict` 同口径：双侧 IRC 端点几何各自位于 TS 与对应验证极小值之间），不看收敛标志或点数。材料取自同边 ts_opt/frequency 与 endpoint_a/b（或物种 geometry）阶段已绑证据的日志，缺材料会被拒并写明缺什么——先补端点优化证据再绑。不得为凑点数或 IRC 原生收敛标志重跑；方向或端点身份未决才延长。若工具/复核仍拒绝，检查其具体理由，提供原始结构与收敛记录；所需阶段未完成时保留交付缺口。

### 2.5 计算所需的能量差

先核对参照是哪个物种/络合物、计量关系与电荷/自旋，所有能量必须来自可比较的设置。每个数附几何、作业、日志及方法来源。

- ΔE‡ = E(TS) − E(指定参照)。现有同级别电子能足够时直接使用；明确是否包含 ZPE，纯电子能不包含。
- ΔG‡ **必须**按 `method-selection.md` §4.1 执行：统一温度、**1 M 标准态**（双分子 `Δn=−1` 时加 `RT ln(24.46)`）、准谐振（默认 100 cm⁻¹ cutoff）与构象 Boltzmann；高级别单点配低级别热校正时记录组合公式，避免把总 G 当作 correction 再加一次。`thermo_analysis` 的 `raw_rrho` 与 ORCA 原生字段**禁止静默混用**；不能跨引擎拼一个 ΔG 剖面。
- 昂贵的最终单点留到路径可信后；用于诊断的少量低成本单点可以提前做。新增单点不修复错误结构/路径。
- 竞争构象/路径用同一参照比较，保留反应构象代价。不能仅从图上“最高 TS”宣布催化循环的决速步，需考虑占据态、浓度、可逆性及动力学。交付选择性时写明标准态与方法不确定度（|ΔΔG‡| ≲ 2 kcal/mol 须标注方法噪声）。

## 3. 证据交付与 DAG

科学上独立的工作可并行，证据按真实依赖复用；避免重复计算。

系统仅有 **delivery DAG**（机理图），不存在 process DAG。节点为络合物体系物种（`species`），边为候选基元步（`steps`）；模型无需填写内部 ID、角色（reactant/intermediate/product）或阶段契约数组。证据通过工作区落盘日志文件提交（`dag_submit_step_evidence`、`dag_submit_species_evidence`），由 harness 负责快照固定与虚频合法性复验（TS 需唯一虚频，物种基态需零虚频）。

| 模式 | 当前行为 |
| --- | --- |
| `standard` | 同样的科学标准；不调用 DAG/Supervisor |
| `dag_record` | Coordinator 提交草稿，自动接受；直接通过文件送审记录确定性证据 |
| `dag_guided` | Supervisor 接受草稿后解锁计算，逐项定向复核送审证据（`dag_review_step` / `dag_review_species`） |

具体 API 读 `dag-operations`，以当前 schema 为准。`submit_compute_job` 只是提交记录，不是完成证据。失败计算/虚频异常应如实记录；必须是完工解析且符合物理自检的计算结果才支持。

`supported` 表示该物种或基元步获得充分证据支持；`rejected` 仍是缺口；`skipped` 是明确放弃；`not_applicable` 是该步骤对当前体系不适用，后两者必须附带科学理由。没有找到 TS 不等于证明无 TS，不能据此擅自填写 `not_applicable`。

### Claisen 示例：`C=COCC=C` → `C=CCCC=O`

以命名络合物体系作为物种，椅式/船式路径是不同候选基元步。先根据成断键选反应映射，再定位真实构象。筛选反应构象后，扫描/插值只支持 ts_guess，不能代替收敛过渡态。无约束 TS 的收敛与频率计算（单虚频且振动矢量合理）支撑过渡态转化；短程双向 IRC 与两侧极小点（optimized endpoint）、方向与身份确认提供 endpoint-supported 级连通证据，不单独证明完整路径或动力学，并将证据文件指针妥善保存。未计算的竞争分支保留理由。

用 `dag_delivery_report` 检查交付缺口。coverage complete 表示所有必需元素已充分支撑或妥善处置；skipped 不得描述成科学验证通过。预算/方法限制下可以明确 `partial`，不需要为了 complete 无限盲目重试。后台仍运行时 stop 是等待；真正结束前处理已有后台工作，避免把暂时休眠写成最终交付。

## 4. 失败后怎么决定

每次重试前写一句：**观测 → 假设原因 → 改什么 → 哪个结果会证伪该假设**。新故障优先通过 AgentHub 检索本地知识和同伴经验；已查过的相同问题复用结果。没有新诊断、新结构或新路径时，不增加同类作业。

| 现象 | 有信息增益的动作 | 不应做的事 |
| --- | --- | --- |
| 输入/程序错误 | 查生成文件、安装版本、外部程序参数；修正后复用可用产物 | 随机换科学方法来试语法 |
| 连续 TS 优化早早落入同一极小点 | 回看滑谷前几何；有依据地换构象/反应坐标/初猜，预算不足则结束该搜索 | 只把 MaxIter 从 200 加到 300 再重跑 |
| 扫描单调或边界最高 | 先 `internal_coordinates` 核对扫描原子序号/键角/预组织；再查范围与端点；有明确假设才补扫 | 宣称所有路径无垒；把 xTB 几何上的 MACE 单点称为 MACE 扫描；在未复核二面角的构象上原样重扫 |
| 扫描突跳 | 检查前后连接/构象；局部加密或改路径 | 自动取最后/最高帧便宣布 TS |
| 2+ 虚频、错误模式、大梯度 | 查未收敛自由度、模式/构象与数值噪声；针对性重精修 | 只追求 n_imag=1 或降低验收标准 |
| 正确的完整 IRC，验证器却不支持 | 保留原生证据，说明能力缺口并请求针对性复核 | 凑点数、改日志、重新跑相同计算 |
| 强多参考/模型域外导致目标量不可信 | 明确方法边界；在用户当前要求和预算内选择适用方法，Benchmark 还需遵循当前题目 MethodPolicy | 把“单参考算完了”当成可靠，或忽略用户要求及当前 Benchmark 限制 |

默认在一个策略出现重复的同类失败时停下来诊断；这不是固定“两次失败就证明不可算”。能够提出新的可检验路径且预算能覆盖必要验证时再继续。**计算未找到、方法不适用、证据已反驳**是不同结论。

结束/交接用短表：`对象与声明 | 已成立证据/指针 | 未决或反证 | 方法/预算限制 | 下一项有价值的验证`。例如：“在允许的 MACE/xTB 和本轮预算内未定位已验证 TS；两次优化落入产物谷，所采样单坐标剖面单调。这不足以证明无垒，当前不报告活化能垒。保留初猜、轨迹与端点结果，交付为 partial。”

## 5. 方法一致性

优化、频率、IRC 描述同一势能面；提高最终单点级别须显式记录。溶剂化、弥散基组、自旋诊断与热化学细节见 `method-selection.md`，不要把 Gaussian 关键字搬到 ORCA，也不要在 MLIP 上增加并不存在的 SCF/积分网格配置。
