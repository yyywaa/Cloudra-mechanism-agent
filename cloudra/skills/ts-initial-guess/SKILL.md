## 0. 何时需要本 skill（触发条件）

1. 从**收敛极小值**出发，要在某一坐标（本项目 = rc1 = D(28,13,6,9)，二面角转动）上找 TS / 转动鞍点，需要给 OptTS 挑一个**种子几何**；
2. 作业能正常跑完，但**首步 Hessian 全正 / 种子一步大位移下滑 / 结果落回极小**（"看起来像 TS 却不收敛"）；
3. 作业秒级失败：`Unrecognized atomic symbol` / `End of file in ZSymb.` / `fd = -1` / l101 硬失败 / `Normal termination` 但没有频率；
4. 需要判断"这个驻点到底算不算已验证 TS"、需要写势垒数字或计数（frequency-verified / fully verified）；
5. 需要把一批约束扫描点连成剖面、判断是否同谷 / 是否跨家族（basin）。

**一句话原则：种子只能取自"计算派生的连续结构"的峰帧；约束剖面的极大/脊点/链点/插值帧都不是势垒，峰帧也只是种子。**

**合法种子 = 计算派生的连续结构的峰帧。** 等价说法：它必须是"逐点续接派生的松弛扫描"所得到的计算剖面峰帧；对 2D 情形为面上最高帧。

## 3. 首步四判据与熔断纪律（SOP 核心）

种子一旦提交 OptTS，必须在**首个 `Step number` 出现的那一步**按下列四条判决；**任一不满足 ⇒ 立即熔断（停作业）+ 回到扫描取种，不得手工补帧**。

| 判据 | 合格 | 不合格（本项目实测反例） |
| --- | --- | --- |
| ① 负本征值个数 | **恰 1**（`Eigenvalues ---` 表中负值计数 = 1） | 793 / 803 / 813 / 764 = **0 个**；≥2 则非 index-1，也应换候选 |
| ② mode 1 成分 | **含目标反应坐标**（对 rc1：D15 的位移/二面角响应最大） | 803 = 甲基/甲氧基主导（D27 0.57619、D26 0.57579、D28 0.55142，D15 仅 0.03850）；793 = 甲基主导 |
| ③ |Δq| / 步 | **≤ 5°**（本项目自定阈值） | 803 = +17.07°；793 = +20.28°；813 = −13.18°；764 = −12.58° |
| ④ Predicted ΔE | **非强下坡** | 803 = −8.49；793 = −5.698；813 = −2.77；764 = −2.66 kcal/mol |

- 合格对照（**job 800**，ts/ts_0005 反向通道，种子 = 计算派生的 m125 收敛帧）：种子处解析 Hessian **恰 1 个负本征值**（`Eigenvalues --- -0.01184 0.00188 0.00319 …`）；mode 1 由 rc1 主导（D15 −0.40699，D24–D28 无一进入前 10）；步 1 Δrc1 = **−1.7423°**、Predicted ΔE = **+0.0529 kcal/mol（上坡）** ⇒ 两道熔断判据均不成立。后续步 3 张 Berny 表 Hessian 各恰 1 个负本征值（−0.01184 → −0.01264 → −0.01200，147 DOF），|Δrc1| ≤ 1.74°。
- **「Predicted ΔE 转负并持续下降」与「Max Force 回升」同时出现**才停；单一指标波动不停。
- 换种纪律：**熔断即停 + 只走 `ts_resume(guess=provided)`，不建第三条 run**；熔断判据是"停"而不是"改参数硬跑"。

### 3.1 "D 编号映射"的坑（必做反查）
- Gaussian 日志里的 **D 编号是它自己内坐标表的顺序**，与本项目自建索引**不一致**：本项目的 rc1 = D(28,13,6,9) 在日志中打印为 **D15**（例：`! D15 D(9,6,13,28) 45.0002`；注意原子序还可能反向排列）。
- **检查步骤（每次都做）**：在 `refine.log` 里定位种子几何回显的 `! D<n> D(i,j,k,l) <值>` 行，用"四个原子号"匹配到自己的坐标，再确认后续 Berny 表里该 `<n>` 的 Old X / New X / Delta X（弧度）与目标值一致；**不得**假设 D15 就是 rc1、D41 就是 ester。
- 实操换算：本项目 D15 的 Old/New X 以弧度给出，例如 813 的 `Old X 0.78539 rad (=45.00°) → New X 0.55534 rad (=31.82°)`、`Delta X (Total) = −0.23005 rad = −13.18°`。

## 4. 合法取种配方（连续扫描 / 续接派生）

1. **续接派生（绝热跟随）**：第 i 点的起始几何 = **第 i−1 点的收敛末帧**；**禁止跳点重建**。每点只冻结目标坐标（本项目：无值 `D 28 13 6 9 F`），其余自由度全弛豫。
2. **1D 峰帧**：在窗口内取该 1D 剖面的**峰帧**（相邻点之间单调性反转处，必要时 2.5° 加密）。
3. **升级 2D**：峰落在窗口边界、或剖面**平坦/单调**（无内点峰）⇒ 升 2D，取**面上最高帧**。本项目实例：窗口 +36…+50 内 A_fwd 支（+40 +22.568 / +45 +20.422 / +50 +18.471 / +55 +16.739，单调下降）与 B_fwd 支（+35 19.046 / +40 20.501 / +42.5 21.2746 / +45 22.073 / +47.5 22.889，单调上升）**两支均无内点峰** ⇒ 直接声明 rc1×rc2 二维续接扫描（窗口 rc1 +41…+44 × rc2 −50…−80，步长 0.5–1° × 5–10°，6–8 点）。
4. 扫描点族/脊点解析：**阶梯（ladder）类件也属合法**——每一级都取自上一级收敛帧（续接），沿 rc2 的单点极大帧即该续接剖面的计算峰（本项目 x42p8 stage1 +21.5646 → stage2 +22.2169 单调上升，故尚未出现 `_ridge_max`）。
5. 每点报告字段照 §1 的清单；**引用活文件时必须注明测量时刻**（例：`progress.md` 的段头时间戳）。

### 4.1 平台 `guess.kind=scan` 路径与效力边界
- **优先路径**：durable 管线声明式取种 `guess.kind=scan`（scan 的扫描定义走**结构化字段**：`scans[].coord_type/atoms/scan_start/scan_end/scan_steps` + `freeze[]`，二维用 `mode`；`calculation.keywords` 只放附加选项（泛函/色散/积分格/SCF））⇒ 正向扫描**不需要**重演 IRC "参数只能写在任务关键字里"的两难。
- **效力边界**：声明中**不得重复任务关键字**（见 §5.4）；**峰帧只是种子**，仍须过 §3 四判据；全程走 `ts_prepare/ts_resume`，**禁手工造帧/手工提交**；`scan` 家族尚未实测 ⇒ 按同一纪律（提交前数任务记号）执行。

## 5. 输入 / 语法坑（每条给逐字报错 + 从日志验证的判据）

### 5.1 ModRedundant：`D i j k l <数值> F` 不冻结
- 现象（本项目 17+ 例）：写 `D 28 13 6 9 5.0 F` 时日志**回显动作字母为 B**、内坐标表给 `estimate`、几何在优化中**自由漂移**；只有**不带数值**的 `D 28 13 6 9 F` 才冻结（**回显 F + 内坐标表该行 `Frozen` + 逐帧恒定在输入几何的当前值**）。
- 验证判据：① 回显动作字段全为 `F`；② 初始坐标清单（`Frozen` 清单）中该行标 `Frozen`；③ 优化多步后该内坐标恒定（本项目实测漂移 ≤0.0005°，阈值 ±0.02°）。对照件：`runs/pm7_route_test/p_11_05_C1`（生效）vs `runs/rc1_ts_work/grid2`（未生效）。
- 受影响件处置（不重投）：`grid2 767–770`、`rc1free 771/772/774`、`ridge2 776–780` 等一律改标「free relaxation from prebuilt (rc1, rc2)」，**不得**作冻结点/包络输入。
- **种子必须预先造到目标值上才能锁值**（无值 F 冻结的是"输入几何的当前值"）；`S n step` 扫描行不受此影响。

### 5.2 坐标块空行（一空行规则 + 无约束区仍需末尾空行）
- 坐标块与 ModRedundant 约束行之间**恰 1 个空行**；缺 ⇒ 逐字：`Unrecognized atomic symbol:  D` → `Symbol not recognized in MSubst.` → `Error termination via Lnk1e in …/l101.exe`（1.3–1.5 s，零机时）。
- **无约束区的作业，坐标块末尾仍需一个空行**：job 818（端点 M1 首次尝试）逐字 `End of file in ZSymb.` + `Error termination via Lnk1e in …/l101.exe`（calculator 退出码 1，零机时）。
- 验证判据（检查步骤）：提交前 `cat -A`（或等价）确认末行是 `$`（空行）；失败后先 `grep -n "ZSymb\|Unrecognized atomic symbol\|l101.exe" <log>` 定位，再改输入——**这是零机时的输入格式失败，不是科学限制**，修好后用**新目录/新名**重投（818 → 819/822），旧件保留审计。

### 5.3 `%chk` 必须是作业目录内的绝对路径
- 相对路径 ⇒ 逐字 `fname=…/xxx.chk` / `fd = -1` / `open-new-file: No such file or directory` / `Error: segmentation violation`（死在 l1，未进 SCF；计算进程 cwd 不是作业目录）。对照：深绝对路径（137 字符）正常运行 ⇒ **深度无妨，必须绝对**。
- 不写 `%chk` ⇒ 检查点落到共享 scratch（本项目 `GAUSS_SCRDIR=/home/ly/g16/scratch` 被 g16 包装器无条件导出），崩溃后难以定位、且独占 scratch 隔离失效。
- 验证判据：日志第 ~81–87 行可见 `fname=`/`fd = -1`；或提交前直接读生成件第 1–3 行的 `%chk`，确认是绝对路径且目录存在。

### 5.4 任务关键字不得重复（框架会注入）
- 现象矩阵（Gaussian 16 RevC.01，探针件 `run_records/engine_probe_segfault_2026-10-06/`）：**重复裸 `freq` = 静默不执行**（`Normal termination` 但 `Harmonic frequencies` = 0、NT=1 却零频率、archive=SP）；**重复 `opt`/`irc` = 首帧 SCF 后 ~1 s 在 l101 硬失败**（逐字 `Wanted an integer as input`，与记号顺序无关：参数在前/在后均失败）。
- 必败件实例：`ts/ts_0005/jobs/declaration_0002/irc/irc.gjf`（sha `49f6e71460e61e637e115c184ac3a19cbf7a2ba17894a887eae372c57d34325e`）route 中 `irc` 令牌计数 = **2**（`#p irc=calcfc … irc=(calcfc,maxpoints=40,stepsize=10)`），因**从未提交**而未消耗机时，已被 `declaration_0003/irc/irc.gjf`（sha `9aa982d6ef93eb4fffe46f1f2f237dd195b04919e86022d2c6e58eb0641dbf3e`，`irc` 计数 = 1）取代。
- 声明侧写法：**只写方法层关键字**（本项目 `empiricaldispersion=gd3bj int=ultrafine scf=(tight,novaracc)`），任务关键字由框架注入。
- 提交前自检（硬门）：读**生成件 route 行**、数**本阶段任务记号**——**2 ⇒ 别投**（先修声明）；**1 ⇒ 正常**；**0 ⇒ 会被方法检查拒**（逐字 `the task keyword is stripped when read from the generated input`）。
- 假失败 vs 真失败：修改 `verification.irc` 声明时出现 `compute_admission_rejected`（提交前方法合同校验，expected 含 `irc` 令牌、actual 不含）= **假失败**（未消耗机时）。本项目曾把它误判为"平台检查器缺陷"，实测真因是声明侧冗余重复任务关键字（报告 §9 A14 自纠）。
- **验收只看任务自身输出段**：频率件须 `Harmonic frequencies` ≥ 1 **且** link 含 `l703`；IRC 件须 `IRC-IRC` > 0 **且**出现 `l1101`/`l123`。**`Normal termination` ≠ 任务真的执行了**。

### 5.5 IRC 参数形态（探针结论，检查步骤）

## 6. 判活与失败分账

1. **长静默 ≠ 卡死**：l703（积分二阶导）、l1002（CPHF）、l1110（初猜 Hessian）阶段**在内存中计算、很少写盘**。判活看 `ps` 的 CPU 累计（本项目实测 l703 25008 s / 379% CPU、l1110 380%）与 chk/rwf 的 mtime，**不据日志停顿判异常**（实例：807 频率件日志静默 ~18–90 min，最终正常出结果）。
2. **`--timeout 1800` 不是作业级看门狗**（检查步骤）：monitor.py 的 `parse_timeout` 只限制"计算进程退出后的日志解析窗口"；作业时长与日志静默无关。
3. **SIGTERM 后的孤儿 link 进程**：kill 包装进程（PGID）⇒ 作业 state=failed / 退出码 −15；必须再按**父 chk 路径**核对 `l502/l703/l1110` 等孤儿并 kill -9（**勿按目录名判断**），复查残留 = 0。
4. **退出码 −9（SIGKILL）属资源事件**（实例 job 744：运行 48 m 47 s、终止于二阶导 SCF、`Harmonic frequencies` = 0、无 termination 行）⇒ **不得当化学失败**；处置 = 提高该阶段 memory_mb（如 12288）+ 降低并发重试，验收仍按 Harmonic frequencies 段。
5. **环境事件（与科学失败分账）判据**：① 有**内核证据**（`__vm_enough_memory` / signal 11，且申请量为**不可能的巨值**）；**且** ② **位置可复现性不成立**。本项目实例：job 819（%mem 2 GB）逐字 `__vm_enough_memory: pid: 27477, comm: l502.exe, bytes: 117228853346304 not enough memory for the allocation` → `l502.exe[27477]: segfault … error 4` → WSL CaptureCrash **signal 11**（同窗另有 2 次 `l502` signal 6）；而**同几何、同 %mem 的 job 820 在崩溃的同一位置继续存活** ⇒ 属**间歇性分配失败**，不是"某几何必崩"。处置序 = **先降并发、其次加内存余量**；再现则留 4 核再重投、**新目录/新名**，化学层不动（v2 目录保留审计）。
6. **终止快照 / 过程值一律不得引用**（本题实测教训：p050_M1 = M0 +105.09 是拉伸氢键后的病态 SCF 快照；m125b 的 +23.117 是步中值；801 的 +22.366 是步 3 过程值）⇒ 只引用 `status = done` + `optcomp = 1` 的收敛值。
7. 所有旧件（失败/终止/必败输入）**保留不删**，用作审计与回归；"删除"报告须 `ls` 直接核实（见 §8.3）。

### 7.3 端点身份三条件 vs 链邻点判据（不得混用）

## 8. 家族 / basin 追踪与指纹口径

### 8.1 同谷规则（适用于相邻约束链点）
- 相邻约束链点必须 **|Δrc2| < 5° 且指纹无跳变**才可连成同一条剖面，否则按 sheet/家族分列。
- **不适用于「鞍点→约束谷」那一步**：TS 是鞍点，其 rc2 并非该 rc1 处约束谷的 rc2；TS→A1（rc1 −131.27）的 rc2 由 −104.25 弛豫到 −97.06，属「**鞍点→约束谷的谷形畸变**」，**不是 basin 断点**。
- 阈值处置：相邻 rc1 点的 |Δrc2| ≥ 5° **或**指纹跳变 ⇒ 标「**断点候选**」：不得直接串成单条同谷剖面，也不得直接宣告换盆，须由 **2.5° 级加密点**或**端点身份**定论。**按用途分开**：(i) 并入剖面/包络须 |Δrc2| < 5° 且无指纹跳变；(ii) 连通性下降链只要求「每点收敛驻点 + 相邻能量不回升 + 任何谷/指纹变化如实披露」，**链不主张单谷**。
- 本项目实例（反向链）：B1（rc1 −121.2708，Δrc2 +0.62°、Δester −3.87°）仍在 TS 同谷；A1（rc1 −131.2713，Δrc2 +7.18°、Δester +5.49°）已进入另一家族 ⇒ 汇总写「**TS 同谷只覆盖 B 侧**；A 侧单列」，且 TS 两侧 ±5° 的能量下降（M0 侧 −0.849、M1 侧 −0.405 kcal/mol）**只作形状描述**，不得据以反推导数/垒宽。

### 8.2 家族命名与判族依据
- 命名（去歧后口径）：正向 **A_fwd = M0 片（P 型：ester ≈ −152±5、ring5 ≈ −37.6±0.5、naph ≈ +132.5）**、**B_fwd = M1 片（Q 型：ester ≈ +170…+173、ring5 ≈ +18…+21.6、naph ≈ +100…+105）**；反向脊（rc1 < 0）用 **Σ− 支（m130/m135/m140/A1）**，不再用「家族 B 通道」；连通性链用**方向名**（链→M0 / 链→M1）。
- **判族以 ester/ring5/naph 指纹 + 能量为准，不得只看 Kabsch**（A_fwd 片 nearest/second-nearest ratio 仅 1.03–1.10）。
- 更细的构象 sheet：S（M0/M1，ester ≈ +165…+170、d57 ≈ 1.77）、P（ester ≈ −152…−160）、Q（ester ≈ +171…+175、d57 ≈ 2.7–2.8）、R（d57 ≈ 3.0–3.33，氢键打开）——**把约束点按单坐标拼曲线时至少 4 个 sheet 交织，每条链内部无突变、突变只发生在 sheet 之间**，故单坐标全周曲线不能当单一势垒曲线读。
- 构造限制（实测）：五元环 D(7,20,13,28) 是**环内二面角**，切断 13–20 后两原子仍由环的另一路径相连 ⇒ **刚性片段旋转改不动它**（12 轮定点迭代后残差恒 −7.1212°）；因此阶梯只锁 4 行（rc1 / rc2 / ester / naph），**ring5 自由弛豫**（锁死它会使 Q 端不可达）。⇒ **任何刚旋构造必须回测所有声称达标的内坐标**。

### 8.3 指纹二面角口径（统一，避免镜像函数）
- 所有二面角指纹（rc1/rc2/ester/ring5/naph）一律用**同一口径**（本项目：ASE / `compare_dft_minima.signed` / `build_ladder.dih`，与 Gaussian 打印的 D 编号、RDKit 三方一致）。
- **禁止引用** `runs/phaseD_M0M3_scan/scripts/geom_metrics.py` 的 `dihedral()`：它返回**镜像值 180°−φ**，会造成指纹错判（d57/d319 是距离，不受影响）。
- 旁证（检查步骤）：`runs/rc1_ts_work/interp/ridge_M0parent_42p8_m62p5.xyz` 实测 rc1 +42.8000 / rc2 −62.5000，与文件名一致。

## 附录 C（v1.1 增补，2026-10-10）：canonical 帧口径 + 两条追加至 §11 的 checklist

（本附录为 v1.1 增量；原 §1–§11 与附录 A/B 内容不变。）

### C.1 打印内坐标表的末列 ≠ 收敛帧几何（实测，本项目 825 = R− slice）
- 实测：格点 1 打印表末列 ester = **172.2156°**，终态 Cartesian 重算 = **172.2284°**（差 **0.0128°**）；格点 2 打印 171.9899° vs 重算 171.9919°（差 **0.0020°**）。0.0128° 已足以制造「伪族跳变」级误判。
- 结论：**canonical 帧与指纹一律取「终态 Cartesian 重算 + 导出 xyz + sha256」**（本项目实现 = 几何 lane 的 `block_row.py`，其 dih/dist 与 `chain_row.py` 逐字相同）；打印表 rad→deg 只作 **≤0.02° 级交叉核验**，超出即须追查，不得任选其一。

### C.2 判族/盆地必须给出耦合量（可为 0.000°）
- 当扫描坐标与某指纹二面角**共享原子**时，族/盆地判定用**弛豫口径**（本点收敛帧 − 本点自身传递帧），并**并列**报告 **RAW**（原始差 = 本点收敛帧 − 上一收敛帧）/ **耦合**（本点传递帧 − 上一收敛帧）/ **RELAX**（弛豫）。
- 参照例两端：① **零耦合端** —— rc1fix 的 7 条续接链的耦合恒 **0.000°**（接力种子绕 C13–C6 轴刚旋，该轴穿过原子 13，而 ester / ring5 / naph / rc2 的四原子中除 13 外全部落在静止侧）⇒ RAW ≡ RELAX，此时只报 RAW 即合规；② **高耦合端** —— 825 的 naph **耦合占比 89%**（RAW −3.4165° = 耦合 −3.0551° + RELAX −0.3614°）⇒ 三项必须并列，否则会把扫描增量误判为盆地跳变。

### C.3 追加至 §11 checklist 的两条（v1.1 起生效）
- [ ] 报任何收敛点 / 峰帧的指纹前，确认来源 = **终态 Cartesian 重算**（附 xyz + sha256），并给出与打印表的差异（应 ≤0.02°）。
- [ ] 报族 / 盆地判定时，**给出耦合量本身（可为 0.000°）**；耦合 ≠ 0 时必须 RAW / 耦合 / RELAX 三项并列。
