## 声明与局限

1. **本文件只作 ts_prepare 的 E2 TS 初猜几何**。IDPP 插值**不产生任何能量**；其键长/角度**不作能垒、ΔE‡ 或机理论证**证据。E2 的 ΔE‡ 必须来自 OptTS（恰 1 虚频，且虚频模以 C4–O3/C4–O5 为主）+ 双向 IRC（一端 I1、一端 I2）+ 两端点 Opt/Freq（0 虚频 + 身份核验）。
2. IDPP 是距离插值，不含能量：真实 E2 鞍点可能在 2.0–2.8 Å 之间的任何位置（本步在势面上是强吸热，I2 比 I1 高约 +11.8 kcal/mol（同批 DFT 纯电子能），TS 偏晚型）。若 OptTS 失败，建议依次试 frame 1/2/4 或改用 `xtb_scan_e2`（GFN2-xTB/ALPB water 沿 d(C4–O3) 1.55→3.90 Å 的弛豫扫描，job 1001）的峰帧。
3. **本初猜是 i1 序**（= 反应物/I1 序，与 prep/i1.xyz 同序）：若下游 run 采用 i2 序，请用上面给出的置换 [1,2,3,7,8,9,4,6,5,10,11]。这一点已单独标注，避免反应中心原子被错认（Na⁺ 体系 reaction_mapping 自动映射有已知问题 issue #179 P6）。
