## 3 TS guess 的构造（可复现脚本 `build/build_final.py`，sha256 `3d816106dcc2ae5473d104582aee1af25d7de79bc1a990294ec9aee3d734fed1`）

文件：`build/ts_guess_27.xyz` sha256 `0c8e46878665441cfe539115b884f25c95fadcdcd02a705e841633381f28d3cb`（27 原子，工作序同上；坐标由脚本从 `INT1_27_opt_frame.xyz` 几何变换生成，无手抄坐标）。

插值参数（以起点帧为基准，沿反应坐标把四个内部量推到鞍点型取值；其余原子刚性随动）：
- `r(C2-O4)` 1.4208 → **2.200 Å**
- `r(C2-C3)` 1.5351 → **1.440 Å**
- `ang(C3-C2-O4)` 108.87° → **90.00°**（C2 走向 sp2 时该角张开/侧倾）
- H22 放在 C3···O4 连线的**远侧分支**：解 |C3-H22|=1.355、|O4-H22|=1.351 的两球交线，取离 C2 更远的那一支（避免 H22 贴着 C2 走）
- O4 与 H21 作为刚性单元一起平移；C3 的另两个 H（8,9）随 C3 刚性平移

自查（化学可容许性 / minsep）：
- 全结构非键接触最短 = **1.769 Å**（25H-26H，即环 CH2 上相邻 H，属正常 1-4 H···H）；**没有任何 H 落在任一重原子 0.5 Å 以内**（要求线 0.5 Å，实测最紧的非键 H···重原子 ≥1.77 Å）。
- `ang(C3-H22···O4)=152.8°`（质子转移的接近角合理），`dih(O4,C2,C3,H22)=-5.4°`（近 syn-periplanar；起点帧为 +68.47°，即 guess 里 C3H3 已转到 syn 构象，这是低能垒甲基转子，不是独立物种）。
- **需要记录的模型事实**：由 C3-O4-C2 三角形，C2 距 C3···O4 直线的垂距只有 ~0.86 Å（起点）到 ~1.2 Å（本 guess），所以「O4 直接夺取 alpha-H」的四中心协同构造中 H22 必然离 C2 很近 —— 本 guess 的 **r(C2···H22)=1.595 Å**（1-3 关系，不计入 minsep 撞原子判定）。这是一条真实张力信息：若该鞍点存在，它是高张力四中心；若 freq 显示不是这条路，则应改判「协同四中心不可行」，考虑分步（C2-O4 先断 → 亚铵/烯胺）或羧基穿梭路线。**本步不预设哪一种是答案。**
