# NR1 · 文献参考数据（Nguyen et al., JPCA 2011, 115, 841–851）

> **用途限定**：本文件只作**物种身份核验**与**路径拓扑**参考。
> 文献数值是 **CCSD(T)/CBS**，本项目用 **B3LYP-D3(BJ)/def2-SVP**，
> **数值不得直接回填 gold**，只可用于：
> ① 判断我们算出的驻点是否是对应的同一个物种/构象（比转动常数、比频率模式）；
> ② 确认路径上有几步、哪几步是构象转换。
>
> 源文件：`jp109143j_si_001.pdf`（14 页）｜全文：`SI_fulltext.txt`

## 一、目标路径 k5：Formamide → HCN + H2O（本题 NR1）

文献能量（CCSD(T)/CBS，kcal/mol，相对甲酰胺 = 0.0）：

```
Formamide (0.0)
  → tsH-1,3      (43.9)   ← 质子转移 N→O（成键变化）
  → INT-1a       (11.0)
  → tsR-1a1b     (34.0)   ← 构象转换（无断键）
  → INT-1b       (14.3)
  → tsR-1b1c     (19.7)   ← 构象转换（无断键）
  → INT-1c       (14.5)
  → INT-1c-tsH2O (73.6)   ← 脱水（成键变化）
  → H2O + HCN    (16.9)
```

### 逐步能垒（相对**本步起点**，文献值，仅对照）

| 步 | TS | 起点 | TS 相对起点 |
|---|---|---|---|
| 1 | tsH-1,3 | Formamide (0.0) | **43.9** |
| 2 | tsR-1a1b | INT-1a (11.0) | **23.0** |
| 3 | tsR-1b1c | INT-1b (14.3) | **5.4** |
| 4 | INT-1c-tsH2O | INT-1c (14.5) | **59.1** |

### 步性质（决定 `bond_changes` 怎么写）

| 步 | 性质 | bond_changes |
|---|---|---|
| 1 · tsH-1,3 | **成键**：H 由 N 转到 O（甲酰胺 → 甲亚胺酸） | break N–H；form O–H |
| 2 · tsR-1a1b | **构象** | **空**（不得捏造成断键） |
| 3 · tsR-1b1c | **构象** | **空** |
| 4 · INT-1c-tsH2O | **成键**：脱水，C–O 断、O–H 断、C≡N 生成 | break C–O / O–H；form C≡N |

## 四、其他相关通道（仅供判断「有没有走错通道」）

| 通道 | 关键点 |
|---|---|
| → H2 + HNCO (k1) | `H2-ts1` 78.8 |
| → NH3 + CO (k2) | `NH3-ts` 80.5 |
| → NH3 + CO (k3) | `tsH-1,2` 72.2 → INT-2a 36.8 → … |
| → H2O + HNC (k4) | 与 k5 共用 `tsH-1,3`/`tsR-1a1b`/`INT-1b`，但走 `INT-1b-tsH2O` 82.7 |
| → H2 + HOCN | `INT-1a-tsH2` 112.5 |

> **重要陷阱**：k4（→HNC）与 k5（→HCN）**共用前四步**，在 `INT-1b` 分岔。
> 若我们的 TS 从 INT-1b 出发却走向 HNC，那不是 NR1 要的产物，**必须在 IRC 端点身份上区分 HCN vs HNC**。
