## 2 端面判据（本文件统一口径，下文所有 exo/endo 都指这个）

定义面符号：以原子 **1,2,3,6 = C4,C5,C6,C9** 的最小二乘平面为"烯烃平面"，法向取使 **原子 7（C10 甲醇桥）为正**。
实测降冰片烯骨架：sdist(C10) = **+0.8619 Å**，两条乙撑桥碳（C7/C8）sdist = **−1.3812 Å**（两侧确实不同面）。
于是：
- **exo 面 = 与 C10 甲醇桥同侧（sdist > 0）**
- **endo 面 = 与乙撑桥同侧（sdist < 0）**

两面用的是**同一底物几何、同一 HCNO 取向规范**（HCNO 的 C 端朝 C4、O 端朝 C5，环平面垂直于烯烃平面），**只有面符号不同**（`face = ±1` 乘在烯烃平面法向上）。因此两面的差别只是"面"，不是 HCNO 摆放方式。

## 4 声明的反应式（端面立体化学显式，原子映射=工作序）

- exo：reactant `[CH:1]#[N+:2][O-:3].[CH:4]1=[CH:5][C@@H:6]2[CH2:7][CH2:8][C@H:9]1[CH2:10]2`；product `[CH:1]1=[N:2][O:3][C@@H:5]2[C@H:4]1[C@H:9]1[CH2:8][CH2:7][C@@H:6]2[CH2:10]1`
- endo：reactant 同上；product `[CH:1]1=[N:2][O:3][C@H:5]2[C@@H:4]1[C@H:9]1[CH2:8][CH2:7][C@@H:6]2[CH2:10]1`

两个产物 SMILES 去掉 map 后的立体化学标识：
- exo：`C1=NO[C@H]2[C@@H]3CC[C@@H](C3)[C@@H]12`
- endo：`C1=NO[C@@H]2[C@@H]3CC[C@@H](C3)[C@H]12`
（CIP：exo = C1 S / C2 S；endo = C1 R / C2 R；桥头 C3 R、C6 S 两面相同 ⇒ 二者是**非对映体**，不是对映体。）

## 5 区域化学说明（为什么只有两面两条通道，不是四条）

降冰片烯有穿过 C10 与 C6···C9 中点的镜面，交换 C4↔C5。因此 "HCNO 的 C 端加成到 C4 / O 端加成到 C5" 与 "C 端加成到 C5 / O 端加成到 C4" 是**同一化合物**（被底物自身对称操作联系），不是两个能量可区分的区域异构体。本任务因此只有 exo / endo 两条通道；每条通道内 N-端/O-端取向没有第三、第四条独立通道。
