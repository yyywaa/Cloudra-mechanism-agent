# 构象选择成本对照协议

状态：离线机制验收可运行；真实远端科学对照未执行，未宣称 AI 节省算力。

## 对照输入和策略

三个策略使用相同候选档案、声明、方法/溶剂/电荷/自旋、节点、显式预算和科学验收标准：

1. 既有工具产生的代表选择，记录实际返回的候选和产物，不能凭区域卡片重新猜它的行为。
2. 固定内坐标容差的确定性区域策略（当前对照实现）。
3. 区域证据加 AI 选择，记录模型、提示版本、原始决策、调用/token 和失败重试成本。

统计启发拆区作为独立探索策略：按反应语义选择关键坐标，再输出全坐标/切点搜索的重采样评分与稳定性。拟合单峰 null 和 batch bootstrap 假设公开，不产生正式 p 值/显著性硬规则。显式接受才变更分区，固定容差对照保留。

## 离线回放

`cloudra.tools.core.conformer_replay.replay_policy` 验证选择契约，使用固定事件产生报告。每次报告记录相同预算、事件摘要和验收标准；未知分支返回 unknown，不填充虚构作业耗时或成功结果。

合成 fixture 只能验证机制。其成本单列为 fixture_cpu_hours，synthetic_verified 不能当作科学成功或实测省算力。真实录制成本只来自对应已完成作业与产物。TS 决策接入同库预算/READY 原子绑定、系统 driver 与项目加载 reconcile；回放本身不创建计算。

## 远端案例矩阵

- 柔性单分子：多个结构区域及优化后盆地合并。
- 反应中心局部差异：整体 RMSD 小但进攻几何不同。
- 两组分和三组分：反应定向与独立片段取向的覆盖/成本。
- 质子转移：不同几何安排及声明是否充分。
- 立体/环身份保持困难：同 SMILES 不同几何身份。
- 低级别非收敛：保留失败、明确干预、不静默换方法。

远端案例先锁定输入、科学参考和预算，再运行三种策略；每种策略多次独立采样/模型运行，记录 seed 和 batch 身份。按体系报告结果，不用单个案例声称普遍优势。远端运行和上线须另行安排；本协议不授权新计算。

## 指标与停止规则

报告可信完成率、实际任务数、分配 CPU 小时（核数×实际运行时间）、失败成本、重用作业数、模型调用/token/有定价来源时的费用、结构区域覆盖、预算耗尽及其他未完成原因。耗时未知和费用未知不得填零。采样覆盖不等于物理构象总体覆盖；低级别能量不能替代正式参考态能垒。

预算控制新动作，运行中超估计不杀作业。未完成必需验证就报告未完成，三种策略均使用相同科学验收。先在离线机制/小规模远端对照中评估，明确 opt-in 才启用；不解除手动 TS/IRC 禁令。
