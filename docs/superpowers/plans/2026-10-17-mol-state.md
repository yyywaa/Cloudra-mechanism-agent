# Mol-owned structure state

User-approved scope: repair the four audited paths, retaining existing scientific acceptance rules. Internal chemistry state is an RDKit Mol; functions copy before changing it. Files are exports or persistence boundaries. No compatibility state or new approval/configuration layer.

## Shared interfaces

- `core.molecule.Molecule`: runtime Mol with complete native serialization at JSON persistence boundaries.
- `read_molecule(input_path=None, input_text=None, input_format='auto', charge=None)`: converts source data to Mol without guessing bonds. Known molecular graphs own formal charges. Coordinate-only declared total charge lives on Mol without invented local charges.
- `copy_conformer(mol, conf_id=-1)`, `with_positions(mol, positions)`: return independent molecular states.
- `to_xyz`, `to_ase`, `total_charge`: derive representations or values.
- Builder components, preparation results and assembly candidates expose actual `.mol`; former chemical fields become derived views.
- Catalog records own `.mol`; atom identities live on atoms. Persist and restore the graph and properties, including isotope, map, charge and coordinates.
- QM renderers receive Mol and derive geometry/charge at export. TS reference input accepts declared molecular graphs; independently computed IRC outputs retain existing geometry-based scientific checks.
