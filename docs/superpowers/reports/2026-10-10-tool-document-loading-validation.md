# 工具说明加载实施与验收

实现保存在 `codex/tool-document-loading` 分支；默认选择复用 Agent 当前模型，语义模式支持 Jev 与已部署的本地 Reranker。两种策略共用完整契约生成、按名称读取及现有权限执行边界，没有新增按工具类别划分的 Agent 系统。

## 已验证的行为

- 全部可用工具的简短用途保留，初始化只预加载选择到的完整契约；未选择工具仍可读取说明并调用。
- 首次实际任务选择一次。普通新任务、会话恢复及压缩不重复选择；显式上下文重置允许新选择。
- 选择前先持久化开始记录；中断恢复可见失败，主任务继续。空选择与服务失败分开记录，不切换后端。
- 读取时按当前权限与实际输入/输出模型生成契约。已预加载契约更新后有替代提示。
- 压缩保留工具名、版本和重读入口；真实 JS 混合输出的计算数据和用户内容保留。
- 全局设置提供两种策略及两个语义后端的独立边界，凭据不回显；清除凭据与切回现有模型一起提交。

本地聚焦验证：语法检查、ruff、323 个 Python 测试、4 个相关浏览器测试、18 个 Node/QuickJS 宿主测试和前端生产构建通过。新增 Jev/Reranker 设置已截图检查，字段与说明可读，无重叠。未运行全仓库 pytest。

## 实施裁决

1. 只跑聚焦测试，按 AGENTS.md 覆盖技能的全套测试默认建议；代价是未修改模块的回归留给 CI。
2. 复用原有环境并让源码指向隔离工作区；代价是依赖环境差异仍可能造成跳过，本次所需 JS/浏览器测试实际执行。
3. 工作区辅助脚本因只读权限循环失败后采用有界的等价初始化；代价是需保持工作区标记与辅助脚本格式一致。
4. 工具目录复用已有的可用性投影参数；代价是投影错误可能暴露过期可用性，权限执行仍由原边界校验。
5. 用量字段保留嵌套缓存/token 信息；代价是下游消费必须接受结构化用量。
6. JS 文档折叠只匹配宿主实际返回的文档值，保留其他输出；代价是变换过的文档文本可能无法折叠，过宽匹配会伤及证据。
7. 设置段放在单独的小组件中，由全局设置引入；代价是需验证该集成位置，已用浏览器测试覆盖。
8. 效果脚本在某后端首个真实失败后停止该后端后续样本；代价是瞬时失败需要显式重跑才能得到剩余结果。
9. API 校验错误提供脱敏的可读消息；代价是错误消息不充分时会妨碍用户修正配置，实际 API 与界面错误测试覆盖。

## 独立审阅与修复

独立审阅额外运行 29 项聚焦测试和真实说明读取/JS 链路，没有 Critical 问题。三个 Important 问题均已复现并在同一修复阶段解决：

1. 首次输入持久化与选择开始之间的中断窗口：首次任务整批消息 ID 与输入原子保存，恢复选择这批原始任务，不使用之后的任务。
2. 目录简介、可用集合及读取协议更新：按实际 JS 协议内容建立版本，追加替代提示并持久化；普通会话恢复不会重复追加相同更新。
3. 按需读取的契约过期：宿主记录所有已读取契约，包括 JS 子调用；空选择和失败选择之后的读取也纳入版本追踪，跨恢复/压缩保留。

对应复现测试先失败再通过；额外验证首次任务多消息锚点、按需读取后的进程恢复，以及拼接说明与计算数据时的保留行为。最终 323 项聚焦 Python 测试全部通过。按执行技能采用测试验证修复，没有再安排第二轮审阅。

延后的小项：选择服务失败目前记录异常类名，尚未增加脱敏 HTTP 状态码及更细原因分类，故凭据、端点和服务故障的定位较粗。

审阅未裁判事项的实施结论：

- Jev/Reranker 真实兼容性保持未验证，因为没有可用端点；上线前需授权的实际连接与选择质量检查。
- 科学正确性与任务交付证据不由这份报告判断，因为未运行科学工具且科学规则未改；选择成功不能代替科学验收。
- 全仓库回归交由 CI，遵守用户的聚焦测试规则；代价是未修改模块没有本地整体验证。

验收报告与原始 JSON 补充保存在仓库，便于核对测试范围、真实连接覆盖和文档量；代价是这些有日期的样本结果不能代表之后的模型或服务状态。
