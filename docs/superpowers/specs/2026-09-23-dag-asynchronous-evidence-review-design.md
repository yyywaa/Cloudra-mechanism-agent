# DAG：异步逐证据审查与交付门禁

日期：2026-09-23。本文记录用户在本次讨论中明确同意的设计；实现与验证状态以代码及测试为准。

## 目标与边界

Cloudra 的交付表示系统愿意为某个有明确范围的结论提供证据与审查意见，
不表示结论已经成为科学事实。Benchmark 独立评价交付的正确性和化学意义，
不能直接将系统内部接受状态当作正确答案。

DAG 承载三层信息：

1. 物种及转化关系，包括候选、中间体、TS 和不同探索分支。
2. 不可变的计算证据，以及证据与研究对象、提交主张的关联。
3. 门禁状态：机器检查、Supervisor 审查意见与尚未解决的问题。

图是可持续修改的研究记录。可以分叉、汇合、替换假设；不要求将初始草稿
视作必须证明到底的固定交付清单。

## 探索与审查

- Agent 可以推进计算、增补或修改假设、放弃不合适的分支，无须等待
  Supervisor 批准。修改理由及已有证据、审查历史保留。
- 保留显式逐份证据送审：Agent 主动选择材料，说明对象和待证明的主张。
  不自动将全部试算输出送审。
- 同份材料可以支撑多种检查；不要求仅因内部阶段不同而重复送审。
- Supervisor 异步深读每份材料，接受、质疑或要求补充证据。机器检查结果
  与模型的科学判断分别记录，不相互冒充。
- Supervisor 可以提出扩展建议。建议默认不产生交付债务；只有指出与当前
  交付结论的具体必要依赖，才构成交付缺口。
- 待审不会冻结探索。硬门禁集中在最终交付，检查本次交付范围所依赖的
  证据与未解决质疑。无关探索分支与可选扩展不阻塞交付。
- Coordinator 用 `dag_propose_mechanism.delivery_targets` 显式声明本次交付的
  物种或步骤（唯一名称或 ID；选中的步骤自动包含两端物种）。省略该字段只
  扩展探索图，不改变已接受的交付范围；也可不新增图元素、单独更新范围。
  扩大范围的声明立即成为当前交付意图：Supervisor 尚未审完时，最终门禁
  就按新范围检查并显示待审缺口，不能凭旧范围提前完成。缩小范围在审查
  通过前不得抹除原有交付债务。`dag_record` 无 Supervisor，范围变更由
  harness 自动接受。
- 候选图、变更日志和对应草稿在同一数据库事务内提交；任何一部分写入失败
  都不留下半份候选。
- 替换文件或删除分支不能静默消除对当前交付仍相关的反证和质疑。

## 证据类别与 IRC

- 保留 TS 优化、频率和 IRC 这些主要证据类别，沿用按科学适用性处理的
  语义；无能垒过程不强制制造 TS。
- 方向、身份及热化学要求属于状态或门禁，不是 Agent 额外逐槽交付的工序。
- IRC 首次方向检查可使用已有两端参考几何，不要求参考几何来自本次
  IRC 外侧帧优化。
- 端点优化是 IRC 机器检查未通过或无法判定时考虑的补充材料，不是固定
  前置阶段。几何接近不能证明优化收敛，也不能证明优化起点的来源。
- Benchmark 与工具复用底层 IRC 验证实现；Benchmark 自身的独立评分
  要求不得因共用实现而被静默移除。
- 同次送审的 TS 与 IRC 文件都挂在目标步骤上；Supervisor 对整份文件组合
  的认可只对这些不可变引用及送审时的步骤、端点身份生效。

## 验收重点

- Guided 模式下待审草稿或证据不阻塞探索性计算与图的更新。
- 一份优化加频率日志可一次送审，无须制造重复阶段审查事项。
- 机器通过不伪造 Supervisor 接受，Supervisor 意见不改写机器事实。
- 与交付范围相关的待审、质疑在最终交付时可见且受到检查。
- 可选建议与不在交付范围内的分支不自动变成缺口。
- 真实异步通知、意见持久化和运行完成边界具有聚焦场景回归。

## 本轮不做

不新增人工放行，不自行变更化学判据、阈值或 benchmark 权重，不以提示词
调整替代必要的执行逻辑修改。涉及新增科学验收条件时向用户确认。
