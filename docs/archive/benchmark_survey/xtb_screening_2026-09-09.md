# Benchmark × GFN2-xTB 可算性筛查（2026-09-09）

> 目的：在"全部 120 题 method_policy 均只放行 xtb（GFN2-xTB）"的评测口径下，按三条化学判据
> 筛选可能**算不了 / 结果不可信**的题：
> 1. **氢键溶剂化依赖（HB-solv）**：机理或能垒由水/醇的氢键网络、质子梭、离子（含两性离子/
>    氧碳鎓/亚胺鎓/氮鎓）溶剂化稳定所主导，气相聚簇 + xtb（最多 ALPB 隐式溶剂）无法复现；
>    gold 锚点多为溶液相或显式水助数值。
> 2. **过渡态过于平坦（flat-TS）**：近无能垒 / 近沉没垒 / 极小能垒（≲3 kcal/mol）或平坦鞍区，
>    使"TS 一阶鞍点 + IRC + 频率"闭环在 xtb 面上不稳，或锚点数值低于 xtb 系统误差。
> 3. **多参考混杂（MR）**：TS/中间体/端点具双自由基oid、开壳单线态、强静态关联，单行列式型
>    xtb（含 UKS 三态）原则上无法描述。
>
> 另附 4. **近简并竞争通道（near-deg）**：hard 档的 ΔΔG‡/ΔΔE‡（0.6–5.8 kcal/mol）落在 xtb
> 误差带宽内，机制图可跑通但"谁占优/产物构型"会答错。
>
> 风险定义：
> - **H**（建议从纯 xtb 评测中剔除 / 特殊处理 / 预期科学拒答）：结构上就做不对或自洽闭环不成立。
> - **M**（xtb 能跑但结果不可信，需要人工复核或换引擎）：机制大体可出，但能垒/选择性/个别步
>   定性存疑。
> - （未列 = 该题按三条判据无明显风险；注意：**单按锚点容差（σ=2–3 kcal/mol）看，xtb 对绝大
>   多数题都会超差**——本筛选只找"结构上会做错/答错"的题，不是误差普查。）

判据来源：`ideapool/reaction_candidates/{easy,normal,hard,impossible}.md` 的专家标注（MR/微溶剂化/
TST/近简并注记）+ 120 个 task JSON 的 gold 机理与能垒锚点。impossible 档本身设计为"强 MR →
应科学拒答"，I 系全部命中 MR 判据属预期行为；S 兄弟题按设计"单参考可算"，仅个别需注意。

## 1. Easy（30 题）

| 题 | 判据 | 风险 | 理由 |
|---|---|---|---|

| T3 | flat-TS | M | 题面即"IRC 反常——两段转变区夹一个全实频准态"。xtb 的粗势面很可能把该平坦区抹平，agent 会错过教科书级 IRC 判别点；TS 本身可出。 |

| P1 | MR（边缘） | M | Cope 椅式 TS 在 impossible 池 A2 中记为 C0²≈0.9 边缘 MR；xtb 单行列式对其能垒/芳香稳定化描述不可信。 |
| C2 / F2 | flat-TS | M | 气相 TS 相对渐近线≈0（C2：Walden 经典垒 0.0、含 ZPE 4.3）；中央络合物口径下垒很小，xtb 对"络合物阱深/沉没垒"系统性偏差会放大。 |
| M10 / M6 | flat-TS | L/M | 甲基/乙烷旋转垒 1.13 / 3.0 kcal/mol，低于 xtb 扭转描述精度，数值可能翻转符号或趋零；TS 存在、机理无虞，仅"数值锚点无意义"。 |
| C1/C3/E1/F1/X1/M16/L1/L2/D1/D3/D4/G2/G3/P2/P3/M1/M3/M8/M14/M15 | — | 未列 | 闭壳层、气相单步、非氢键主导；xtb 可跑。G3(ene) 与 X1/M16 有"协同 vs 分步/高垒"背景但仍按单参考主通道可算，锚点容差风险另计。 |

## 2. Normal（30 题）

Normal 整体特征：**水相酸碱离子网络**（OH⁻/H₃O⁺/水写进 SMILES 只代表催化当量，机理中大量
"由水拔 H/给 H/驰豫去质子"步与中间体（烯醇盐、亚胺鎓、氧碳鎓、氮鎓、两性离子、双负离子）的
稳定化依赖体相水的氢键网络与溶剂化自由能）。按判据 1 多数应标 M~H。

| 题 | 判据 | 风险 | 理由 |
|---|---|---|---|
| NU1 | HB-solv + 离子 | **H** | Cannizzaro 经**双负离子**（二甲醛 OH⁻ 加合物再去质子）分子间氢负转移；气相裸双负离子不现实，锚点本身是"中性水助通道"。xtb 气相无法给出该机理的相对稳定性。 |
| NA1 | flat-TS + HB-solv | M（偏 H） | 决速 C–C 加成"近沉没垒"（锚点≈5 kcal/mol，气相烯醇盐-醛）；去质子/回质子靠水周转，题面未写水、需 agent 自行微溶剂化才能建出步 1/3——建模歧义 + 近沉没垒双重风险。 |
| NA2/NA4/NA5 | HB-solv | M | 烯醇盐/亚胺鎓/氧碳鎓网络 + 水周转质子（NA4 还叠加 6 中心脱羧 TS）；能垒与中间体相对稳定性依赖体相水。 |
| NA7 | HB-solv | M | nitronate 阴离子 + 1,4-共轭加成；锚点取自溶液相 30 kcal/mol；1,2/1,4 判别要可靠 ΔΔ。 |
| NI1 / NI3 | HB-solv | M | 亚胺形成/缩醛 A-1：碳胺醇脱水与氧碳鎓在水中的稳定性是机理核心；NI3 的"水驰豫去质子"需要第二水，题面只带 1 水。 |
| NO3 / NR1 / NR2 / HL1 | HB-solv | M | 酸催化 1,2-迁移（Baeyer–Villiger、频哪醇、Beckmann）经质子化/水攻/去质子网络；NR1 md 明写"水簇辅助 Wagner–Meerwein 型"计算背景。 |
| NO5 / NY2 | HB-solv | M | A-2 环氧/酯 AAC2：水加成 + 驰豫质子转移网络，四面体中间体水稳化；borderline SN2 步对溶剂敏感。 |
| NO4 / NY3 | HB-solv | M | OH⁻ 亲核步在气相高估垒、产物烷氧负离子稳定性依赖溶剂；单步 TS 可出。 |
| NH1/NH2/NH3 | HB-solv | M | Fischer 吲哚/Paal–Knorr：多步缩合-脱水-芳构化，酸催化与水中质子转移贯穿；NH3 明写"水介导 hemialcohol 路径显著降垒"。 |
| NU5/NU6 | HB-solv | M | Passerini 靠醛-酸氢键簇；Staudinger 两性离子中间体气相不稳（电荷分离 TS）。 |
| NQ3 | HB-solv | M | Nazarov 阳离子 4π 电环化 + H₃O⁺ 质子化/去质子化级联，氧碳鎓稳定依赖酸/水。 |
| NR3 | MR（竞争通道） | M | 主通道协同 Curtius 闭壳层可算；但竞争通道经**酰基氮烯**（开壳单线态/双组态，impossible 池 J5 同族）——agent 若去算竞争通道会进 MR 区。 |
| NU7 | MR（竞争）+ flat-TS | M | [2,3] 闭壳层主通道可算；[1,2]-Stevens 竞争通道具双自由基对特征（md 自注三甲基/苄基铵叶立德为双自由基路径），且两通道近简并（2–3 kcal）。 |
| NX1 / NX2 | near-deg + flat-TS | M | F⁻+二级氟代物气相 E2：SN2 vs E2（NX1 ΔΔ≈2.5）、Zaitsev vs Hofmann（NX2）都靠小 ΔΔ 与 E1cb-like 电子效应判别，xtb 大概率排错序。 |
| NX3 | HB-solv | M | 季铵 + OH⁻ 溶液相 E2（锚点溶液 ΔG‡12.8），气相带电离去基消除与 SN2 竞争排序不可靠。 |
| NX4 | — | L/M | 分子内 syn-Ei 五中心环状 TS，闭壳层、无写水，可算；气相垒与溶液锚点偏差另计。 |
| NO2 | — | L/M | DMDO spiro TS 闭壳层单参考可算；O–O 过氧键参数化误差另计。 |
| NQ2 / NH5 | MR（边缘） | L/M | 杂 DA 与 [3+2]：主 TS 协同闭壳层；[3+2] 有"双自由基分步"历史争议、异步极性 TS，xtb 定量不可信但机理可出。 |

## 3. Hard（20 题）

Hard 核心难点=**微小平能量差定选择性**（ΔΔ 0.6–5.8 kcal/mol），全部低于 xtb 的相对误差
（对氢键/次级轨道作用/构象能常达 1–3+ kcal/mol）。按判据 2/4，多数应 M~H；另有两族氢键驱动。

| 题 | 判据 | 风险 | 理由 |
|---|---|---|---|
| HF1 | HB-solv + near-deg | **H** | Henbest 定向环氧化：烯丙醇 OH···OOH 分子内氢键导向 syn（ΔΔ≈1.4）。xtb 氢键强度与方向性误差≳ΔΔ → 直接答错 cis/trans。 |
| HI1 | HB-solv + near-deg | **H** | 脯氨酸催化 aldol：Houk–List 椅式 TS 靠羧酸氢键网络定面选择性（ΔΔ≈1.2），多步烯胺/水解亦依赖水；DMSO 隐式+气相 xtb 排不出主对映面。 |
| HI4 | HB-solv + near-deg | **H** | 硫脲双氢键催化 Strecker（ΔΔ≈1–2）：选择性完全由氢键/非共价相互作用差决定，xtb 无法分辨。 |
| HE1 / HE2 | near-deg | **H/M** | Felkin–Anh（ΔΔ 0.7–0.9）/轴向进攻（1.3–1.5）：无环构象系综 + σ* 立体电子效应的小 ΔΔ，xtb 排序不可信。 |
| HE3 | near-deg + HB-solv | **H/M** | CBS 双配位六元环椅式 TS（ΔΔ≈2），B–H/配位/构象组装体在 xtb 下 ee 方向易错。 |
| HG1 | MR(边缘) + near-deg | **H/M** | 取代 Cope 椅/船 ΔΔ 5.8：Cope TS 本具边缘双自由基oid + 椅船差对方法敏感。 |
| HG2 | near-deg | M | Claisen 椅/船 ΔΔ 2–3，双甲基假赤道排布差在 xtb 误差内。 |
| HA1/HA2/HA6 | near-deg | M | 顺旋开环 torqueselection ΔΔ 2–4：电子（给/受体外向-内向）vs 位阻判别需准确 σ 轨道作用，xtb 易翻方向。 |
| HB7 | near-deg | M | 5-MeCp + MA 的 anti/syn π-面（位阻控制小 ΔΔ）；DA 主 TS 可算但面选择性不可信。 |
| HK1 | near-deg | M | 硼烯醇盐 Z–T 椅式 syn/anti（dr >95:5 需准确椅/船与假赤道差）。 |
| HL4 | near-deg | M | [2,3] S→C 手性转移，内型/外型 TS 偏好小 ΔΔ；S 参数化误差叠加。 |
| HJ2 | near-deg | M | 1-甲基环己烯氢硼化区域选择性（anti-Markovnikov 电子判别）；B 参数化一般。 |
| HD2 | HB-solv | L/M | Fürst–Plattner anti-diaxial 开环：立体专一性由构象锁定决定（几何判据、较稳），OH⁻ 水相溶剂化只影响相对能。 |
| HJ1 / HJ4 | flat-TS | L/M | 二亚胺双氢转移（G2 同族，闭壳层可算）/ 二级氟代物 anti-E2（气相近沉没垒背景）。 |
| HH1 | — | L/M | 联萘消旋（ΔG‡23.5 单 TS，无选择性竞争），仅尺寸 20 重原子。 |

| S 题 | 备注 |

| SA11 | ³O₂ 氢抽提（三态，UKS 可算）→ 产物为自由基对（乙烯基+HO₂·），xtb 开壳描述定量差。 |

## 5. 结论与使用建议

1. **按三条判据的必剔/特殊处理清单（H 级，纯 xtb 评测建议剔除或预期拒答）**：
   easy：M12；normal：NU1；hard：HF1、HI1、HI4、HE1、HE2、HE3、HG1；impossible：I 系 20 题（设计使然）。
   （normal NA1 接近 H：见上表"偏 H"注。）
2. **M 级（xtb 结果不可信，需复核或换 ORCA/高精度）**：easy T3/F3/T1/P1/C2/F2/M10/M6；normal
   大部分离子网络题（判据 1）+ NX1/NX2/NU7/NR3/NH5/NQ2；hard 其余全部（判据 near-deg）；
   impossible S 兄弟中 SB5/SA11/SG8/SD2/SJ7。
3. **结构性提醒**：hard 档以"微小 ΔΔ 定选择性"为出题本质，与 xtb 单引擎不匹配是**系统性**问题，
   不是个别题；若 hard 档必须纯 xtb 跑，等于把"谁占优"交给噪声。normal 档"水相离子网络"同理
   （判据 1 命中面广）。这两档建议：改题面为"气相/微溶剂化计算对象"已有，但**锚点与判分仍按
   溶液相或文献值**，xtb 几乎必然超 σ 容差 → 需要 computed_by_us 气相参考值或放宽容差（属科学
   决策，需你拍板）。
4. **与既有档位设计的关系**：impossible 档的"拒答校准"设计成立——I 系本就是 MR 靶子；真正要
   盯的是 easy/normal/hard 里混入的 MR/氢键/平坦面题（M12 在 easy、Cope 在 easy、S 兄弟里的
   SB5/SJ7 等），它们会稀释"前三档 xtb 可算"的档位前提。
