# 分子工作台：查看、编辑与保存结构

[文档首页](README.md) · [项目首页](../README_CN.md)

项目控制台的**「结构、计算与机理」**页面集中展示保存结构、计算记录和文件产物。点击小型结构预览或「打开工作台」，即可在独立窗口中查看和编辑；也可点击「新建／导入分子」，或在项目内按 **Alt+M**。在输入框中打字时，此快捷键不会触发。

## 页面与化学归属

- **standard 项目**直接显示结构与计算卡片，无需建立机理图。卡片提供可用的实际结构预览、来源、计算类型与已知状态。
- **DAG 项目**在同一页面加入机理图。选中物种或反应步，可筛选与它明确关联的记录；点击卡片上的对象标签，可定位回图中对象。
- 显示「未关联化学对象」的文件仍可打开、编辑。需要关联时，使用卡片的「关联对象」，选择已有物种或反应步并确认。关联只记录来源关系，不改变科学验收状态。

文件名、目录和当前选中的 DAG 节点都不会自动决定结构的化学归属。没有分子结构的报告等文件按文件产物展示，不补造分子预览。

## 导入与查看计算过程

在窗口顶部选择来源类型，再粘贴内容并点击「新建／打开」；也可填写项目文件路径，或选择本地文件后打开。支持 SMILES 新建、XYZ／MOL／SDF 等结构、Gaussian／ORCA 输入与输出，以及此前保存的完整结构记录。

SMILES 新建得到的是生成的初始结构，不代表已经优化。XYZ 与日志中的坐标不会自动确定化学键；需要时可显式使用「明确感知连接关系」，再检查和修改连接图。

打开计算记录时，默认选择**最新有实际几何的一帧**。通过帧滑块、播放或曲线点选择其他帧。仅有能量等数值、缺少坐标的点仍保留在曲线和记录中，但不能据此编辑不存在的结构。

| 数据 | 可以查看的内容 |
| --- | --- |
| 几何优化 | 实际输出帧、能量、可取得的 RMS 力与最大力、单位和原生收敛状态。 |
| 频率 | 有符号的实际频率及配对位移；选择模式后点击「播放真实位移」，动画使用该模式的实际参考几何。 |
| IRC | 原始记录可提供的路径点、方向、能量和结构；ORCA 逐点结构需要同一作业的轨迹边文件。 |
| 扫描 | 各采样点的扫描坐标与能量；多维扫描可切换横轴，并固定其他坐标查看切片。 |
| 已保存的力场轨迹 | 原有逐步结构、能量和可用梯度，保留力场来源与原始单位。 |

点击「导出 CSV」可导出帧／点编号、路径、扫描坐标以及可用能量和力指标。缺失的原始事实显示为未知：最大力不会冒充 RMS 力，缺少模式位移时不播放示意振动，缺少结构时不补造坐标。仅上传 ORCA 主日志不会同时带入其边文件；需要完整轨迹时，应从项目内保留这些文件的作业路径打开。

## 从某一帧开始编辑

「来源帧」用于回看原始记录，「编辑稿」保留你的修改。选择所需历史帧后，点击「以此帧建立编辑稿」；保存时记录的来源就是该帧。回看其他来源帧不会改写原计算，也不会把编辑稿的来源自动切到最新帧。

依次点击画面中的原子，或使用侧栏原子列表。再次点击可取消，点击「清空」可重新选择。原子编号与点击次序分别显示。

| 有序选择 | 定义的坐标 | 单位 |
| --- | --- | --- |
| A → B | 两原子距离 | Å |
| A → B → C | 以 B 为顶点的键角 | ° |
| A → B → C → D | 围绕 B—C 的二面角 | ° |

同一组选择可以执行两类操作：

1. **调整结构**：填写目标值，点击「预览结构调整」，检查后「确认修改」。默认固定前侧，移动末侧基团；可切换固定侧。环等无法唯一分开的连接关系需要手动指定移动原子。
2. **定义下一次计算**：点击「定义冻结坐标」，或填写起点、终点和步数后「添加独立扫描坐标」。多个扫描坐标按独立维度生成势能面扫描。侧栏可查看、删除这些定义，并切换画面标注。

还可以选两个原子预览加键、删键或更改键级，或选择镜面预览整分子／指定原子的镜像。修改先进入编辑稿，可使用「撤销」。删除原子导致冻结／扫描定义失效时，界面会移除受影响条目并提示重新定义，原编号不会被悄悄指向其他原子。

## 基团替换与共享历史

先在母体中依次选择**保留侧原子、被替换侧原子**，再输入基团 SMILES。带有连接标记的 SMILES 可直接声明连接点；未标记时，点击「预览基团／选择连接原子」，在基团预览中点选连接原子，再预览替换结果并确认。

基团历史跨项目共享，可按名称或 SMILES 搜索、复用和删除。排序先显示**本项目使用过的基团**，各组再按**累计确认使用次数**从高到低排列。只有确认替换才记录使用；预览和失败操作不增加次数。

## 保存与生成下一次输入

填写结构名称后，点击「保存编辑稿到项目」。完整分子状态、连接关系、来源帧、计算设置与冻结／扫描定义保存在项目的 `.cloudra/structures/` 中，同时提供 XYZ、MOL 等文件。之后从页面重新打开保存记录，可以继续编辑；仅导出的 XYZ 不包含完整连接图和设置。

保存成功后，主 Agent 会收到持久消息，知道来源文件／帧、新保存路径和坐标设置。**保存不会自动提交计算。**

如勾选「同时生成原生计算输入」，须明确填写引擎、方法、基组、电荷、多重度和计算类型；无需独立基组的方法也要显式确认留空。检查所需原生关键词，程序不会代选科学参数，也不保证从旧日志自动补全方法和基组。Gaussian 扫描起点与当前结构不一致时，需要先调整起始结构，再生成输入。

人工编辑得到的是有来源的候选结构。它不会自动继承原产物的物种／反应步身份，也不会继承旧结构的能量、频率、TS 或 IRC 验收结论。后续科学判断仍须依据对应结构的新计算与实际证据；相关要求见 [TS 流程与科学验收](TS_PROCESS_SOP.md)。
