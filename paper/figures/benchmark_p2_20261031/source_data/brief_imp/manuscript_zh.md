# Results 可用段落

Impossible 组揭示了维护计算证据与判断允许方法能否支持目标主张之间的区别。brief-errors 的正式均分为0.483，高于 guided 的0.445、同backbone standard的0.247与record的0.233。但逐题配对时，guided在10题中的5题更高，brief-errors在3题更高，2题持平。brief相对guided的0.038均分优势集中于IA1和IA9：这两题的负结论只在brief中获得完整准确度分，而IG8呈现相反结果。brief的加权准确度增益（+0.060）抵消了其图结构（−0.0066）和自洽性（−0.0155）贡献的下降；在准确度相同的其余7题上，guided的综合均分反而高0.050。因此，brief在IMP中的均分较高，并不对应于简略诊断普遍改善了证据组织。

不同组获得接受的负结论也形成互补，而非一致的强弱排序：brief在IA1与IA9获得accuracy=1，guided和standard则在IG8获得accuracy=1；对于同时包含可达与不可达步骤的IB9，guided与brief均为accuracy=0.7。在全部40个IMP运行中，14个同时具有self-consistency=1和accuracy=0，说明已有证据的组织程度与目标主张的可接受性是两个不同层面。保存的科学声明还展示了一种更细致的处理方式：brief/IC3明确将真正的最低开壳层单重态及对应状态转换边标记为不可达，拒绝给出所求单重态—三重态能隙，同时把已经计算的闭壳层单重态保留为独立表征分支，并明确排除将其两个方法依赖的相对能量解释为目标能隙。这一案例体现了保留有效探索结果、同时不将其提升为原始问题答案的能力。

# Discussion 可用段落

这些结果提示，科学引导需要支持两类不同的决定：如何补齐一次计算的证据链，以及这次计算能否回答原始研究问题。IA1和IA9使二者的区别具体可见：归档的standard报告已经认识到电子态描述的限制，却仍将半经验计算结果交付为正的能垒；brief/IC3则保留了“可计算的闭壳层分支”与“尚未计算的目标态”之间的区别。获得驻点、完成计算或整理出机理图，都不能单独决定最终主张应该覆盖多大范围。诊断详略可能通过影响下一步研究行动改变这种平衡：继续修复当前局部证明，或重新审视方法与目标是否匹配。IA1、IA9和IG8的交叉结果支持将其作为依赖任务的研究策略假说讨论，不能据此认为较短反馈具有普遍优势。

IMP分数还需要与实际主张一同解释。record/IA5正确否定了目标异旋路径，但归档记录表明，匹配器选择了具有相同端点的另一个正路径，因此未给予准确度分。brief/IC3的accuracy同样为0，尽管其保存图明确拒绝目标开壳层态和数值能隙，并区分了连接关系相同的两个单重电子态。本文保留正式分数，不把accuracy=0统一解释为科学拒绝错误。当前本地交付包包含最终分数与部分审计材料，但不含guided/brief IMP的完整对话，因而无法判断拒绝发生的时序，也不能建立诊断长度的因果作用。brief相对guided的均分差相应具有较大不确定性，已有逐题bootstrap的95%区间为−0.188至+0.284。两项IMP事后处理分别保留标记：standard/IA9采用审计重建图，brief/IC3仅修正证据引用而未改变科学主张。
