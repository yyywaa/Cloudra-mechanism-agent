\section{Data, software, and reproduction materials}
\label{sec:si-reproduction}
\subsection{Public data availability}
The study data are publicly available with read-only access at \url{https://drive.google.com/drive/folders/1yZo3eJuCUuAgedQztgCtLyJcc8MZipf7}. This directory provides the full P2 campaign archive \path{Cloudra-P2-final-20261031-FULL.tar.gz}, the 48-run P1b repeated-task archive and its offline-organization supplements, the Gold reference-calculation evidence snapshot, and the compact SI companion-data archive \path{Cloudra_SI_Data.zip}. The package versions, inventories, and checksums are provided with the downloads.

The P2 archive contains the 200 full-benchmark runs; the P1b archive contains the separate 48 repeated-task runs. The Gold archive contains reference calculation inputs, native outputs, geometries, Hessians, and curation records. The SI companion archive contains task definitions, full-precision scores, behavioral records, and the materials used to reproduce the publication tables and figures.

The separate \href{https://drive.google.com/drive/folders/1Zkn6_2aDlloAe-bmfd7w27zxmQKj5L9K}{complete behavioral-source archive (20261030)} contains frozen inputs and responses, activation states and logits, readable event traces, source databases and calculation records, analysis scripts, and vector figures. Its topic index and manuscript-context files identify the section and figure numbers used in that manuscript version.

\subsection{Machine-readable task and score records}
The supplementary source package contains \path{companion_data/cloudrabench_50_task_catalogue.csv}, the 50 task JSON files in \path{companion_data/task_definitions/}, and \path{companion_data/cloudrabench_200_run_scores.csv}. The task files contain molecular inputs, task text, permitted methods, Gold graphs, and scoring settings. The score table stores all 200 composites and 600 components at their original precision. A manifest records file hashes and the precision displayed in the printed tables.

The P2 publication-source package contains the final evaluations, paired summaries, Brief/Impossible analyses, extracted timing data, and field sources used in the figures. The manifest \path{companion_data/evaluation_manifest.json} records reference task-file hashes, evaluator revision \texttt{0961d9ab}, and the source of each run's score. The reproduction script reads these records to assemble the 200-run table; the plotting scripts use the resulting tables. All reproduced results derive from the retained run records.

\subsection{Software responsibilities and calculation records}
Cloudra revision 70daa5a identifies the implementation described in the main-text methods.\citep{ref14} The repository will be made public upon preprint posting under the GNU AGPL. Until then, reproducible tables and scores are in the companion data package. RDKit and ETKDG supply molecular representations and coordinate embedding; MMFF94 supplies force-field relaxation.\citep{ref12,etkdg2020,ref13,mmff941996} NumPy supplies numerical array/linear-algebra operations, NetworkX supplies graph representation and matching, and cclib works with engine-specific readers to extract quantum-chemical quantities.\citep{numpy2020,networkx2008,cclib2008} ASE supplies the NEB/MDMin implementation used in standard IDPP, and Adam is used in the lightweight interpolation path.\citep{ref08,neb2000,ase2017,adam2015} Task-name semantic projections use BGE-M3 embeddings and scikit-learn PCA.\citep{bgem32024,sklearn2011} Publication tables are assembled with pandas, and the quantitative figures are drawn with Matplotlib.\citep{pandas2010,matplotlib2007}

Each run records the program, model/API name, charge, spin, method, basis, and keywords used for its calculations and model requests. These records identify the experimental versions; dependency lower bounds specify installation requirements. Native outputs contain stationary-point energies, frequencies, normal modes, IRC geometries, and the links to endpoint optimization and frequency calculations. Numerical barriers use the electronic-energy difference in Equation~\ref{eq:si-barrier}.

\subsection{Reproduction entry points}
The Cloudra repository will be made public with this preprint. Until then, reconstruct the retained P2 publication tables and figures from the companion data package by running the following commands in \path{companion_data/publication_reproduction/}:
\begin{quote}\small\ttfamily
python scripts/benchmark\_p2/prepare\_publication\_data.py\\
python scripts/benchmark\_p2/plot\_benchmark\_results.py\\
python scripts/benchmark\_p2/plot\_speed\_delivery.py\\
python scripts/benchmark\_p2/plot\_imp.py
\end{quote}
That directory in the companion-data archive has the same layout as the repository and includes these scripts. The archive also includes the timing extractions and frozen behavioral requests and responses. The activation archive contains the original prompts, intervention commands, captured states, and full-vocabulary logits, which directly reproduce the reported probabilities and equal-logit controls. Replay and analysis scripts are in \path{companion_data/behavioral_scripts/}; model weights remain outside the archive. The literature directory contains the complete register, screening records, and search history. Editable TeX files, vector figures, and the bibliography accompany this SI for subsequent revision.

\subsection{Data-package inventory}
The \href{https://drive.google.com/file/d/1lXNR6zhWTP2kJ1B5_-A9elXmblQX5ALf/view}{SI companion-data archive} is distributed separately from the compact Overleaf typesetting project. Unpack \path{Cloudra_SI_Data.zip} beside the SI source to obtain the referenced \path{companion_data/} directory. Its subdirectories contain the following materials:
\begin{itemize}[nosep,leftmargin=1.5em]
\item \path{task_definitions/}: all 50 final reference task definitions, including molecular inputs and rubrics.
\item \path{publication_reproduction/}: publication input records, field provenance, bootstrap summaries, timing records, and table/figure scripts.
\item \path{behavioral/}: frozen input sets, actual request/response records, deployment snapshots, geometric/evidence source cases, and activation readouts.
\item \path{behavioral_scripts/}: the corresponding intervention and diagnostic code.
\item \path{revision_20261031/}: deployment/version metadata, archive-relative configuration and request summaries, inspected Easy-task trajectories, and historical Impossible assignment audits retained for provenance.
\item \path{revision_20261101/}: the original-run NI1 geometries and native-output provenance, uncapped barrier-error analysis, and inventories of the archived completion records.
\item \path{revision_20261102/target_matching/}: the official target-correspondence Accuracy overlay applied to the publication table, including before/after Accuracy reports, the matching audit, and \texttt{target\_matching\_accuracy\_corrections.csv}.
\item \path{literature/}: all 85 source-linked systems and the coding/search records.
\end{itemize}
A file-level SHA-256 inventory accompanies the archive. Source data retain their recorded precision; the SI analyzes the retained agent runs and quantum-chemical calculations.
