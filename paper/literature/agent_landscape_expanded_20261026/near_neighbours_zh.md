# 这轮扩展中值得补读的近邻

本文是供引言措辞与引用使用的阅读和定位笔记，不替代各系统的 benchmark 比较。

## Gráfico：计算图、结构化验证与机理应用

[El Agente Gráfico](https://arxiv.org/html/2602.17902v1) 的 Sections 2.1–2.3、Figure 3 和附录展示了类型化计算节点、构象/微溶剂化、优化、频率检查与分子性质工作流，也有 MOF 案例。[v2（2026年8月7日）](https://arxiv.org/html/2602.17902v2) 将标题改为语义执行运行时，并补充报告二硫键氧化还原机理等开放研究。引言采用 v2 引用；统计矩阵保留首版的任务编码依据，R 空白不能解读为当前系统没有机理应用。它应加入图与校验架构的对照。Cloudra 不能把“用了图”“有频率检查”本身作为独占贡献；应具体解释物种/反应步骤承载的科学主张、计算证据关联及交付语义。

## VirtualLab_CC：分子科研流程、方法选择与失败恢复

[原论文](https://www.sciencedirect.com/science/article/pii/S2949747726000230) 和[官方项目](https://github.com/CCBG-Lab/VirtualLab_CC) 描述了 Criegee 中间体–萜烯相关计算，LLM 协调 CREST、DFT 优化/频率及耦合簇作业，并处理执行失败。它明确保留关键科学决策的人审，TS 定位仍有半手动步骤。本轮没有据此否认其研究深度；对照点是自动机理探索及交付范围，而不是是否能调用量化程序。

## Magnolia：几何、长任务和经验积累的另一条路线

[Magnolia](https://arxiv.org/html/2610.27230v1) 的 Sections 3.1–3.3 有芳香分子优化/电子性质、丁烷 MD/弛豫扭转扫描和修饰 DNA MD 实例。其重点是跨会话记忆和人审经验积累。它提醒我们：几何测量、计算产物和长期研究记录可以通过不同架构组合，比较应落到证据如何形成可核查的机理结论。

## 通用编码 Agent 加领域工具/技能

[AtomisticSkills](https://arxiv.org/html/2605.24002v1)、[FermiLink](https://arxiv.org/html/2604.03460v1) 和 [OpenClaw 化学技能工作流](https://arxiv.org/html/2603.25522v1) 展示了把领域能力加到通用编码 Agent 上的路线，覆盖实际计算与错误反馈。Cloudra 的几何工具和 DAG 应说明具体分工及解决的研究瓶颈，不能仅以“专用多 Agent + 工具调用”区分。

## CatGo：架构高度相关，原论文仍需补读

[官方代码](https://github.com/Hello-QM/catgo-LRG) 和[作者向 CP2K 社区的介绍](https://github.com/cp2k/cp2k/discussions/5221) 已明确提供结构构建/编辑、可视 DAG 工作流以及 QC/MD 执行集成。这是有必要加入近邻阅读列表的系统。本轮 [RSC 原论文](https://doi.org/10.1039/d6dd00273k) 与 ChemRxiv 正文访问受限，未完成案例级核读，因此未把其广泛功能列表直接转成主统计的任务标记。现有材料不能据此判断它缺少机制证据图，也不能把普通工作流 DAG 与 Cloudra 的交付语义不加说明地等同。

## 对引言措辞的直接影响

引言的主线改为：“尽管计算化学 Agent 的研究范围不断拓展，直接面向有机反应机理探索的工作仍相对有限。”随后聚焦化学假说、三维操作和计算证据如何持续关联。70 项样本没有单独编码有机机理探索，因此保留定性表述，不以 R=8 或分子类数量给出相应比例；材料/表面的统计仅交代研究版图。ARCHE、Quntur、Estructural、Aitomia 等原近邻仍需明确引用，承认其已有机理、几何或路径工作。不同论文的任务覆盖格子不等于任务难度、端到端完成或科学验收，也不提供可直接对比的 Cloudra 得分。
