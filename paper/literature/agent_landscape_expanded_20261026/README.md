# Cloudra 同行文献扩展样本

检索截止：2026 年 10 月 26 日。时间范围从 2023 年 1 月 1 日开始。保留原 26 项样本，新增 44 项，共 **70 个分别描述的系统或计算工作流**。扩展统计另存一版；引言源稿已采用下述有机机理定位，Word 保留正在修订的版本。

这是有逐项来源的结构化文献样本，尚不是数据库穷尽检索或 PRISMA 系统综述。54 条检索日志包括多关键词组合及引文追踪，不等于 54 个互相独立的检索实验。32 条外围筛选记录包括未纳入、未完成筛选、重名/更名及评述线索；它们不是互斥的 32 篇被拒论文。

## 结果

| 实际展示的研究对象 | 系统数 | 本样本占比 |
|---|---:|---:|
| 扩展材料、晶体与表面 | 34 | 48.6% |
| 有限分子与配合物 | 19 | 27.1% |
| 分子液体、软物质与生物分子 | 9 | 12.9% |
| 实际展示多个对象类别 | 8 | 11.4% |
| 合计 | 70 | 100% |

**引言主线采用：尽管计算化学 Agent 的研究范围不断拓展，直接面向有机反应机理探索的工作仍相对有限。** 这是基于逐项阅读的定性文献判断；当前六类任务编码未单独统计“有机机理探索”，因此不从 R 或有限分子条目数推导其数量与比例。材料/表面的 34 项用于描述样本版图。研究对象与边界条件分别记录：蛋白质、聚合物或溶液采用周期盒，不会因此转成晶体/表面类。跨类系统只计一次，也不因软件声称支持多个后端而自动归为跨类。

8 个跨类系统为 QUASAR、El Agente Gráfico、FermiLink、AtomisticSkills、AutoDFT、MLIPilot、Paimon 和 Magnolia。其具体对象和证据在逐项记录中列明。此类别包含“有限分子与晶体”以及“分子液体与固体”等不同组合，不能把全部 8 项追加到材料类或分子类后再声称互斥比例。

## 纳入、去重与编码

纳入要求：LLM 在实际执行的分子、原子或分子粗粒化物理计算中参与规划、工具调用、输入/代码修改或基于计算反馈作决策。允许人参与、半自动流程和训练算法改进工作流。单纯问答、数据库检索、标量性质预测、分子生成、湿实验编排及传统确定性自动化不单独构成纳入依据。粗粒化蛋白振动和聚合物模拟已明确标注，不能当作量子化学频率或全原子 MD。

计数单位是分别描述的系统/工作流，既不是每篇版本，也不是每个模型、题目或运行。预印本、期刊版、修订版和更名项目合并；同一研究组的不同架构/评测系统可以分别计数，另做家族合并敏感性分析。未命名的早期 DFT 演示也可以纳入，不能只保留有品牌名称的系统。

两套 DynaMate 分属不同作者和软件栈；Guilbert 的 DynAgent/DynaMate 合并一次，de Gillis 的 LAMMPS/Moltemplate DynaMate 本轮仍待进一步筛选。两个 MDAgent 分别是 2025 材料 LAMMPS 工作和 2026 生物分子工作，不能合并。VASPilot、VASP Agent 和 AutoDFT 也是不同系统。

| 代码 | 正面证据的含义 |
|---|---|
| T | 结构构建或编辑 |
| E | 单独展示的静态能量、电子结构或材料性质计算 |
| O | 几何优化/弛豫 |
| F | 振动、频率及相应热化学；含明确标注的粗粒化正常模 |
| R | 显式路径或 TS 搜索；含非化学反应的结构 NEB |
| D | 分子动力学或量子动力学；基于 MD 的 PMF/MM-PBSA 等归在这里 |

各任务可重叠，正面记录数为 **T=49，E=51，O=44，F=20，R=8，D=29**。空白表示本轮未编码到证据，不表示系统没有该能力。计算尝试也可证明任务覆盖，不能把覆盖方块当作成功率。静态能量不会因为做了几何优化而自动补一个 E；MD 输运、反应网络抽取、自由能图、扫描峰也不自动等于 R。

R 的 8 项包括材料表面反应、位错迁移和有限分子工作；不能写成“只有 8 个机理发现 Agent”，更不能由矩阵推断其 benchmark 与 Cloudra 难度相同。

## 检索和证据质量

三路并行主题检索涵盖分子量子化学/反应机理、材料/表面/催化、分子动力学/聚合物/生物分子；再补跨类框架、2023–2024 早期工作及 2026 年 9–10 月新报告。检索使用标题、缩写、任务与软件关键词，并沿原论文参考文献和作者项目页追踪。发现的重要引文入口是 Dral 等人的 [49 系统 Perspective](https://arxiv.org/html/2608.18508v1)，但它的名单、任务分配和统计分母没有直接复制为本样本；新增条目均回到各自原始报告或官方项目材料编码。

多数新增证据来自论文结果、方法、附录、官方代码或原始项目演示。部分出版社/预印本平台直接打开被拒，但可读到其索引中的原始全文；相应来源限制已逐项说明。单纯二手介绍和搜索摘要没有用来补齐未核实的任务格子。

Protomia 依赖开发者工作实例和开发者写作的 Perspective，Chelatron 依赖 DOE/LANL 官方演示，尚不能声称二者已有独立论文评测。MLP Copilot 的 LLM 参与知识组织、验证规划和决策上下文，计算活动及科学决策由人审阅；不能描述为 LLM 自主提交所有计算。

`first_public_date` 使用本轮定位到的可追踪日期，不保证每项都是不可争议的最早公开日。AutoSolvate-Agent 用原始 workshop 论文印刷的 2025-08-06，作者列表另报 2025-06-08，初次发帖时间未查明。CASCADE 用当前标题预印本日期，早期 SkillPuzzler 日期未定；生物分子 DynaMate 的早期 DynAgent 版本也存在类似限制。Protomia 首发日为开发者声明，Chelatron 为官方会议材料日期。这些不确定性不影响本轮对象/任务计数，因此不额外制作精确增长趋势图。

未解决的线索继续留档，主要包括 ArIA、Q-planner、LARA-HPC、CatGo、ChatMat、MatBrain、ISAAC、另一套 DynaMate 等。ArIA 的原始摘要明确声明分子 ORCA 模拟，但本轮未读到具体算例；CatGo 官方代码确有结构编辑及 DAG 工作流接口，但原论文算例尚未完成核读。它们均不能据此被写成“没有计算能力”。

## 敏感性分析

- El Agente 六个系统合并为一个家族：**N=65**，材料/表面 33、有限分子 15、软物质/生物分子 9、跨类 8。家族因有实际分子和固体案例而归入跨类。
- 暂去官方项目演示而无独立原始论文算例的 Protomia 与 Chelatron：**N=68**，材料 34、有限分子 17、软物质 9、跨类 8。
- 再去只在已执行计算项目中提供人审规划/验证辅助的 MLP Copilot：**N=67**，材料 33、有限分子 17、软物质 9、跨类 8。
- TSBench 的 benchmark 内置 Agent 环境及纯约化模型的量子动力学 Agent 继续在外围单列，没有为了增大样本而并入主分母。

这些分析展示计数单位与纳入边界的影响，不用于挑选最支持某种叙事的比例。不是概率样本，因此不报告人群置信区间。

## 图与论文使用

所有图用 Matplotlib 绘制，宽 **86 mm**，最小字号 **7.5 pt**。完整矩阵按对象分成多个单栏面板，不把 70 行压进一张图；Cloudra 单独显示设计定位，不计入分母。建议正文保留对象分布及最相关的分子/跨类对照，其余完整矩阵进入 SI。

视觉规范沿用原三张单栏图：英文 DejaVu Sans、中文采用原图相同的字体选择；正文标签 7.8 pt、辅助说明最小 7.5 pt；材料绿 `#658568`、分子蓝 `#587C92`、软物质金 `#BD9950`，新增跨类用中性灰 `#7A858A`。保留 2.1 mm 方形任务标记、交替浅底、0.6 pt 细线及 Cloudra 的深绿定位说明。面板拆分承担新增信息量，不靠缩字承载。

引言重点是**直接面向有机反应机理探索的工作仍相对有限**，并明确承认 ARCHE、Quntur 等近邻已有进展。Cloudra 的定位落在**有机小分子机理探索中，化学意图如何转成可检查的几何操作，以及计算证据如何关联到具体物种和反应步骤的交付**。一般量化任务、单步 TS 搜索与机理研究的范围分别说明，不把“有机机理”扩大成所有分子计算。图用于交代研究版图；性能提升、任务难度与科学验收仍需要各自的 benchmark 和真实计算证据。
