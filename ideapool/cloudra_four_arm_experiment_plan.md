## 一、研究主旨与核心科学问题

在反应机理自主探索任务中，通用大语言模型（LLM）常因缺乏严谨的物理约束而陷入“伪收敛”与幻觉。面向计算化学顶级期刊（JCTC / JCIM），本研究的核心问题是：**科学校验门禁、DAG 证据拓扑编排、化学领域算法集成与高操作性的错误诊断反馈，如何协同保障自主智能体在机理探索中的可靠性与纠错能力？**

本系统不把底层单一量化算法视作不可替代的独创点，也不依赖单一的编排图概念，而是构建了一套完整的化学机理闭环：
- **假设与拓扑编排（DAG）**：将机理推测形式化为反应物、中间体、过渡态与产物的有向无环图，将每一步反应主张与严格的量子化学计算绑定。
- **底层计算与科学确证（QM Engines）**：统一驱动 Gaussian / ORCA 完成基态初猜、鞍点优化（TS Opt）、频率分析（有且仅有一阶虚频）与双向内禀反应坐标（IRC）路径验证。
- **外部督导与验收拦截（Supervisor & Stop Audit）**：独立于主执行智能体的监督角色，依据物理准则决定是否允许流程结算，拒绝缺乏虚频或路径证据的过早交付。
- **结构化诊断与自愈循环（Diagnostic Feedback）**：当遇到几何发散、虚频不对或 IRC 无法闭合时，将量化底层日志解构成具备化学意义的错误类型与操作建议，引导智能体自我修正。

论文正文将围绕具体体系展开真实的研究轨迹：展示智能体如何提出机理假设、调度量化工具、遭受物理失败被拦截、依据诊断反馈恢复并最终达成确证，如实报告成功、有效阶段性交付（Partial）以及物理不可达（Impossible）判定。

## 二、四组对照实验设计（Four-Arm Ablation）

实验通过四个受控分支解耦核心系统组件的影响，各组配置如下：

| 组别代号 | 实验分支 | 核心组件设定 | 督导与结算拦截 | 错误反馈粒度 | 旨在检验的科学假说 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Arm A**<br>完整引导版 | `benchmark/arm-guided` | 保留完整化学工具链与独立科学校验工具（`ts_guess.verify` 等） | 开启独立 Supervisor，执行严格的科学校验与结算强拦截 | 完整领域诊断与恢复引导 | 系统完整能力上限基准。 |
| **Arm B**<br>自主无拦截版 | `benchmark/arm-record` | 保留完整工具链与 DAG 拓扑记录，但移除结算硬约束 | 关闭 Supervisor 拦截，智能体自主决定何时停止与结算 | 完整领域诊断与恢复引导 | **外部物理门禁的必要性**：检验缺乏外部督导拦截时，智能体是否会产生过早结算与假成功。 |
| **Arm C**<br>判定中性化基线 | `benchmark/arm-standard` | 禁用独立校验入口，隐藏 DAG 工具；保留底层量化计算，公开科学结论中性化 | 同 Arm B（无外部强拦截） | 普通程序输出，无高层自动判定结论 | **科学校验与显式拓扑的协同效应**：检验仅给模型原生日志和基础计算时，模型能否自发完成机理确证。 |
| **Arm D**<br>简略诊断版 | `benchmark/arm-guided-brief-errors` | 工具链、DAG 与门禁逻辑完全同 Arm A | 保留 Supervisor 与完整结算强拦截（同 Arm A） | 仅提供紧凑的失败类别与对象代码，剥离详细解释与长篇建议 | **领域深度诊断的因果价值**：在规则与拦截一致时，详尽的错误解释对智能体自愈效率的提升幅度。 |

### 对照维度的有效解释边界

所有组共用基础交付要求：正式结束前必须提交工作区根目录的 `mechanism_graph.json`，文件缺失或格式错误时反馈修复对象并继续运行。此检查不判断科学证据是否成立；Standard 与 Record 仍保留各自的科学验收设置，后台挂起与研究子任务不要求提前提交整个项目的图。

1. **Arm A 对 Arm B（督导与强拦截包的效应）**：评估外部物理门禁是否显著降低假成功率、促使智能体在遇到失败时继续尝试，以及引入的额外交互成本。
2. **Arm B 对 Arm C（校验引导与显式拓扑的组合效应）**：评估缺乏专用校验接口、拓扑组织工具及自动化结论反馈时，智能体从原生日志中解读机理与自发验证的能力边界。需要注意，当前 C 组同时移除了 DAG 工具与公开判断标签，属于组合消融。
3. **Arm A 对 Arm D（诊断信息粒度的纯效应）**：在系统门禁、工具集合与任务上下文完全一致的前提下，单独隔离错误反馈的详略对纠错成功率、无效重试轮数和资源开销的因果影响。

### 细节实现与隔离保证

- **Arm C 的判定中性化处理**：底层的几何优化、频率分析与 IRC 真实计算完全保留并计入后台数据库；仅在返回给模型的响应载荷中，将 `verified`、`candidate_only` 及明确的科学结论字段转为 `null` 或中性说明文本，迫使模型像人类研究者一样查阅原始计算输出，离线评分依旧基于真实物理产物。
- **Arm D 的简略错误处理**：通过 `brief_errors.py` 截断长篇指导文字，但保留精确的错误类别码与目标文件名，不修改任何判定逻辑或收敛阈值。混合文本字段（如包含频率与键长测量的原生字符串）按原样保留以避免破坏原始事实。

## 三、基准题库与评估体系

### 3.1 题库分级

评测采用冻结的标准反应题库（50 题），涵盖四个难度梯度：
- **Easy（20 题）**：单步闭环反应，路径明确，主要考验基态与一阶鞍点寻找的基础能力。
- **Normal（10 题）**：存在竞争路径或多步级联，要求智能体维护连贯的机理图并正确连接中间体。
- **Hard（10 题）**：涉及复杂立体化学敏感性、构象丰富体系或柔性骨架，考验构象搜索与精准过渡态捕捉。
- **Impossible（10 题）**：物理化学上不可达或禁阻的反应通路，考核智能体能否基于计算证据给出合理论证并正确标记不可达（`accessible=false`），而非为了交卷臆造假过渡态。

### 3.2 评价指标三维解耦

评测体系彻底解耦交付状态、科学真值与计算成本，坚决不使用单一综合分掩盖物理瑕疵：

| 评估维度 | 指标项 | 判定准则与科学含义 |
| :--- | :--- | :--- |
| **科学真实性** | **独立科学确证（Scientific Success）** | 由独立离线评估器审核原生量化日志：鞍点存在且仅有 1 个虚频，双向 IRC 分别光滑连接至对应基态极小值（0 虚频），且反应能垒与黄金标准偏差在容许阈值内。 |
|  | **假成功率（False Success）** | 智能体自称任务完成（Claimed Complete），但离线物理确证未通过。直接反映智能体的幻觉程度与系统的虚假自信。 |
|  | **有效阶段性成果（Valid Partial）** | 针对未完全走通的复杂体系，智能体如实声明局部交付，且交付的中间体或候选过渡态经离线确证成立，给予阶段性认可而不计入完全成功。 |
|  | **不可达识别率（Abstain / Refusal）** | 在 Impossible 题目中正确识别路径阻断并拒绝虚假交付的比例。 |
| **探索质量** | **连续基准得分（Continuous Score）** | 包含拓扑相似度（10%）、物理自洽性（30%）与能垒精度（60%）的分级加权量化。 |
| **资源开销** | **系统成本（System Cost）** | 统计实际调用的量化计算核心时数、模型上下文 Token 消耗、工具交互轮数与墙钟时间。 |

## 四、执行路线与停机纪律

### 第一阶段（P0）：分支工程验收与一致性冻结

在消耗正式算力预算前，必须在本地通过环境验收：
1. 校验 A/B/C/D 四个分支与公共基线（`8c568ca`）的继承关系无漂移。
2. 验证 B 组非强制结算门禁、C 组公开结论中性化逻辑、D 组错误截断逻辑各自生效且不破坏底层计算驱动。
3. 验证离线评测引擎对于无 DAG 交付（Arm C）仍能通过原生日志回溯提取物理证据。
4. 冻结题库配置文件与随机种子，确保同题四臂使用相同的初始构型与基础输入。

### 第二阶段（P1）：四臂代表性小样本试跑（Pilot Run）

选取包含 Easy、Normal、Hard、Impossible 各 1 题的代表性子集，在受控预算下独立启动四臂通跑：
- 重点观测运行流是否卡死、上下文压缩机制是否正常、各组是否有预料之外的信息泄漏。
- 检查 Arm D 在发生错误时智能体是否陷入无意义的高频复读，检查 Arm B 是否频繁发生过早结算。
- 确认全部运行轨迹与原生量化文件完整归档，并可无损喂入离线评分脚本。

#### P1b 实测与离线重算结果沉淀（2026-10-24）

在工作站（WSL2 环境）完成了首轮四臂代表性先导实测（P1b 战役），共覆盖 48 个独立沙箱（4 臂 × 4 题 [E1, NB1, HA1, IA1] × 3 轮重复）。原始运行日志位于 `/home/ly/cloudra-p1b-20261024`，离线重算结果沉淀于 `docs/benchmarks/p1b_rescored_results.csv` 与 `docs/benchmarks/SCORING_FAIRNESS_FIXES.md`。

##### 1. 评分公平性缺陷根治

在初步评估中发现，部分物理上完全收敛且能垒正确的计算被评测器重罚（从应得的高分跌至 −1.0 或 0.325）。经排查定位到三处评估器设计缺陷并予以彻底修复：
1. **JSON Schema 过于苛刻导致整图作废**：原 `properties` 仅允许标量，当智能体将 `evidence_log` 或虚频写成列表时校验失败；节点与边禁止额外键导致注释被拒。全图作废触发“无图”惩罚（−1.0）。已修复为宽容模式，忽略无关扩展字段。
2. **TS 证据仅截取首个路径**：过渡态通常包含优化、频率与 IRC 三份日志，旧评估逻辑仅取首个路径，导致无法读取频率块，判定无鞍点而使能垒准确度归零。已修复为自动遍历并绑定全部可用原生日志。
3. **选择性定性判定硬编码标签**：原实现要求边的 `channel` 字符串必须与题库私有标签（如 `outward_rotation`）完全一致，而任务提示词从未提及该命名。已改为比对优势通道产物的物种同构性（`species_substitution_cost`）。

##### 3. 先导实验核心科学发现

1. **外部物理门禁是遏制虚假自信与幻觉的决定性屏障（Arm A vs Arm B/C）**：
   在物理禁阻的反应（IA1）中，缺乏 Supervisor 拦截的 Arm B 与 Arm C 发生了 100% 的虚假交付——智能体在无法找到真实过渡态时，强行捏造了 18.6–25.4 kcal/mol 的虚假能垒并声明机理成立，导致准确度归零（总分仅 0.102）。而在 Arm A 中，Supervisor 的严格门禁倒逼智能体做出了 100% 正确的物理不可达拒答（1.000 分）。
2. **详尽引导提升决策稳定性，简略诊断在可解任务中具备极高韧性（Arm A vs Arm D）**：
   在单步、多步及复杂立体选择性等物理可达任务（E1, NB1, HA1）上，Arm D 仅凭紧凑的错误类别代码便取得了与 Arm A 相当的优异成绩（0.943–1.000），说明结构化错误码足以引导模型自愈。但在面对边界模糊的不可达任务时，详尽的化学解释能显著增强模型做出“不可达判定”的置信度，使 Arm A 达到极低的不确定性（方差仅 0.032）。
3. **显式拓扑编排与科学反馈的协同价值（Arm B vs Arm C）**：
   在常规反应上，模型尚可凭借通识代码能力调用量化程序；但在面对复杂立体异构与竞争通道（HA1）时，完全丧失 DAG 拓扑组织与明确科学反馈的 Arm C 发生严重退化（0.243 分，甚至在 r2 中完全遗漏交付图），方差高达 0.574。显式拓扑结构在复杂反应网络探索中起到了关键的“认知锚点”作用。

## 五、运行入口规范

评测统一通过模块化 CLI 触发，采用严格的物理隔离目录运行：

```bash
# 验证评测入口与环境管线（无模型探针）
python -m cloudra.benchmark --backend none \
  --tasks-dir ideapool/tasks/easy --only E1 \
  --data-dir /tmp/cloudra_probe

# 正式运行命令模板（需指定各分支独立的绝对数据目录）
python -m cloudra.benchmark --backend runtime_v2 \
  --tasks-dir ideapool/tasks/easy \
  --tasks-dir ideapool/tasks/normal \
  --tasks-dir ideapool/tasks/hard \
  --tasks-dir ideapool/tasks/impossible \
  --data-dir /path/to/isolated/arm_workspace/run \
  --concurrency 1
```

所有正式评测日志与量化产物均要求持久化留存，为论文正文提供可完全复现的原始物理证据支撑。
