## 1. 论文定位与核心主张（Claims）

面向 JCTC 的化学机理 Agent 论文，开篇直接旗帜鲜明地点出我们的核心学术主张：**科学校验门禁、DAG 证据拓扑编排、化学势能面（PES）算法工具链与引导式报错信息，是直接协同提升自主智能体（Agent）机理研究能力与物理可靠性的四大决定性要素。**

系统贯彻了**“智能的克制”（Intelligent Restraint / Agentic Parsimony）**的核心架构设计哲学：不把大模型当作无所不能的万能操作系统，也不强求它在多轮交互中手工维护复杂的底层运行时工程（如集群排队轮询、文件路径拼接、原子序号重排、中间轨迹持久化、哈希幂等键与版本状态差量等）。相反，我们将这些高度确定性的机械任务彻底下沉给系统的状态机与底座（以 `ts_process` 与 `ComputeDB` 为代表），使大模型的认知预算高度聚焦于高阶机理假设推演、化学参数决策与结构化报错诊断自愈。这一“关注点分离与动作空间约束”模式在主流 Agent 系统文献（如 SWE-agent、ChemCrow、CodeAct 等）中已被多方严格证实有效，因此论文将直接通过前沿文献引用阐明其理论自洽性，不额外开设孤立的消融实验臂，但在系统架构章节开辟专门板块深入剖析。

正文围绕这一核心主张展开严密的篇章布局：
1. **开篇主张与理论假设**：直接阐明四大要素如何正交协同，解决通用大模型在量化机理研究中的空间盲区、虚假自信与假收敛。
2. **贯穿案例与工具算法交织叙事**：以一个真实的复杂机理任务（如竞争电环化或多步级联）为骨架，全程展示智能体从提出假说、构建 DAG、调用底层计算工具，到中途发生物理失败被具体门禁拦截、根据引导式报错恢复的完整工作流；并在推进步骤中交织拆解底层工具算法的数学实现。
3. **架构设计哲学：“智能的克制”与运行时下沉**：以 `ts_process` 为核心，阐述关注点分离与动作空间约束，将底层复杂的调度、重排、快照与状态机完全交由系统托管，免除模型认知过载；结合前沿 Agent 文献（SWE-agent, ChemCrow 等）确立其理论先进性。
4. **评测数据挖掘与机器可解释性**：基于 50 题 Benchmark 进行深度数据挖掘，对任务进行多维化学归属（周环、消除、自由基、立体选择性、禁阻等）；将智能体运行轨迹映射到语义嵌入空间，分析决策路径的分岔、循环与收敛形态，开展机器可解释性分析，统计智能体在不同化学维度的表现。
5. **四组消融实验实证**：依据 48 沙箱先导复现性审计（P1b）与全量评测，回答门禁必要性（IA1 假成功杜绝）、诊断粒度纯效应（Arm A vs Arm D 稳定性与方差压缩）及拓扑组织价值。
6. **课题组真实未发表机理计算（备选拓展）**：在时间与算力许可下，展示系统协助解决一个未发表的真实有机反应机理，证明系统在非预设考场环境下的实战泛化能力。
7. **科学讨论与能力边界（多软结合体系）**：如实客观地评述系统的不足，重点聚焦于“**多软结合体系**”（弱相互作用、超分子柔性构型与多组分溶剂化配合物），剖析当前分数较低的物理根源，并指出干净重测与未来发展的方向。

### 3.1 贯穿案例的写法：全流程实操与底层算法交织

案例按真实探索时间线推进，杜绝“粉饰太平”的顺风局包装；在智能体推进研究步骤的动态叙事中，自然穿插所调用化学工具的底层数学与物理实现：

1. **问题提出与机理假设（Hypothesis & DAG Setup）**：
   - 任务输入仅为未标号分子与反应条件，智能体提出候选机理假设，并在 DAG 中初始化反应物、候选过渡态与产物节点。
   - **交织算法一：原子映射与反应中心感知**。解析 SMILES/SDF 拓扑，调用最大公共子图同构算法；针对位阻轴与手性中心，采用基于范德华半径按图距离指数衰减（$\rho^d$）的 BFS 权重遍历算法（`reaction_mapping.py`），计算端点距离变化矩阵并自动提取动态成断键原子对（Watch-pairs），免除人工坐标标定。
2. **过渡态初猜与势能面扫描（TS Guess Generation）**：
   - 智能体基于识别的反应中心调用初猜工具生成初始构型。
   - **交织算法二：刚体对齐与 IDPP 路径插值**。先经由纯 NumPy 实现的 Kabsch 奇异值分解（SVD）消除端点刚体平移与转动；随后系统根据算力预算选择标准模式（Coupled NEB-IDPP，带改进切线法、距离负四次方对势 $r_{ij}^{-4}$ 与 MDMin 迭代）或轻量模式（独立构型目标距离加权与 Adam 快速松弛），自适应提取路径距离中点构型。
3. **鞍点精确优化与虚频确证（TS Opt & Normal Mode Verification）**：
   - 调度 Gaussian/ORCA 底层引擎执行一阶鞍点优化与谐性频率分析。
   - **交织算法三：虚频振动本征模投影判据（`_assess_imag_mode_alignment`）**。鞍点优化收敛且有且仅有 1 个虚频后，系统提取虚频简正振动位移矢量，计算各原子对的相对位移模长，并严格投影至步骤 1 识别的反应中心 watch-pairs。若振动模长未显著落在成断键对上（如发生骨架扭曲或假虚频），直接判定方向未对齐，拒绝晋级。
4. **反应方向检验与路径闭环（Directional Proof & IRC）**：
   - 推进双向内禀反应坐标（IRC）检验。
   - **交织算法四：短程 IRC 与端点基态重松弛**。拒绝无休止的全程 IRC 积分耗时，仅从鞍点双向各推进有限步关键帧，再将双向末帧分别优化至零虚频稳定极小值，以严格的微分拓扑闭环替代冗余的平坦区积分。
5. **分层门禁拦截与自愈恢复（Multi-Layer Gating & Recovery）**：
   - 真实呈现探索中遭遇的几何发散、错误虚频或 IRC 不对称失败，并清晰区分**由谁发现、由谁拦截**：
     - 计算引擎级（几何优化 MaxCycle 耗尽、SCF 发散）；
     - 工具算法级（虚频投影未对齐、端点极小值存在残余虚频）；
     - DAG 契约级（缺少双向端点证据、未完成频率闭环）；
     - 外部 Supervisor 门禁（拒绝未经证明的过早交付）。
   - 智能体接收结构化诊断反馈后调整初始扭转角或切换计算参数，完成自愈闭环。

### 3.2 架构设计哲学：“智能的克制”与运行时下沉（以 ts_process 为核心）

在传统朴素的 Agent 设计中，开发者往往试图让大模型接管从高阶假设到低阶工程的一切细节，强迫模型在多轮对话中手工记忆和维护集群作业 ID 轮询、临时文件路径拼装、原子编号跨帧对齐、中间快照持久化、以及并发幂等键。这种过度放权不仅白白耗尽上下文预算，更导致严重的认知过载与灾难性状态漂移。

Cloudra 践行了**“智能的克制”（Intelligent Restraint / Agentic Parsimony）**的设计哲学，在认知推理与确定性工程之间划定绝对红线：
1. **职责分离与动作空间约束**：将大模型的职责严格限制在**科学意图声明、化学方法选择、结构化报错诊断与假设修正**；将一切具有确定性算法解的机械工作（文件 I/O、跨端点原子重排、轨迹序列化、计算队列状态机调度等）彻底下沉至系统底座。
2. **以 `ts_process` 为代表的确定性 SOP 状态机**：
   - 模型对外仅交互极简的高阶接口（`ts_prepare` / `ts_resume`），底层由状态机自动驱动 `declare -> build -> map -> assemble -> guess -> validate -> submit -> refine -> verdict` 的严密流转；
   - 自动处理拓扑映射下的原子重排（`reorder_atoms_by_mapping`）与不可变快照落盘；
   - **阻塞信息点名到原子**：校验由流程自身闭环执行，遭遇挫折时直接将病因定位到具体原子对，模型据此修改参数即可恢复；
   - **极度节制的事件推送**：仅向智能体推送“阻塞（blocked）”与“终态（terminal）”两类事件，绝不将海量中间日志和阶段推进过程灌入模型上下文，杜绝上下文污染。
3. **文献自洽与免消融定性**：这一方法论在主流智能体系统文献（如 SWE-agent 提出的 Agent-Computer Interface 范式、ChemCrow 的专业化学引擎解耦、以及 Reflexion 等）中已被多方严格证明是杜绝 Agent 崩溃、降低 Token 损耗的核心原则。因此，论文直接通过文献引用确立其学术合理性，无需单开消融实验臂，而在系统架构与方法论板块作为重要理论亮点进行专题剖析。

### 3.3 Benchmark 数据挖掘、任务归属与机器可解释性

不把 50 题评测仅作为单一的分数排行榜，而是将其作为高密度的行为挖掘宝库，深入分析自主智能体的决策空间：

1. **多维化学任务归属（Task Taxonomic Profiling）**：
   - 依据严谨的物理化学特征，对 50 道试题建立正交分类体系：单步周环反应（电环化、Diels-Alder）、多步极性级联、自由基重排、芳香取代、竞争性立体选择性通道、以及物理禁阻反应（Impossible 负样本）。
   - 统计智能体在不同反应拓扑、电子结构类型和势能面曲率特征下的成功率梯度与脆弱点。
2. **轨迹在语义潜空间中的拓扑演化（Semantic Space Trajectory Mining）**：
   - 将智能体多轮决策过程中的思维链文本、工具入参及环境反馈转化为语义嵌入（Embedding），映射至二维/三维降维空间。
   - 观测不同实验组别（Arm A/B/C/D）在解空间中的探索轨迹分布：成功任务呈现向目标吸引子平滑收敛的流形；陷入打转的任务呈现闭合环路；缺乏门禁的基线组（Arm B/C）则在未触及真实化学驻点时突变跳跃至虚假终止点。
3. **机器可解释性与决策归因（Machine Interpretability）**：
   - 分析工具调用的转移矩阵与马尔可夫决策特征，揭示智能体在面对特定报错代码（如虚频发散、IRC 断裂）时的策略转移概率。
   - 统计人工介入需求度、无效重试轮数与算力开销分布，给出智能体认知边界的形式化机理解释。

| A 完整版 | `benchmark/arm-guided` | 工具、DAG、Supervisor 和强制科学完整结算保留；partial 依既有流程处理 |

| C 校验入口禁用、判定反馈模糊化 | `benchmark/arm-standard` | 独立 verify/strict 禁用；计算、测量和内部真实判断保留，公开自动科学结论中性化；实际还隐藏 DAG，并有残余信息渠道 |
| D 简略报错完整版 | `benchmark/arm-guided-brief-errors` | 与 A 保持工具、判定、阈值和拦截一致，仅缩短模型可见诊断；原始计算输出和混合科学文本仍可能带有引导 |

- A/B：强制干预组合效应，不能写成纯 Supervisor 消融。
- B/C：独立校验入口、判定反馈与 DAG 可见性等共同变化，不能写成单一工具或纯 DAG 效应。
- A/D：引导式诊断反馈的作用；D 是较简略反馈，不是所有引导归零。
- 三项对比均不独立识别某个底层算法的贡献，也不代表与其他 Agent 系统的性能比较。

先导实测证据参考：四臂在代表性子集（E1/NB1/HA1/IA1）的 48 沙箱历史离线快照归档于 `docs/benchmarks/SCORING_FAIRNESS_FIXES.md` 与 `docs/benchmarks/p1b_rescored_results.csv`。2026-10-24 历史均值为 Guided `0.979`、Brief-errors `0.907`、Record `0.729`、Standard `0.5344666667`，均为连续分数，不是科学成功率。

统一模型、任务、预算规则、计算条件和独立评估；报告真正使用的分支/commit，而非只相信 mode 标签。四组各自从任务起点运行，不做现场分叉续跑；暂不扩成逐算法全量消融。正式实验的运行和停止条件沿用配套实验计划，不由本文另行规定。

### 3.5 完整、正确、partial 和分数

结果必须分别回答三个问题：

1. **完整吗？** 是否覆盖该任务要求的交付项目与证据，而非 Agent 有没有说 complete。
2. **正确吗？** 对实际交付且可判定的主张逐项独立审核；候选、无证据和无法判断单列，不以“未发现错误”代替已证实正确。
3. **完整且正确吗？** 完整任务契约是否被满足，且所需结论通过独立科学审核。这才支持完整科学成功的统计。

partial 允许交付候选、有效子结果和未解决问题，不要求所有产物事先在线验真；离线审计识别其中有效部分。partial 不能自动标为 verified，也不能并入完整成功率。

同时报告假成功、误接受/误拒绝、有效 partial、人工介入和实际成本。在线门禁的接受/拒绝与 Agent 最终的科学主张或拒答分开统计；没有该在线门禁的组，不将“不适用”记为零错误。明确全部计划任务、已启动任务、可评估任务、声称完成任务等分母，并给逐题配对结果及适当的不确定性；重复种子不算新的独立题目。

运行阶段保存完整轨迹与原始证据，正式评分在离线整理为统一机理图后完成。四组同规则：可从该次运行已有内容人工恢复缺失 JSON、证据绑定和路径，保留来源与人工介入记录；不能按 Gold 新增科学结论或补入新计算。当前运行代码仍有即时评分和基础交付约束，即时分只作诊断快照；本次方法调整不表示代码已改造。

连续分数用于描述部分进展及误差结构。加权 0.9 不是 90% 成功率。缺正式工件或 `undelivered` 标签不能直接等同于科学零分；离线整理也不能补造缺失的频率或 IRC 证据。科学验收要求保持不变，审查仍需确认原运行实际有什么、缺什么。

### 3.6 真实未发表机理实战（备选）与系统局限性（多软结合体系）

1. **课题组真实未发表机理计算（实战验证，视时间算力增补）**：
   - 若时间与计算资源允许，将选取一个课题组正在研究的真实、尚未发表的有机反应机理案例作为压轴实战。
   - 证明系统不仅能在静态考场（Benchmark）中拿高分，更能作为计算化学家的真实协作伙伴，面对全然未知的势能面自主给出有启发性的路径探索与过渡态确证。

2. **能力不足与物理边界评述（聚焦“多软结合体系”）**：
   - 论文 Discussions 章节坚决摒弃“全知全能”的虚夸叙事，以一流理论化学家的严谨与坦荡直面系统的能力短板。
   - **核心局限明确落定于“多软结合体系”**（包含多组分非共价复合物、弱相互作用主导的溶剂化超分子体系、以及高柔性长链聚集态等）。
   - **实测表现与物理根因剖析**：在 Cloudra Bench 题库中，凡是深度涉及多软结合或弱结合特征的反应任务，智能体的综合得分均普遍不高。这类体系的势能面极其平坦、构象势阱极浅且熵权效应显著，单行列式基态 DFT/半经验泛函难以精确刻画动态色散与氢键网络，基于共价骨架的刚性坐标映射与局部反应中心假设在弱结合通道中面临失效。
   - **学术口径界定**：如实指出当前低分数据为开发阶段的非正式实测观察，后续将在完全独立的纯净环境中执行全套复测以给出严格统计值；但整体趋势与定性物理局限不会发生根本性逆转。诚实揭示这一边界不仅不会削弱论文价值，反而能极大增强 JCTC 审稿人对本研究科学诚实度的信任，并为计算化学 Agent 未来的超分子动力学与多尺度算法演进指明方向。

## 4. 架构、算法数学与 SI 的分工

正文需要能解释能力来源的方法，而不是只有工程示意图。完整可复现定义放在 Methods/SI，正文给出关键思想、输入输出、科学含义与实例。

| 内容 | 正文必须讲清楚 | Methods / SI 应准备的细节 |
| --- | --- | --- |
| 架构和状态流 | Agent 决策、化学工具、DAG 证据、Supervisor、异步作业及离线评价的职责；失败/partial 的返回路径 | 角色、工具集合、消息/事件顺序、实际接口、版本与恢复规则；避免把 runtime DAG 与评分图 schema 混为一谈 |
| 结构与初猜构造 | 原子映射、端点对齐、构象/路径候选如何减少模型直接编造几何；其失败边界 | 实际使用的映射与匹配、坐标变换、约束、单位、原子编号和构象选择规则 |
| 路径与几何算法 | 所用方法优化什么、输出是什么，为什么只是候选而非科学确证 | 目标函数、梯度或近似、耦合/约束、优化器、停止准则、数值稳定处理、初始化及版本；未使用的实验模块不凑作论文贡献 |
| TS 与科学校验 | 鞍点优化、频率与 IRC 方向证据如何串联；正常结束与科学有效不同 | 既有判据、可配置默认值、原生输出解析、映射/几何及端点证据关联；短 IRC 不要求自身走到底，不因写作另改阈值 |
| Benchmark 和独立审核 | 题库构成、参考适用域、完整/正确与部分分数的区别 | 冻结公式、逐项评分/否定规则、Gold 来源与缺口、分母、失败分类、统计与人工审计流程 |
| 复现材料 | 读者如何从代表图回到真实证据 | 逐题配置/版本/种子、输入、原生日志、结构、能量与状态索引、全量结果和 HTML 轨迹；数据许可与访问边界 |

**IDPP 的具体写法：** 当前 [实现说明](../docs/IDPP_MODES.md)区分 `standard` 与 `light`。standard 调用 ASE 的 IDPP 实现；light 保留旧的独立图像启发式优化。Methods/SI 应如实列出目标与权重、图像耦合、优化器、停止/退化处理和 ASE 版本，不能把二者包装成同一算法的等价实现。此处的 standard 是插值模式，与 C 分支的 standard 名称无关。

文件生成成功、优化满足停止条件、结构适合后续计算，以及 TS 最终通过校验，是不同事实。IDPP 修复或标准实现对齐只能支持实现层面的表述；没有匹配的下游结果，不能宣称提高了 TS 成功率。原始算法文献与软件来源在正式 Methods 中逐条核验后引用，本计划不补写未经检索的参考文献。

现有 [论文草稿](../paper/draft.md)、[章节目录](../paper/sections/)和 [SI 草稿](../paper/supplementary_information.md)作为素材入口，不视为已完成的新叙事。旧草稿的题数、评分逻辑、接口要求与未解决事项均须对照冻结版本更新，不能直接复制成当前事实。

## 6. 实际写作顺序

1. **整理证据清单。** 将已有材料标记为设计事实、工程测试、正式运行结果、非正式观察或待补证据；只用运行记录判定实验完成情况。
2. **选贯穿任务并整理完整轨迹。** 先写“发生了什么”，用真实事件确定图 1/2，保留失败和人工介入。
3. **写架构与化学 Methods。** 从该任务向外解释通用方法，补齐数学和参数来源，明确外部方法、本项目实现及实际改进的区别。
4. **冻结结果表与分析口径。** 与实验计划一致，列好完整/正确/partial、成本、任务分类及四臂差异；数据未齐时留待填，不写结果句。
5. **依据正式结果写 benchmark、轨迹与消融。** 先写逐项观察，再讨论解释与竞争解释；语义分析和真实案例只在有充分材料时加入。
6. **写局限与讨论，再定稿引言、摘要和标题。** 用最终证据反向检查开篇每条 claim，避免引言承诺多于结果。
7. **核对正文、SI 与复现索引。** 同一运行/结构/能量/版本在各处一致，图表可追溯；随后按选定期刊的实际要求调整格式。

不按固定日期承诺完成，也不把可选真实案例或语义分析变成启动主文写作的前提。先写已确定的方法与证据框架，结果部分等待真实数据。
