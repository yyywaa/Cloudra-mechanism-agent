## 一、一句话定位

Cloudra 在论文中的核心主张（**不使用“首个”等主观宣称**）：

> 一个面向有机小分子反应机理发现的 LLM 多 Agent 系统：以**有机小分子结构感知**为输入与分析底座，
> 以**DAG 导向的确定性编排**（辅以知识图谱的经验沉淀与检索）为核心机制，
> 以**无政府架构**为多 Agent 的组织载体，从初始反应物与反应条件出发自主提出竞争性机理假设，
> 自动编排量子化学验证流程（过渡态搜索、IRC 连通性确认、能量剖面分析），基于严谨的计算结果实现假设的闭环修正、对比与淘汰，
> 最终收敛到具有完整物理证据链的化学机理论断。

三大支柱（创新点与能力载体）：
1. **有机小分子结构感知**：Agent 不再将分子仅仅视为线性的 SMILES 文本，而是对成键状态、立体化学和
   电子结构具备可物理验证的感知能力（包括原子映射、键级感知、异常键长/键角检测、Mayer 键级及 IBO 定域轨道分析等）。
2. **无政府架构**：技术实现层面的组织载体——摒弃固定中央调度器的扁平化多 Agent 协同体系
   （基于 AgentHub 论坛机制的横向通信 + Coordinator 角色分派 + 定时提醒唤醒 + 异常自动恢复）。
   **验证方法待定**：如何将其从工程实现描述转化为可证伪的科学对比实验仍是开放问题（详见第十节）。
3. **DAG 导向确定性编排 + 知识图谱（核心创新点）**：
   将机理假设、证据绑定与阶段契约显式外化为持久化、可审计的有向无环图；交付完备性由物理证据派生的确定性覆盖率判定，
   而非依赖大语言模型的主观自我宣称；同时利用知识图谱沉淀跨任务经验，并通过 AgentHub 知识资源层实现高效回填。

## 三、创新点（Novelty）深入分析（v0.3 重构）

### 3.1 明确回避的宣称
- **不宣称“首个（First）”**：在端到端、完全自主、多 Agent 协作、DFT 验证等任何维度均避免使用 first 类表述；通过实质的技术支柱与严密的实验对照确立贡献。
- 明确回避以下已被同行充分探索的方向：
  - “多 Agent 编排量子化学计算” —— El Agente Q、ChemGraph 等已有扎实实现；
  - “基于 LLM 的科学假设生成” —— Google Co-Scientist 已在 Nature 发表；
  - “Agent 之间的信息共享机制” —— 避免与 AgentRxiv 等已有概念重叠；
  - “自动过渡态初猜与搜索” —— TSAgent 在表面体系的重规划循环已有深入研究；
  - “指令执行的安全审批” —— 属于工程落地保障，不作为论文理论核心。

### 3.2 重点聚焦的三大支柱

**支柱 1：有机小分子结构感知**
现有的化学 Agent 系统大多将分子作为 SMILES 字符串输入，成键状态、立体化学以及过渡态的部分成键情况往往依赖大语言模型的文本模式推测。Cloudra 在工具层为 Agent 提供了严谨的物理与几何结构感知：包括原子映射追踪、键级识别、成键/断键过程中的异常几何参数检测、Mayer 键级分析以及定域化 Lewis 结构分析（IBO）。机理假设的提出与筛选建立在客观物理结构之上，实现从“文本直觉感知”到“几何与电子结构感知”的跨越。

**支柱 2：无政府架构**（技术组织载体；**验证方法待定**）
采用扁平化、无单一中心调度器的协作模式：以 AgentHub 为横向通信媒介，结合 Coordinator 的任务协调、定时提醒与异常自愈机制。该架构作为系统的底层组织方式，**目前暂不作为独立的理论创新点宣称**，后续将探索可量化的实验评估方案（例如：与具有严格中心编排器的系统进行容错性与抗干扰对比，或分析通信拓扑对决策一致性的影响）。

**支柱 3：DAG 导向确定性编排 + 知识图谱（核心创新点）**
- **DAG 导向的确定性编排**：将机理假设、证据绑定与阶段状态显式建模为持久化且可审计的有向无环图。任务完成度由物理证据派生的阶段覆盖率（Stage Coverage）客观判定，杜绝模型在证据不足时提前“宣布完成”；各阶段严格按契约顺序绑定，过渡态特征（如唯一虚频 n_imag==1）由确定性检查器硬性判定。这一机制正面解决了 2026 年批判文献中指出的“Agent 框架无法可靠判断自身何时真正完成任务”的普遍缺陷。
- **知识图谱沉淀与检索**：将跨任务的历史经验构建为结构化图谱，作为 AgentHub 的默认知识资源层（GraphRAG），支持 Agent 在需要时自主检索；被动提示仅在关键节点触发，避免频繁全量检索造成上下文噪声污染。

### 3.3 与相近前沿工作的核心边界划分
- **与 ARplorer 的区别**：ARplorer 仅使用 LLM 离线生成 SMARTS 规则，反应搜索空间被规则静态锁定，后续仅执行规则枚举与筛选，模型无法在获得物理计算反馈后动态调整策略。Cloudra 实现了**在线假设生成与计算结果驱动的闭环修正**——随着计算深入动态更新假设空间。核心差异在于“静态规则引擎 + LLM 离线初始化”与“LLM 作为具备在线反思能力的决策主体”。
- **与 TSAgent 的区别**：TSAgent 侧重于“给定反应路线与初猜几何，定位特定的过渡态结构”，本质上是**单路径上的数值优化与寻优问题**；Cloudra 则聚焦于“从反应物与反应条件出发，自主提出多条竞争机理假设、并行验证、相互比较并最终收敛”，解决的是**假设空间的自主构建与决策选择问题**。
- **与 ChemGraph 的区别**：ChemGraph 的计算流程止步于热力学性质（自由能与反应焓），不包含过渡态搜索与动态机理推导，且缺乏底层的几何与电子结构感知层。
- **与 RxnNet 的区别**：RxnNet 主要依赖硬编码的启发式化学规则库，未将 LLM 作为自主推理与决策的核心。
- **与 AdsMind 的区别**：AdsMind 专注于**多相催化中的吸附构型搜索**（属于无化学键断裂重组的弱相互作用体系，侧重于单一势能面极小点搜索）；Cloudra 专注于**有机反应机理发现**（涉及化学键断裂与重组、多步反应网络、竞争路径及过渡态物理定性）。

### 3.4 审稿人四问与应对策略

1. **“引入底层结构感知与直接输入 SMILES 相比，实际效果有何显著差异？”**（针对支柱 1 的验证）
   → 应对策略：在消融实验中设置“开启完整结构感知工具 vs 仅提供 SMILES 纯文本”作为核心对照组；在测试集中专门设计高度依赖立体构型与微观成键特征的反应（如轴手性构建、endo/exo 异构选择等），纯文本输入在此类任务上的失效，可直接作为支持支柱 1 的有力证据。
2. **“如何量化 DAG 确定性编排带来的实质收益？”**（针对核心创新点的验证）
   → 应对策略：通过三模式消融实验（无图 standard / 自动记录 dag_record / 严谨复核 dag_guided）提供直接数据支撑；评测指标除了机理召回率与能垒误差外，重点统计**幻觉率与交付完备性**（即在无 DAG 约束下，模型提前宣称完成但物理证据存在实质缺失的比例）。
3. **“知识图谱在跨任务复用时，是否会引入错误先验并导致误差放大？”**（针对支柱 3 知识图谱层的验证）
   → 应对策略：图谱条目严格按照证据等级（L0 文献知识 / L1 计算验证 / L2 理论假设）进行分层管理，被计算证伪的假设采取“保留记录但大幅降权”的策略；在消融实验中通过对比“接入图谱 vs 不接图谱”，专门监测错误结论的复现与纠错情况。
4. **“如何证明系统是在自主推导机理，而不是在复述训练集记忆？”**（针对泛化能力的质疑）
   → 应对策略：测试集中大量引入具有竞争路径的反应（如协同机理 vs 分步机理、对映面选择性竞争），正确结论取决于物理计算得出的相对能垒差值；在 Impossible 难度梯队中引入多参考态体系，考察系统能否准确识别“当前方法级别无法可靠处理”并主动做出合理拒答——**在算力与方法受限时主动做出可靠的拒答，本身就是正确的科研决策行为**，也是现有多数大模型系统难以达成的指标。

### 步骤 2：四级难度基准测试集设计（Easy / Normal / Hard / Impossible）

**方法学定位与化学信息学底座**：以高阶等变机器学习势 **MACE-OMol25** 为唯一物理计算金标准（2026-08-25 决策：单引擎锁定，不再引入 AIMNet2 / MACE-OFF 等其他 MLIP 作交叉验证；`ideapool/mlp_benchmark/SUMMARY.md` 此前的 AIMNet2 主选结论已作废并在文首标注过时），深入探讨 MLIP 训练分布偏向与物理边界，重点评估 Agent 的端到端链路执行、机理假设生成/淘汰、微观 3D 几何感知及强多参考态的主动科学拒答能力。

**测试集规模（定稿）**：Easy 30 / Normal 30 / Hard 20 / Impossible 20，共计 100 个反应体系。

**题面规范（2026-08-25 决策）**：全部题目仅向 Agent 提供 atom-mapped 反应 SMILES + 总电荷/自旋多重度 + 反应条件 + 输出契约（含可解析的拒答通道），**不提供任何 3D 几何**——3D 构想与构象搜索作为全档统一的第一个可独立计分阶段纳入考核；`gold_dag` / `gold_value`（含理论级别与来源 DOI）/ 预注册容差 / 难度标定（专家估时）/ MR 诊断共识值（Impossible 档）/ 兄弟题对 id 等元数据仅评分侧可见。

**MACE-OMol25 训练集偏向与四级难度梯度对齐**：
- **训练集特性与偏向**：基于 1.4 亿 $\omega\text{B97M-V/def2-TZVPD}$ 计算，吸收了 Transition-1x 与 ANI-1xBB 等反应轨迹，具备反应性（有机 TS 搜索成功率 ~96%）；但反应轨迹高密度集中于重原子 $\le 7$、CHNO 主族的单步气相反应，多步人名反应网络与复杂杂原子（P/S/卤素）密度骤降；
- **底层物理天花板**：OMol25 全量标注基于单参考 DFT（开壳层用 UKS），对于强静态关联、近简并态及多参考双自由基体系，底层 DFT 数据本身失真，MACE 在该区域输出非物理能垒。
- **四难度梯队具体重构定义**：
  - **Easy（30 题）—— 教材级经典单步反应（重原子 $\le 7$，CHNO 主族原型）**：
    丁二烯+乙烯 Diels-Alder、丙烯醛环加成、经典 SN2/E2、环丁烯顺旋开环、小分子酮式-烯醇式互变。完全命中 MACE-OMol25 核心高频舒适区，重点考核 Agent「SMILES 输入 → 3D 构想 → MACE+NEB/Sella 寻找 TS → 虚频与 IRC 物理核验 → 绑定 DAG」的端到端基础闭环能力。
  - **Normal（30 题）—— 循序渐进的经典可算反应（路线竞争 → 简单多步 → 复杂人名网络，2026-08-30 修订）**：
    三层递进：N1 路线竞争判别（二级碳 SN2 vs E2、E2 的 Zaitsev vs Hofmann 取向、Hofmann/Cope 消除、1,2 vs 1,4 加成、spiro vs planar 氧转移等单底物多通道体系）；N2 简单多步网络（Aldol 加成、Henry、Cannizzaro、Paal–Knorr 呋喃/吡咯、Knorr 吡唑、Huisgen 1,3-偶极环加成等 2–3 步体系）；N3 复杂人名反应网络（Claisen 重排、Beckmann 重排、Baeyer-Villiger 氧化、Mannich 反应、Fischer 吲哚合成核心步骤等 3–4 步级联；简化的 Wittig 反应含 P 属第三周期元素，其去留待评审打标，CHNO 替代考点为铵叶立德 [2,3]/[1,2] 竞争）。底物采用局部电荷明确的小骨架，**新增题目一律纯 CHNO(F)（第 2 周期元素）以命中 MACE-OMol25 训练高密度区**；MACE 具备局部键变计算能力但未见过完整多步流程，重点考验 Agent 竞争路径能垒排序、自主提出多步机理假设、中间体捕获与反应网络 DAG 剪枝能力。（注：easy 档已定稿的含 Cl 气相 SN2/E2 条目 C1/C2/C3/E1 为例外，不追溯整改。）
  - **Hard（20 题）—— 新颖微观立体化学与手性体系**：
    精选近几年文献中小分子量、高立体敏锐度的体系（顺旋/对旋 torquoselectivity、特征性 endo/exo 偏好翻转、阻转异构消旋阻垒、手性小分子/氢键诱导的微观立体位阻选择性）。利用 MACE 的高阶等变张量积对 3D 几何构象的高度敏感性，考核 Agent 的三维几何感知、原子空间映射与精细构象搜索能力。
  - **Impossible（20 题）—— 强多参考态与近简并双自由基体系（方法边界与科学拒答）**：
    环丁二烯 D4h 自动异构化、四亚甲基乙烷 45° 扭转态、邻/间/对苯炔体系、开壳层 Criegee 中间体、氧代烯丙基双自由基等。直接击穿 MACE 与单参考 DFT 的物理假设，系统给出任何势垒均为非物理结果；核心考核 Agent 能否在自旋/电子态诊断中识别强关联特征，明确指出方法局限并**主动提交科学拒答（Abstention）**。

**评测体系：运行轨迹多维评估（Trajectory-Level Multi-dimensional Evaluation）**：
> 核心原则：摒弃单一标量能垒打分，重点从 Agent 交互与执行轨迹（Trajectory）中抽取结构化行为指标，多维度量 Agentic 科研推理能力。

1. **五大核心评估维度**：
   - **Dim 1: 假设构建与网络拓扑度（Hypothesis & Topology）**：提出来的机理是否符合化学基本原理，中间体集合与键变序列是否完备，是否能正确提炼竞争路径；
   - **Dim 2: 工具调用与物理自洽性（Tool Sanity & Physical Checks）**：3D 构象生成、MACE 势能面鞍点优化、虚频单一性（$n_{\text{imag}}==1$）及 IRC 双向连通性核验的严格度；
   - **Dim 3: 闭环纠错与执行韧性（Error Recovery & Resilience）**：面对构型不收敛、虚频错误或 IRC 断裂时，能否自主分析物理原因并自适应调整初猜重新探索；
   - **Dim 4: 定性排序与相对能量趋势（Qualitative Ranking）**：竞争路径主副产物能垒高低序、决速步指认是否与权威文献/实验一致；
   - **Dim 5: 方法边界认知与科学拒答（Epistemic Modesty & Abstention）**：在 Impossible 梯队中识别强多参考/开壳层失效域，给出严谨科学论据并主动拒答（SimpleQA 式三态计分：合理拒答正向得分，盲目瞎算扣分；结合 AbstentionBench 查全/查准率）。
2. **验证链（四层，全程确定性、零 LLM judge）**：
   - **L0 物理门禁（fail-to-pass 主判据）**：收敛 → 极小点 0 虚频 / TS 恰好 1 个虚频 → $|\nu_{\text{imag}}| \ge 100\ \text{cm}^{-1}$（排除构象假 TS）→ 虚频模式位移沿变化键 → IRC 两端连通到声明物种；借鉴 Terminal-Bench 三准则：门禁通过 ⟺ 化学上可接受（Specificity）、可解档冻结前必须实际跑通（Solvability）、成功必须绑定实际执行的计算证据链防"背文献势垒"（Integrity）；
   - **L1 能量容差比对（次级指标，独立计分）**：容差预注册且 ≥ MACE-OMol25 实测误差（由 Easy 档试算标定，见待办）；流程成功与能量精度分开报，避免绝对能量比对的不可复现陷阱（TSAgent 教训）与结构性零分；
   - **L2 机理相似度**（化学参数化 GED，见第 3 条）：比对 agent 交付机理图与 gold_dag；
   - **L3 三态计分与拒答质量**：SimpleQA 式 correct=+1 / abstain=0 / wrong=−p（p≈4–9，全拒与永不拒两个刷分基线都必须次优）；Impossible 档报拒答 recall，Easy–Hard 报误拒率，整体报 Abstention F1。
3. **机理相似度指标：化学参数化图编辑距离（本工作的化学信息学方法学贡献，2026-08-25 定稿）**：
   - **构造**：经典 GED 的 0/1 节点替换代价替换为化学语义参数化的连续代价——(a) 两个零代价 hash 短路：tautomer-insensitive 与 protonation-insensitive molhash 命中即 c=0（RDKit 一行调用，零参数零标定，互变异构/质子化差异视为无足轻重）；(b) 其余情况进双参数 sigmoid 作用于 Morgan 指纹 Tanimoto：两端平坦、中段陡降（"细微结构差距无关紧要"），中心取指纹分布实际中段（~0.35–0.45，而非直觉的 0.5——相似分子 Tanimoto 常仅 0.4–0.7）；(c) **立体分层规则**：Easy/Normal 的 gold 不标立体，isomeric 与 no-stereo 失配同价 0；Hard 档 no-stereo 失配高代价（≈1）——立体一致性只在"与 gold 比对"处可验，L0 物理门禁只保证计算内部自洽，两处罚的是不同性质的错误；(d) 边替换代价 = 基元步键变集合（atom-mapped 断/成键对）的对称差，协同 vs 分步等机理层面分歧在此显式计价；
   - **双重产出**：标量分数 + 最优对齐的**编辑脚本**（gold→agent 机理的逐步 diff：缺哪个中间体、哪步键变错、哪条竞争路径多余）——评分与失败归因报告从同一对象长出；
   - **工程与标定**：机理图 ≤20 节点，GED 直接调 networkx，无性能风险；不做标注集标定（自由参数仅 sigmoid 中心/陡度两个），降级为**锚点单测**——手写十余个已知节点对（同一物种/互变异构/对映体/同系物/差一个官能基/完全无关）断言代价排序，参数定死后冻结进评测规范（预注册，防"橡皮尺"）；
   - **定位与 novelty**：分子指纹相似度与反应指纹（rxnfp 谱系）只作用于单分子/单步反应；将机理假设作为化学语义类型化图整体比对尚无现成工作，是可独立发布的评测方法学工件；投稿前须做针对性 novelty 核查（KinBot/AutoMeKin 等自动机理发现谱系的相邻概念）。
4. **零算力依赖参考库构建**：每题的黄金参考值（拓扑图、文献/实验能垒 $\Delta G^\ddagger$、产物比例）直接提取自权威文献已发表数据，登记 `gold_dag` 与 `gold_value`，评测脚本仅做轨迹解析与真值比对。
5. **统计严谨性**：报告各维度通过率及 Wilson 95% 置信区间；每题 k≥3 次独立重复，报 pass@1 与 pass^k（可靠性下限）；成本账本含计算作业数、工具调用数、cpu-hours 与墙钟时间（token 仅作参考量单列，不作主成本轴——DAG 投影/notices 等上下文注入策略会污染 token 计数）。
6. **效率量化框架（2026-08-25 定稿）**：
   - **成本轴**：计算作业数与工具调用数双轴（不设预算帽——预算是否生效无法预期，预算曲线方案已否决）；
   - **进度轴（细粒度）**：所有引起 DAG 正向改动的行为均为进度跳点——中间体/边创建并保留、证据绑定、复核通过、阶段 pending→supported、机理草稿被接受；纵轴取与 gold_dag 对齐的**净覆盖**（被驳回/删除的不计），保证曲线单调且抗刷；stage 状态几乎只在最终单点翻转，不能单独充当进度轴；
   - **核心产物 = 进度-成本曲线**：横轴累计计算作业数/工具调用数、纵轴 DAG 净覆盖；派生 AUC（效率主指标）、收敛拐点（达终值 90% 时的累计成本）、平台期（无进度打转段长度）；
   - **浪费与纠错诊断**：浪费计算比（结果未绑定任何 stage 的作业 / 总作业）、冗余调用比（直接复用 harness `loop.detected` 事件）、纠错延迟（首个失败信号 → 下一次进度跳点的成本）、早拒答奖励（Impossible 档成本感知计分）；
   - **防作弊闸门**：效率指标只在正确交付或合理拒答的轨迹上解释，不得奖励"快速失败"。

#### 题目 JSON Schema 与评分器架构（2026-08-29 定稿）

候选池 markdown 是"人读"形态；进入评测前需升级为**机器可读的 task JSON**。本节定稿题目数据结构与评分器架构。

**1. 设计约束（来自现有系统摸底）**：系统内无独立"题目"概念——一次任务 = Project + coordinator AgentSession + query 文本；DAG stage 契约由**被测 agent 自己声明**（预声明会泄题）；评分基础已存在：`dag/completion.py` 的 `evaluate_delivery`（确定性覆盖判定）、`dag/controller.py` 的 `audit_stop`、TS 频率 `n_imag==1` 硬检查。题目 JSON 因此只描述"**喂给 agent 什么 + 跑完拿什么确定性打分**"，不预声明 stage 契约。

**2. task JSON 顶层字段**（一题一文件，`ideapool/tasks/{tier}/{task_id}.json`）：

| 字段 | 内容 | 评分侧可见 |
|---|---|---|
| `task_id` / `tier` / `family` / `name` | 如 `easy-D1`；tier ∈ easy/normal/hard/impossible | 否（仅标识） |
| `prompt` | `query`（题目文本，**显式要求 agent 在沙箱根目录维护 `mechanism_graph.json`**）、`role`、`orchestration_mode`、`seed_graph_template` | 否（喂给 agent） |
| `system` | `reactants`/`products`（SMILES 分开存）、`charge`、`multiplicity`、`conditions`、`elements`、`max_heavy_atoms`、`closed_shell`、`single_step` | 部分（题面只给 SMILES/电荷/多重度/条件） |
| `method_policy` | `allowed_methods`（**默认 `["mace-omol25","xtb"]` 双引擎放开**，2026-08-29 确认）、`allowed_basis_max`、`forbid`（如 `["ccsd(t)","wb97m-v/def2-tzvpd","dlpno"]`）、`intercept_layers` | 部分（允许级别告知 agent，拦截规则不细说） |
| `gold` | `mechanism_graph`（结构化：nodes=物种/TS、edges=基元步+键变集合+可达性标注）、`reference_computation`（`level_of_theory`、`barrier_kcal_mol`、`barrier_type`、`verification`、`reference_doi`、`computed_by_us`） | **是**（仅评分侧） |
| `rubric` | `expected_outcome`、`integrity`、`self_consistency`、`graph_similarity`、`accuracy`、`impossible_case` | **是**（仅评分侧） |

**3. 评分三层取证式审计（forensic audit）**：与"监督 agent 声明"不同，是**跑完后对沙箱的事后取证**。

- **Layer 1 · 交付诚信分（Delivery Integrity）**：沙箱递归扫描 → 提取机理图 JSON + 遍历目录找计算产物文件。图里每个节点/边能否在沙箱找到对应计算文件（优化 .log/.out、频率、IRC、能量）？**能完整对上图 → 诚信分满分；图里声称算了但目录无对应文件 → 扣分**（谎报交付）。注意：这不评"机理对不对"，只评"声称的交付是否真实存在"。
  - 图来源：**DAG 模式**（dag_guided/dag_record）直接投影交付图为 JSON（权威）；**standard 模式** agent 按沙箱模板自建 `mechanism_graph.json`，跑完与 gold_dag 做图相似比对。
  - 题面必须在 query 里**明确告知**写图 JSON 的义务（杜绝"agent 不知道要写"的冤枉分），但不引导"填满才算诚信"——填不填、填得对不对、有无真实文件支撑，都是被测能力。
- **Layer 2 · 自洽性分（Self-consistency）**：只评 Layer 1 里**有证据绑定的子图**——TS 是否一阶鞍点（n_imag==1）、IRC 是否连通两端、频率全实（极小）/恰一虚（TS）、端点 identity 是否对得上声明物种、能垒是否内部自洽。
- **Layer 3 · 准确性分（Accuracy，软）**：我们用规定计算级别算参考答案（gold barrier）设范围；agent 能垒 vs 参考值用**高斯衰减**评分（非硬阈值）——偏差小满分、偏差大扣分、偏差很大扣多。`max_penalty_fraction` 封顶（默认 0.3）防扣多（参数不同计算结果难相同，但偏差很大要扣多）。

**4. 各题精确度可调**：能垒高斯 `sigma_kcal_mol` 每题独立（非全局）。分档梯度定稿 **easy σ=3.0 / normal σ=2.0 / hard σ=1.5 kcal/mol**（2026-08-29 确认），`max_penalty_fraction=0.3` 统一；最终数值由 Easy 档 MACE 试算实测误差标定（容差 ≥ 金标准实测误差）。允许 `accuracy.enabled=false`（该题只评自洽不评精度）。

**5. 图相似度 = 化学参数化 GED**（复用第 3 条，不另造）：molhash 零代价短路（tautomer/protonation-insensitive）→ Morgan 指纹 Tanimoto 过双参数 sigmoid（中心 ~0.40）→ 立体分层（Easy/Normal 不标立体失配同价 0，Hard 高代价）→ 边代价 = 基元步键变集合对称差。networkx GED 实现，产出标量分数 + 编辑脚本（失败归因 diff）。

**6. Impossible 档标准答案**：agent 能想出机理 + **在图里把对应节点显式标注 `accessible=false`**（物理上不可达）。评分 = 识别出正确机理 AND 正确标注不可达性；硬凑出能量反而扣分。`impossible_case.require_inaccessible_annotation=true` + `gold_inaccessible_nodes` 列表驱动。

**7. 评测 runner 独立模块**：复用全部现有 API 但做更严格沙箱隔离 + **独立数据库管理**（与交互式会话库分离，防污染）。

**8. 计算方法拦截层（harness 主动拦截，不扣分）**：agent 尝试超出 `method_policy` 白名单的高级泛函/基组/方法时，harness **主动拦截**（拒绝执行 + 明确理由），**不扣分不记负**——尝试作弊/超纲不是罪，由系统拦住即可。拦截点：
- **bashtool**：`tools/core/command_analyzer.py` / `bash_habit_guard.py` 拦截命令行里手写高级方法关键字（直接写 `! wB97M-V def2-TZVPD` 的 ORCA 输入、调用未授权二进制）；
- **计算任务提交 tool**：`submit_compute_job` + `qm_input_writer` 校验 `method`/`basis`/`level_of_theory` 是否在白名单内，超出即拒。

**9. 待办（本小节新增）**：编写 task JSON 的 Pydantic schema（落 `ideapool/tasks/schema.py` 或独立评测包）；编写 easy 30 题 JSON 生成器（解析 `easy.md`）；实现评分器三层管线（沙箱扫描 → 证据绑定 → 图 GED → 能垒高斯打分）；实现方法拦截层（bashtool + 计算提交 tool 白名单校验）；搭建独立 runner 模块与独立数据库；**先用 MACE-OMol25 亲手算 easy 30 题参考答案**（`reference_computation.computed_by_us=true`），标定各题 `sigma` 并验证可解档全跑通。

## 八、知识图谱层技术方案（GraphRAG：算化排错决策图谱）

> 指导原则：**“不为了追求概念新颖而堆砌组件，切实解决问题才是论文的核心价值。”**
> 在 v0.3 与 v0.4 中，知识图谱层正式纳入执行计划，作为核心创新点（支柱 3）的组成部分。大模型并不缺乏有机化学常识，其在计算化学领域的最大瓶颈在于缺乏**“计算失败后的试错与排错经验”**。

### 8.1 图谱本体构想（Ontology：现象—诊断—根因—处置—兜底）
知识图谱的核心数据源为**计算化学公社（Sobereva 经典教程与论坛实战经验）**及权威文献中的计算方法学规范。图谱本质上是一个**面向算化排错的有向决策图（Decision DAG）**，而非简单的无序文本堆叠。

图谱中的核心实体节点与关系定义如下：
- **现象节点（Symptom / Error Signature）**：定义具体的异常现象与报错模式（如：TS 优化收敛但出现多个虚频 `n_imag > 1`、SCF 能量震荡不收敛、IRC 放坡两端回落至同一侧、开壳层自旋污染严重 `<S²>` 异常、线性角崩溃等）；
- **诊断判断节点（Diagnostic Criterion）**：定义排查动作与条件阈值（如：用 Multiwfn/GaussView 检查次级虚频振动模态是否属于甲基/侧链旋转、判断次级虚频绝对值是否小于 50 cm⁻¹、评估 T1/D1 诊断指标）；
- **处置动作节点（Mitigation Action）**：定义具体可执行的计算参数调整与构型修改（如：沿次级虚频法向坐标位移 0.1 Å 后重新 `opt(ts,calcfc)`、添加二次收敛算法 `scf(xqc,maxcycle=500)`、手动扭曲二面角打破高对称性二阶鞍点、执行破缺自旋测试等）；
- **兜底/升级节点（Fallback / Escalation）**：定义多次尝试未果后的升阶策略（如：提升基组重新计算力常数、转为 QST2 搜索、或识别多参考态特征后主动做出合理拒答）。
- **关系边（Edges）**：包含 `DIAGNOSED_BY`（现象→诊断）、`BRANCHES_IF`（诊断条件→根因分支）、`RESOLVED_BY`（根因→处置动作）、`FALLBACK_TO`（失败降级链）。

### 8.2 检索机制：节点锚定 + 沿边子图展开（Node Matching + Path Traversal）
当 Agent 遇到报错或主动发起检索时，检索过程分为两步完成：
1. **节点锚定（Node Matching）**：根据当前报错特征、解析器警告或检索关键词，精确匹配图谱中的“现象节点”（如定位到 `TS_Multi_Imaginary_Freq`）；
2. **沿边展开局部子图（Neighborhood / Path Traversal）**：检索不仅返回命中节点，而是顺着有向边向外遍历 1–2 跳（1-2 Hop），将关联的诊断动作、条件分支、推荐关键字及兜底方案一并提取出来，组装为一条完整的因果决策链。

### 8.3 Context 呈现形态：结构化决策树导图（Decision Tree Walk）
检索到的子图在注入模型上下文时，不以松散的散文段落呈现，而是渲染为具有清晰缩进与逻辑分支的**树状排查路线**：

```text
[公社排错图谱：TS 多虚频处置路径]
当前故障: 过渡态优化出现多个虚频 (n_imag > 1)
├─ 诊断步骤 1: 检查次级虚频 (freq_2) 的振动模态与大小
│  ├─ 分支 A (次级虚频 < 50 cm⁻¹ 且为无关侧链/甲基旋转)
│  │  └─ 推荐动作: 沿该次级模态微移构型 0.1 Å -> 重新执行 opt(ts,calcfc)
│  └─ 分支 B (两虚频数值相当，且均涉及反应主骨架成键断键)
│     ├─ 根因诊断: 初猜构型很可能落入了高对称性的二阶鞍点
│     └─ 推荐动作: 手动扭曲二面角 5-10° 打破对称性 -> 重新提交 QST2/TS 搜索
└─ 兜底策略: 若尝试 2 次后仍存在多虚频 -> 建议改用更高精度泛函重新生成初始 Hessian
```
这种形式将**诊断次序、条件分支与降级链条**直观呈现给大模型，模型能直接对照自身的具体计算状态选择正确的工具参数与构型调整策略。

### 8.4 证据等级分层管理机制（防止错误先验传播）
- **L0 计算化学方法学与公社实战经验**：源自计算化学公社教程与经典文献规范（如泛函基组搭配、opt(ts,calcfc) 等命令技巧、溶剂效应团簇处理、多参考态经验阈值等），附带出处链接，保持可质疑性；
- **L1 经过物理验证的计算结论**：经量子化学优化收敛并获得 IRC 确认的实际机理步与过渡态数据，置信度最高；
- **L2 模型理论假设与探索性建议**：未经计算验证的推测，明确标注假设性质，仅作为灵感参考；
- **证伪条目保留降权**：被后续计算推翻的假设不予物理删除，而是打上“已证伪”标签并降低检索排序权重——失败与证伪记录同样具有重要的科学参考价值。
- 检索排序遵循 `L1 > L0 > L2`。知识图谱自我迭代可能引发的确认偏误（Confirmation Bias）风险，通过上述证据分层与证伪降权机制进行严格约束，并在消融实验中重点监控错误结论的复现情况。

### 8.5 知识图谱与 AgentHub 的协同定位
- **AgentHub 负责任务内的横向实时通信与协同**（即时信息流与跨 Agent 广播）；
- **知识图谱负责跨任务的纵向经验沉淀与检索**（结构化决策库与实战排错锦囊）；
- 被动注入严格限制在关键节点（如机理草稿提出前、计算报错产生时、交付审计发现证据缺口时），严控上下文噪声。
