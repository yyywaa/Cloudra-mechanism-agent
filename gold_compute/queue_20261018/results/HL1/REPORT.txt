### 0.2 sdist 的定义式（本报告唯一使用的定义）
1. 取原子 **1,2,3,6 = C4,C5,C6,C9** 的四个坐标，做最小二乘平面（SVD 取最小奇异向量），得单位法向 n0 与质心 c。
2. **符号约定：令 sdist(X) = n·(r_X − c)，其中 n 取 n0 或 −n0，使 sdist(原子7 = C10) > 0。** 本文所有 sdist 都用这枚 n。
   实测：n = (0.461998, 0.373382, −0.804452)，u(C1→C2) = (0.594986, 0.542159, 0.593342)，
   c = (0.6270, −0.4068, −0.2571) Å，sdist(C10) = **+0.8619**（降冰片烯骨架），乙撑桥原子 4/5 = −1.3812/−1.3812。
3. **与重启前 BUILD_PROVENANCE.md 的 n 差一个整体负号**：那边的 n_old = unit((C5−C4)×(C6−C4)) 满足 sdist_old(C10) = −0.862。
   两个 n 只差符号，面归属完全一致：**C10 同侧 = n 正侧 = n_old 负侧**。
4. 通道命名（标准口径，与 BUILD_PROVENANCE.md 一致）：

### 8.4 面选择性
**ΔΔE‡ = 11.89 − 6.95 = +4.94 kcal/mol，偏向 C10 同侧（endo）通道**（两侧均用同一 E_ref）。
**表述定稿**：ΔΔE‡ 一律写「**约 5 kcal/mol 量级，倾向 C10 同侧（endo）**」，不把 4.94 当有效数字；
括注保留两位精度的算术值（4.94 = 11.89 − 6.95），并注明「两位差值的算术结果，不作有效数字声明；B3LYP-D3BJ/def2-SVP 单点能本征不确定度 ±1–2 kcal/mol」。
同样地 **e_endo 6.95 / e_exo 11.89 也加同一句 caveat**，避免被当成精确值引用。未做 ZPE/热校正。

### 8.5 末态与选择性不可混用
ΔE(P_exo − P_endo) = +1.62 kcal/mol（C10 同侧产物更稳定）是**末态热力学差**，不是面选择性；
动力学选择性只看 TS 相对同一 E_ref 的那一栏。**区域化学无选择性（两种区域异构体是同一化合物的镜像），面化学有选择性**，两者不能混。
