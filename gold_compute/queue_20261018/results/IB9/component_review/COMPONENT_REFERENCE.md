# IB9-E1 拆组分参考审计

## 它是络合物吗？
798原料侧IRC B与833最终结构均由坐标工具确认完整11原子、两组分、无新增跨组分共价键：CH2N2与乙烯。这是气相非共价预反应接触体/弱复合物候选，不是金属配位络合物（无金属），更不能称已证实束缚极小值。833仍−29.75/−4.37cm⁻¹；本轮允许拆分参考不等于删除这些负频。

## 原子对应（均1-based）
TS/798/833工作序C1,C2,N3,N4,C5,H6…H11：乙烯成员[1,2,6,7,8,9]，C1带H6/H7、C2带H8/H9；CH2N2成员[3,4,5,10,11]，链C5–N4–N3，C5带H10/H11。
- 复用742的局部[C1,N2,N3,H4,H5]→工作序[5,4,3,10,11]；题设重原子map=[1,2,3]。
- 复用745的局部[C1,C2,H3,H4,H5,H6]→工作序[1,2,6,7,8,9]；题设重原子map=[5,4]。
- 这些是保连通的显式对应；独立构建单体的等价H任意置换只选一种双射，不伪称历史逐原子轨迹。工作反应中心仍[1,5]/[2,3]，不是题设map数字。

833内部距离CC1.317、CN1.252、NN1.129Å，NNC179.8°；742独立单体CN1.253、NN1.130Å、180°，745 CC1.316Å，均无结构异常。798 B外帧两反应接近距离2.704/2.595Å→8333.383/3.249Å，仍相同两组分无氢转移/错物种。
