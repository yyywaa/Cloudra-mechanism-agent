## 1. 总反应与模型

### 1.1 反应

threo/erythro-N,N-dimethyl-3-phenyl-2-butylamine oxide 的 Cope 消除（syn-Ei，五元环过渡态）：

```
C6H5-CH(CH3)-CH(N+(O-)(CH3)2)-CH3   ->   Ph-C(CH3)=CH-CH3  +  (CH3)2N-OH
C12H19NO (q=0)                         C10H12              C2H7NO
```

- 目标通道：生成 **2-苯基-2-丁烯**（2-phenyl-2-butene）+ **N,N-二甲基羟胺**。
- 附带通道（必须实算并单独命名，不得冒充目标产物）：C2 上甲基（map 1）的 β-H 被消除 → **3-苯基-1-丁烯**（3-phenyl-1-butene）+ 二甲基羟胺。
- 反应物连接骨架沿用任务书：`CC([N+](C)(C)[O-])C(C)c1ccccc1`（该骨架本身**不含**立体声明，不能直接当作已指定的 threo/erythro 底物）。

### 1.2 模型与规模限制

| 项 | 值 | 说明 |
|---|---|---|
| 化学式（底物） | C12H19NO | 中性闭壳层 |
| 总原子数 | 33 | 14 重原子 + 19 H |
| 重原子数 | 14 | 12 C + 1 N + 1 O |
| 电荷 / 重数 | 0 / 1 | 胺氧化物为 N+–O− 内盐，净电荷 0；受限（RHF/闭壳层） |
| 相 | 气相 | 不用隐式溶剂；本题只验证本级别立体映射，不拟合溶液速率（原论文有显著溶剂效应） |
| 方法 | B3LYP-D3(BJ)/def2-SVP | ORCA 6.1.x，或 Gaussian 16（`EmpiricalDispersion=GD3BJ` + `Int(UltraFine)` + `SCF=Tight`）；ORCA 用 RIJCOSX/def2-J 辅助基组 |
| elements | `["C","H","N","O"]` | 无金属、无酸/碱助剂、无抗衡离子 |

| 一致性约束 | 同一条能垒必须同程序、同方法、同一模型 | 不得跨程序/跨相/跨模型混减 |

### 1.3 题面限制（写入 query 时应保留）

- 必须分别构造 threo 与 erythro 两种底物，并以 3D 几何 + CIP 核对后再标名；**不得**把无立体信息的骨架当作已指定底物。
- 必须以实际 3D 重新指派烯烃 E/Z；**不得**把作者 cis/trans 名称直接翻译成 E/Z。

- 若算出其他区域消除通道，保留并写明其身份，不得用它顶替指定的 2-苯基-2-丁烯。

## 2. 节点表

### 2.1 原子映射（题源 atom-map 标签，**1-based**）

所有节点字符串共用同一套 map 号，bond_changes 直接引用这套号（见 §3.4）。

| map | 元素 | 身份 |
|---|---|---|
| 1 | C | C2 上的甲基碳（β 位；其上的 H 是区域通道的离去氢来源） |
| 2 | C | 立体中心 C2（连 N5、C1、C3、H） |
| 3 | C | 立体中心 C3（连 Ph、C4、C2、H15）——主通道 β-H 所在碳 |
| 4 | C | C3 上的甲基碳 |
| 5 | N | 胺氧化物氮 N+ |
| 6 | C | N-甲基（一） |
| 7 | C | N-甲基（二） |
| 8 | O | 胺氧化物氧 O−（消除时接受 β-H，产物中成为 N–O–H 的羟基氧） |
| 9–14 | C | 苯基：9=ipso，10–13=邻/间，14=对（`[c:9]1[cH:10][cH:11][cH:12][cH:13][cH:14]1`） |
| 15 | H | **C3 上的 β-H**（主通道被转移到 O8 的质子） |

### 2.2 底物节点（R）

两个非对映体各取**一个对映体**作计算代表（另一对映体路径为镜像、能垒相同；若实际改用另一对映体，必须在 mechanism_graph 中显式换号，不得两个对映体的端点混用）。**threo / erythro 与 A / B 的对应关系必须先按原论文结构图核定**；本草案只用 A（两中心同向）与 B（反向）作为占位标签，不预设 A=threo。

**R_A（非对映体 A 的代表，同向构型）**

```
[CH2:1]([H:16])[C@@:2]([N+:5]([CH3:6])([CH3:7])[O-:8])[C@@:3]([H:15])([CH3:4])[c:9]1[cH:10][cH:11][cH:12][cH:13][cH:14]1
```

**R_B（非对映体 B 的代表，反向构型）**

```
[CH2:1]([H:16])[C@@:2]([N+:5]([CH3:6])([CH3:7])[O-:8])[C@:3]([H:15])([CH3:4])[c:9]1[cH:10][cH:11][cH:12][cH:13][cH:14]1
```

- `@`/`@@` 是**占位初值**：SMILES 的手性标记依赖串内原子书写次序，照抄会翻构型（前例：`hi.py` I1 记的 `[C@H:16]` 事件）。最终构型一律由优化后 3D 几何经 RDKit CIP 回读并记录，节点字符串只是图的载体。
- **构象身份（关键）**：R_A / R_B 必须是**可反应构象**的极小值，即 O8 与 H15 处于 syn-periplanar、且 O8···H15 与 C2···C3 的距离/角度允许闭成五元环 N5–C2–C3–H15···O8。这不是"全局最小构象"的默认结论：
  - 若 Opt+Freq 发现全局最小构象与可反应构象不同，两者**都**是极小值，必须登记为构象边（`conformational: true`、`bond_changes: []`、`weight: 0`），**不计化学步、不计步数、不冒充中间体**；
  - 化学能垒的分母始终是**可反应构象本身**，不是全局最小。
- 质子位置：两个底物节点中 H15 都明确在 C3 上、H16 在 C1 上；O8 上无质子（O− 端）。
- **实测锁定（HI1 计算线，2026-10-18；A/B 占位标签到此终结）**：两枚底物极小值已定，并由 QM 几何 + RDKit CIP 指派：
  - **A = erythro**：C2 = R、C3 = R（本例两中心"同向"）；未加 map 的 isomeric SMILES 实记为 `C[C@@H]([N+](C)(C)[O-])[C@H](C)c1ccccc1`。
  - **B = threo**：C2 = R、C3 = S（"反向"）；实记为 `C[C@@H]([N+](C)(C)[O-])[C@@H](C)c1ccccc1`。
  - 该线另用参照物（L-Thr / L-allo-Thr）验证过 threo/erythro 的 inv 二面角判据方向，并如实登记 threo 几何偏离理想 ±120°（未抹成理想值）——引用时以他们的 CIP 标签 + Fischer 构造为准，本草案不重做命名。
  - 因此 §2.2 两个映射字符串里的 `@`/`@@` 仍只是"图载体"：**入库以 mechanism_graph.json 的节点字符串 + CIP 回读为准**，本草案不另外手写第二套映射 SMILES（手写等于把"照抄翻构型"的风险再制造一次）。

### 2.3 产物节点（P）

每个主通道产物 = 两片段（烯烃 + 二甲基羟胺）同一节点。

**P_main_Zlike**（两个甲基**反式**，即 C1-甲基与 C4-甲基异侧；等价于苯基与 C1-甲基同侧）

```
[CH3:1]/[CH:2]=[C:3](/[CH3:4])[c:9]1[cH:10][cH:11][cH:12][cH:13][cH:14]1.[O:8]([H:15])[N:5]([CH3:6])[CH3:7]
```

**P_main_Elike**（两个甲基**同侧**；苯基与 C1-甲基异侧）

```
[CH3:1]/[CH:2]=[C:3](\[CH3:4])[c:9]1[cH:10][cH:11][cH:12][cH:13][cH:14]1.[O:8]([H:15])[N:5]([CH3:6])[CH3:7]
```

- 上面两个字符串里的 `/`、`\` **只表示两种几何的相对关系**（同号斜杠 = 两个甲基顺式）。它们在入库时的 E/Z 标签必须以 RDKit CIP 回读为准（`Chem.AssignStereochemistry` 后取 `GetStereo`），**不得**按书写顺序或名称臆断——现已由实测锁定为 Z / E（见下两条），但入库仍以 CIP 回读值为准。
- 每个底物的主通道**只有一个**产物节点：syn-Ei 立体专一，烯烃几何由该底物自身 TS 的 3D 唯一决定。判定规则：TS 中 O8 与被消除的 H15 必须 syn-periplanar；由此读出的 C1-甲基 / C4-甲基相对关系落到上述两个节点之一。
- **自检闸门**：两个非对映底物的主产物烯烃几何必须相反（同一 syn-Ei 规则的必然结果）。若算出同一几何，说明该底物的 TS 几何或构型指派有误，必须回查，不能直接登记。
- **闸门已通过（实测）**：erythro（A）主产物 = **Z**（TS 几何中 C1 与 Ph 同侧，dih(C1–C2–C3–C9ipso) ≈ −3.5°）⇒ 落到 `P_main_Zlike`；threo（B）主产物 = **E**（C1 与 C4 同侧、Ph 反 C1，≈ −5.5°）⇒ 落到 `P_main_Elike`。两底物几何相反，自检通过。
- 该实测同时确认了本节占位写法的语义：**同号斜杠（`/`…`/`）就是 Z**，与 `P_main_Zlike` 的字符串一致（对照的未标 map 产物串：Z = `C/C=C(/C)c1ccccc1.CN(C)O`，E = `C/C=C(\C)c1ccccc1.CN(C)O`）。
- 判据措辞固定为"**高优先基团（C1-甲基与 Ph）同侧 ⇒ Z**"；作者 cis/trans 的指代基团与实测口径无关，两者不得混用。
- 原论文 "threo→cis、erythro→trans" 的说法只作对照，**不入 gold**；且原文 cis/trans 指代的是哪两组基团（两个甲基，还是苯基/甲基）必须先按原文结构图核定。

**P_regio_A / P_regio_B**（区域通道：3-苯基-1-丁烯 + 二甲基羟胺；H16 转移到 O8，H15 仍留在 C3 上）

```
[CH2:1]=[CH:2][C@@:3]([H:15])([CH3:4])[c:9]1[cH:10][cH:11][cH:12][cH:13][cH:14]1.[O:8]([H:16])[N:5]([CH3:6])[CH3:7]
```

（B 的对应节点把 `[C@@:3]` 换成 `[C@:3]`。终端 =CH2 无 E/Z。）

- **构型"保持"但 CIP 描述符会翻转（实测，必须写进图注）**：区域通道里 C3 不参与断键，几何构型保持；但 C3 的优先序由反应物的 N-侧碳 > Ph > C4-甲基 变为产物的 Ph > C2(=CH−) > C4-甲基，**优先序互换 ⇒ 同一构型在产物里写成相反字母**。实测：erythro（C3 = R）的区域产物 C3 记为 **S**，未标 map 串 `C=C[C@H](C)c1ccccc1.CN(C)O`。
  因此 `@`/`@@` 与 R/S **不能**当作"构型是否保持"的判据；每条区域边的产物必须重新 CIP 指派，并在 graph 注里同时写"构型保持（几何）+ 描述符翻转（CIP）"。

### 2.4 中间体

**无化学中间体。** Cope 消除按单步协同 syn-Ei 登记（一条化学边：质子转移 + C–N 断裂 + C=C 形成同步）。

- 若 TS 搜索/短 IRC 显示明显**分步**行为（例如先得 O8–H15 而 C2–N5 仍存的羟胺/碳正离子对极小值），必须把该极小值作为节点、拆成两条边，每条用自身起点作分母；**不得**用分步结果冒充协同通道，也不得把分步中间体当作"必有一虚频"以外的证据。
- 分步假说在本级别气相下是否成立，正是本题要如实回答的内容之一；草案不作预判。

### 3.2 构象边（非化学步）

### 3.3 weight 的口径

`weight` 只表达**评分配分**，不是 gold 数值：主通道 1.0；区域竞争通道 0.5 并置 `competing` / `channel` 标记，表示"必须指出其存在与身份"。最终配分由正式题面与生成器决定，草案不改阈值。

### 3.4 原子序约定（强制）

1. bond_changes 中所有原子号 = 节点映射 SMILES 里的 **atom-map 标签号，1-based**；**不是** SMILES 串内书写序号，也不是 0-based 数组下标。与 `hard_registry/hi.py` I1 的 `reaction_center`（"题源 atom-map 标签序 1-based"）一致。
2. 键级变化写成 `(i,j) 旧级→新级`（本文件只出现 `1→2`）；纯断键/成键不带键级。
3. 若下游 `declare.json` / 工作序需要 0-based 或按工作几何重排的其他序，必须由**同一张映射表机械转换**，并在注释里同时写出两套号（照 `hi.py` I1 的写法：题源 1-based / 工作序 1-based / 0-based 三行都写）。
4. 任何节点字符串重排原子次序后，bond_changes 的号**不变**（号跟 atom-map 走），但 `@`/`@@` 必须重新推导。

| 产物端：2-苯基-2-丁烯、3-苯基-1-丁烯、二甲基羟胺，各自单体 | **仅作端点身份**（IRC 另一侧），不作分母 | Opt+Freq，0 虚频；片段构成与节点一致 |

**参考极小值 = 该步自身起点极小值，纯电子能相减。** 即 ΔE‡ = E(TS) − E(该 TS 对应边的起点极小值)，同程序、同方法、同一模型、不含 ZPE/热校正；产物端能量只在需要报反应能时另列，不得混入能垒。

- **同一通道可能有两套分母（实测已出现，必须在图里定死）**：主通道的 IRC 反应物端无约束优化会落到**比图里 reactant 节点更低的构象极小值**，于是同一 TS 存在"与节点绑定者"和"更低构象者"两个分母、两组 ΔE‡。处理规则：① 图里边绑的分母必须与 reactant 节点日志**同一条**；② 另一口径并列写入 REPORT 并注明是构象差所致，**不得**混称、不得挑大/挑小当 gold；③ 若把更低构象也当节点，必须补一条 `conformational: true`、`bond_changes: []`、`weight: 0` 的构象边并在图上注明它是非化学步。

### 4.3 端点与连通性验收

- TS：恰 **1 个**虚频；虚频位移的净方向必须落在 `(3,15)/(2,5)`（主通道）或 `(1,16)/(2,5)`（区域通道）上，且与 bond_changes 同向。
- 短 IRC：双向各取足够判方向的短区间（不要求跑满、不以点数代替方向判断）；两侧末帧分别做**无约束 Opt+Freq**，0 虚频。
- 端点身份用**片段判据**（元素/连接/电荷/CIP），不用能量近似；IRC 一侧若先落到氢键复合物，该复合物是独立极小值，须单独 Opt+Freq 并按需登记为节点。

## 5. 已知风险与必须核验的点

1. **构象 ≠ 化学步。** 底物的全局最小构象与可反应构象可能不同；两者的差是构象差，不许当成"中间体"或"预反应络合能"计入能垒，也不许用构象差凑选择性（`weight: 0` 的构象边，见 §3.2）。
2. **两个非对映底物不得相减。** 必须"每条能垒只用该底物自身的合格起点"。禁止用 E(产物_X) − E(产物_Y) 或跨底物的 TS 差宣称面选择性/非对映选择性——本题没有共同的"面"参考。
3. **两面/两侧选择性必须绑定 3D 关系。** Cope 消除的 syn-Ei 是立体专一的：syn 关系必须由几何（O8···H15···C3 与 C2–N5 的二面角/距离）读出，不能只靠名字或 SMILES 的 `@` 标签。
4. **名称不能直译。** threo/erythro ↔ (2R,3R)/(2S,3S)/(2R,3S)/(2S,3R) 的对应、以及原文 cis/trans 指代基团，都必须由原论文结构图 + RDKit CIP 现场核定；把"threo→cis"直接写成"threo→Z"是禁止的。
5. **区域通道身份。** 3-苯基-1-丁烯是独立通道，必须自算并标名；不得用它的能垒或产物顶替 2-苯基-2-丁烯通道。
6. **气相模型边界。** 原论文显示显著溶剂效应；本级别只验证立体映射，不用它拟合溶液速率、不与文献能垒数值比对、不把文献值当 gold。
7. **无本地已验证 Cartesian。** 原 2006 官方 SI 未声明提供笛卡尔坐标；初猜必须由工具从映射 SMILES 生成（3D 嵌入 + 构象搜索），**不得手写坐标**，也不得挪用近年不同底物的结构充作本模型原始结构。
8. **软模伪鞍点。** 五元环 TS 可能很松散（虚频绝对值偏小），且甲基转动、O–N 扭转会产生伪鞍点（前例：HL1 `-67.99 cm-1` 甲基转动被记为 pseudo-saddle）。必须做虚频位移的成分记录（反应中心对 / 重原子 / 最大单原子位移三份额），最大份额落在旁观基团时写 soft-mode-dominated 并回查。
   **但"H 份额高"本身不是伪鞍点的证据**：实测两条主通道的虚频模中 H 份额约 0.94–0.96、重原子份额约 0.03，却仍是真正的 syn-Ei 鞍点。判据是**逐键投影**（沿成/断键单位矢量的投影标度接近 1 Å，远大于噪声）与**符号是否与 bond_changes 同向**，不是份额阈值。记录必须同时给：份额 + 逐键投影（带符号）+ 投影标尺。
9. **@ 标签翻转。** 节点字符串重排或从产物反写时，`@`/`@@` 会静默翻构型（前例：I1 的 `[C@H:16]`）。每次编辑端点字符串后都要 RDKit CIP 回读。
10. **电中性与自旋。** 胺氧化物 N+–O− 是内盐，各节点净电荷必须恒为 0；记录 `<S^2>`、波函数稳定性检查；若出现明显自旋污染或双自由基特征，如实报告并说明该通道在本级别不可信，而不是换一个数凑上。
11. **闭壳层单重态前提。** 若出现低单–三态交叉或 C–N 均裂倾向，属模型适用性信息，必须写进 REPORT，不属"能垒"。

## 6. 不含 gold 声明与正式入库缺口

### 6.1 声明

**本草案不含任何 gold 数值。** 具体地：没有 barrier 数值、没有 ΔΔE‡、没有能垒排序结论、没有引用文献能垒；§3 的 `weight` 只是配分骨架，不是能量。

§2 中的立体身份（threo/erythro 与 A/B 的锁定、两个主产物的 Z/E、区域产物"构型保持但描述符翻转"）**不是本草案自产的断言**，而是转引 HI1 计算线已实测并经 CIP 回读的结论（`results/HI1/REPORT.txt`、`results/HI1/mechanism_graph.json`）；草案只吸收其**结构身份**，不复制其能量数值。本文件若与那些原生日志冲突，以原生日志为准。

§2.2 两个映射字符串里的 `@`/`@@` 仍是占位（图载体），入库以 mechanism_graph.json 的节点字符串 + CIP 回读为准。
