## 共同验收标准（三题都适用）

一份计算要能被接进 gold，必须同时满足：

1. **原生日志**：程序原生输出文件原样提供（不改写、不追加注释），附 `sha256` 与程序版本号。
2. **能量定义**：明确写 `De`（纯电子）还是 `D0`（含 ZPE），单位 kcal/mol；两个都给最好，禁止混成一个数。
3. **⟨S²⟩**：每个开壳层计算给出期望值，偏差 > 10% 要写明并说明是否做自旋投影。
4. **波函数稳定性**：`stable=opt` 或等价的稳定性分析通过；未通过要写清哪个不稳定性、换什么参考态重算。
5. **几何**：优化收敛（`Stationary point found` / 程序等价标记），并提供几何文件（xyz/mol）。
6. **方法链一致**：能量差的两端必须同一方法、同一基组、同一程序、同一相对论/溶剂设定；**禁止跨程序或跨方法相减**。

## IG8 · Cr₂ 基态解离曲线与键能

- **体系**：Cr₂，`q=0`，题面要求基态（形式六重键）。实际基态为多重度 1 附近的多参考问题，**必须让用户确认目标多重度/态**。
- **需要产出**：
  - 解离曲线：至少 12 点，r(Cr–Cr) 从 ~1.5 Å 到 ~5.0 Å（5.0 Å 处作为解离极限，或用超分子渐近法）
  - 平衡键长 r_e、振动频率（若做）
  - BDE：`De` 与 `D0` 都报
- **本地已有（仅作对照，不能当 gold）**：无。本地白名单只有 xTB/B3LYP+def2-SVP，对 Cr 这种强关联体系不可信。
- **建议方法（待用户确认）**：CASSCF(12,12) 起步 + 动态相关（CASPT2/NEVPT2 或 MRCI+Q）；基组至少 def2-TZVP，最好含相对论（DKH2/ZORA + 相应基组）。要报活性空间、态数、态平均权重。
- **验收补充**：曲线必须单调无伪极值（或说明为何有）；Cr 的 3d 占据要报告。
- **rubric 容差**：accuracy `sigma = 3.0 kcal/mol`，`max_penalty_fraction = 0.3`。

## IF3 · triangulene 基态自旋多重度与单-三重态能隙

- **体系**：triangulene，C22H12，`q=0`；题面声明 `multiplicity=3`（三重态基态）。
- **需要产出**：
  - 三重态与单重态各自优化几何，及两者能量
  - ΔE(S–T)：`De` 与 `D0` 都报（单位 kcal/mol）
  - 单重态是否为开壳层（双自由基）——报告 ⟨S²⟩ 与自然轨道占据数
- **本地已有**：无可用值。单参考 DFT 对非 Kekulé 双自由基给不出可信 gap。
- **建议方法（待用户确认）**：CASSCF(10,10) 或更大活性空间 + NEVPT2/CASPT2；基组 def2-TZVP 起。**必须做态平均并报权重**，避免只优化单态导致 S/T 不可比。
- **验收补充**：单重态必须显式给 ⟨S²⟩；若用 BS-DFT 作诊断，要标「诊断值，不作为 gold」。
- **rubric 容差**：同 IG8。

## IC3 · 苯基氮宾单-三重态能隙与最低单重态电子结构

- **体系**：phenylnitrene `[N]c1ccccc1`，`q=0`；题面声明 `multiplicity=3`。
- **需要产出**：
  - 三重态与最低单重态（开壳层）各自优化几何
  - ΔE(S–T)：`De` 与 `D0`
  - 最低单重态的电子结构证据：⟨S²⟩、自然轨道/自旋密度、是否双自由基
- **本地已有**：无可用值。这是需要 MR 的经典案例。
- **建议方法（待用户确认）**：CASSCF(8,8)（N 的 p 与苯环 π 体系）+ CASPT2/NEVPT2；基组 def2-TZVP 起；必要时加 (8,9)/(10,10) 做活性空间敏感性检查。
- **验收补充**：必须给出活性空间敏感性（至少两组空间对比），否则 ΔE 的误差无法界定。
- **rubric 容差**：同 IG8。

## 需要用户确认的三件事（不确认不能开算）

1. **目标自旋态**：IG8 的目标多重度是什么（题面只写 "ground-state"）；IF3/IC3 是否坚持题面的三重态为参照。
2. **方法方案**：活性空间大小、是否做态平均、动态相关方法（CASPT2 / NEVPT2 / MRCI+Q）、相对论处理（是否需要）。
3. **算力**：本机之外那台的核数/内存/最长墙钟，以及是否有 ORCA（版本）/其他 MR 程序。
