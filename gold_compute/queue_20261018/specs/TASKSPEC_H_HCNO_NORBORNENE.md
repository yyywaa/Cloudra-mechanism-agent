## 1. 总反应与模型

### 1.1 反应

formonitrile oxide（HCNO，fulminic acid 型 1,3-偶极）对 norbornene（降冰片烯）C=C 的两面 [3+2] 环加成，生成降冰片烷稠合的 4,5-二氢异噁唑（2-isoxazoline）：

```
H-C#N(+)-O(-)  +  C7H10(norbornene)   ->   C8H11NO (norbornane-fused 2-isoxazoline)
C8H11NO 总反应式（净加成，无副产物）
```

- 反应物连接式沿用任务书：`C#[N+][O-].C1=CC2CCC1C2`（净电荷 0、重数 1、10 重原子）。
- **两个通道 = 偶极对 C=C 的两个相对面**（对刚性桥环的 F1 / F2，见 §2.4）。不是区域通道，也不是构象通道。
- 产物端只有**一个**分子（稠合多环），无分离小分子副产物；两通道的区别只在生成的非对映体（相对桥的立体关系）。

### 1.2 模型与规模限制

| 项 | 值 | 说明 |
|---|---|---|
| 化学式 | C8H11NO | 加成物；反应物为 C7H10 + CHNO |
| 总原子数 | 21 | 10 重原子 + 11 H |
| 重原子数 | 10 | 7（norbornene）+ 3（C、N、O of HCNO） |
| 电荷 / 重数 | 0 / 1 | HCNO 为 N+–O− 内盐，净电荷 0；受限闭壳层 |
| 相 | 气相 | 不用隐式溶剂；不拟合溶液速率 |
| 方法 | B3LYP-D3(BJ)/def2-SVP | ORCA 6.1.x，或 Gaussian 16（`EmpiricalDispersion=GD3BJ` + `Int(UltraFine)` + `SCF=Tight`） |
| elements | `["C","H","N","O"]` | 无金属、无酸预活化、无柔性有机催化剂 |
| max_heavy_atoms | `10` | 刚性骨架，重原子数不大 |
| single_step | `true` | 每面**一条**化学边（协同 [3+2]）；两面是两条平行单步通道，不是多步网络 |
| 一致性约束 | 同一条能垒必须同程序、同方法、同一模型；两面比较须同一合格反应物参考 | 见 §5.2 |

### 1.3 题面限制（写入 query 时应保留）

- 必须对刚性桥环的两个相对面**分别**准备初猜，各自取得相关一虚频 TS、短 IRC 方向区间与两端极小值身份。
- 必须实际核对**新 C–C、新 C–O 键**及产物相对桥的立体关系；两面命名必须用**可复核的 3D 关系**，不能只写 syn/anti 或 endo/exo 文字。
- 两面比较必须使用**同一合格反应物参考**；若存在不同预复合物，先查明参考关系，禁止以不同络合物的任意能量差制造"优势面"。
- 不预设本项目方法下的 favored 面；不得借用苯甲腈氧化物 / 取代降冰片烯的数据冒充本题。

## 2. 节点表

### 2.1 原子映射（题源 atom-map 标签，**1-based**）

| map | 元素 | 身份 |
|---|---|---|
| 1 | C | norbornene 的 C1：C=C 的一端（保留其 H） |
| 2 | C | norbornene 的 C2：C=C 的另一端（保留其 H） |
| 3 | C | 桥头 C3（连 C2、C4、C7） |
| 4 | C | 乙撑桥 CH2（C4） |
| 5 | C | 乙撑桥 CH2（C5） |
| 6 | C | 桥头 C6（连 C5、C1、C7） |
| 7 | C | 一碳桥 CH2（C7，**面判据的参照原子**，见 §2.4） |
| 8 | C | HCNO 的碳（产物中为异噁唑啉 C3，保留其 H11） |
| 9 | N | HCNO 的氮（N+ → 产物环内 N） |
| 10 | O | HCNO 的氧（O− → 产物环内 O，并新建 O10–C2 键） |
| 11 | H | C8 上的 H（全程留在 C8，不转移） |

> 除 H11 外所有 H 隐式，不进 bond_changes。C1–C2 之间由双键变单键，**保留为环内稠合键**。

### 2.2 反应物节点

**孤立的两个单体（仅用于报告渐近线与身份核对，不作任何能垒的分母）**

```
[CH:1]1=[CH:2][CH:3]2[CH2:4][CH2:5][CH:6]1[CH2:7]2          norbornene, C7H10
[H:11][C:8]#[N+:9][O-:10]                                    formonitrile oxide (HCNO)
```

- norbornene 身份核对：桥头 = C3/C6；C1=C2 为双键；C7 为一碳桥；C4–C5 为乙撑桥（`GetSubstructMatch` 或等价检查）。
- HCNO 身份核对：**必须是 formonitrile oxide**（H 在碳上、C≡N、N–O 单键、N+–O− 内盐），**不得**在建模中滑成 HOCN / 异氰酸 / 氰酸，也不得让 H11 迁到 N 或 O。产物节点中 H11 必须仍在 C8 上。

**R_ref（反应物参考节点 = 两面共用的预复合物）**

```
[H:11][C:8]#[N+:9][O-:10].[CH:1]1=[CH:2][CH:3]2[CH2:4][CH2:5][CH:6]1[CH2:7]2
```

- 图节点字符串只是"两片段并存"的载体；**它的具体 3D 几何（偶极相对 C=C 的取向与距离）由后续 Opt+Freq 的极小值决定**，草案不预设某一取向。
- 若实际存在**两个不同的预复合物**（例如偶极朝向 C7 侧 vs 朝向 C4–C5 侧的氢键/偶极作用不同），必须：
  1. 各自 Opt+Freq（0 虚频）并分别命名 `R_F1` / `R_F2`；
  2. 把两面能垒分别相对**各自复合物**给出（"本步起点"口径），**同时**给出相对同一个 R_ref 的口径；
  3. 把复合物之间的差登记为构象/重排边（`conformational: true`、`bond_changes: []`、`weight: 0`），不得把它算成化学步或"选择性能垒"。

### 2.3 产物节点

加成物骨架：C1–C8(=N9)–O10–C2，且 C1–C2 成环稠合；即 C1、C8、N9、O10、C2 五元异噁唑啉环与降冰片烷在 C1–C2 处稠合。

**P_F1 / P_F2（两面产物，同分异构、不同非对映体）**

```
[C@H:1]12[CH:8]=[N:9][O:10][C@@H:2]2[C@H:3]3[CH2:4][CH2:5][C@H:6]1[CH2:7]3
```

- 两个产物节点**共用上面的连接式**，区别只在 C1/C2 等处的相对构型（即异噁唑啉环落在 C7 侧还是 C4–C5 侧）。字符串里的 `@`/`@@` 是**占位**：必须由优化后 3D 几何经 RDKit CIP 重写，**不得**照抄或按"对/错面"随意改符号（前例：`hi.py` I1 的 `[C@H:16]` 翻转事件）。
- 产物相对桥的立体关系必须用**可复核判据**：取 {C1, C2, C3, C6} 的平面，比较 C8（或 O10）与 C7 在该平面同侧/异侧的符号；两产物必须给出相反的符号。文字名称（exo/endo）只作注释，不作判据。
- **两个产物的身份核对**：用 RDKit canonical isomeric SMILES 比较——两产物必须**不同**；同时核对它们不是同一分子的不同构象（若相同，说明拼错环或立体标签被抹平）。

### 2.4 两面（F1 / F2）的可复核定义

不得用"exo/endo"或"syn/anti"文字直接指定面。定义与记录方式：

1. 参考平面 Π = {C1, C2, C3, C6} 的最佳平面（最小二乘）。
2. 参照原子 = **C7**；其相对 Π 的有符号位移记 `s(C7) = ±`。
3. 对每个通道，取 TS 与产物中新成键原子对 (C8, O10) 的中心点或有符号位移 `s(dipole) = ±`。
4. **面标签 = sign(s(C7) · s(dipole))**：`+` 记 F1（偶极与 C7 同侧），`-` 记 F2（与 C4–C5 乙撑桥同侧）。
5. 每份日志必须写出该符号、用到的原子号、以及测量时的几何文件路径；换程序/换几何重算后必须复现同一符号。

> F1/F2 与文献 exo/endo 名称的对应**必须**由某个参照结构（例如原文给出的构型图）核定并留痕；不得假定"F1 = exo"。

### 2.5 区域取向（regio orientation）

HCNO 是不对称偶极（C 端 / O 端），在给定面上有两种放置方式：`C8→C1, O10→C2` 或 `C8→C2, O10→C1`。

- 由于 norbornene 的 C1/C2 由分子内镜面对称相关，这两个取向的产物**未必**是独立通道：它们可能是同一分子、或互为对映体。**必须**用 RDKit canonical isomeric SMILES + CIP 现场判定，不得按名称假定只有一条或两条通道。
- 若判定为对映体：本通道在非手性试剂下给出外消旋体，登记为一个**非对映面通道**，并在 graph 中注明 `racemic: true`（对映体的能量相同，不需要重复算能垒，但需要说明为何不重复算）。
- 若判定为**不同**的非对映体：则每面各有两个通道，共 4 条边，必须全部登记。
- 本草案默认边表按"每面一条边"（§3.1），并把上述判定作为**入库前必须完成的核对项**；判定结果若要求扩边，按判定结果扩，不沿用草案的边数。

### 2.6 中间体

**无化学中间体**：1,3-偶极环加成按单步协同登记（一条化学边）。若 TS/IRC 显示明显分步（双自由基/两性离子极小值），必须拆边、如实登记，并说明该极小值的自旋与电荷状态；不得用分步结果冒充协同通道。

## 3. 边表

### 3.1 化学边

| edge id（建议） | from → to | step_type | bond_changes（form / break） | weight |
|---|---|---|---|---|
| `HM1_E1` | R_ref → P_F1 | concerted 1,3-dipolar [3+2] cycloaddition on face F1: dipolarophile C1–C2 attacked so that the dipole sits on the C7 side | form: `(1,8)` 新建 C–C；`(2,10)` 新建 C–O ／ break: `(1,2)` 键级 2→1；`(8,9)` 键级 3→2 | 0.5 |
| `HM1_E2` | R_ref → P_F2 | concerted 1,3-dipolar [3+2] cycloaddition on face F2: dipole approaches from the C4–C5 bridge side | 同 `HM1_E1` | 0.5 |

- `N9–O10` 单键全程不动（键级恒 1），不写进 bond_changes；`C8–H11` 不动。

- 虚频模的净方向必须落在 `(1,8)`/`(2,10)` 成键与 `(1,2)`/`(8,9)` 断键上且与之同向；方向相反的鞍点按 pseudo-saddle 处理，不回填。

### 3.2 构象/取向边（非化学步）

| edge id | from → to | step_type | bond_changes | weight |
|---|---|---|---|---|
| `HM1_C1` | 预复合物 A → R_ref | conformational/orientational relaxation (no bond change) | `[]` | 0 |

- 仅在确实存在多个预复合物时登记（§2.2）；`conformational: true`、`weight: 0`、不计步数、不冒充中间体、不作"面选择性"的依据。

### 3.3 原子序约定（强制）

1. bond_changes 的原子号 = 节点映射 SMILES 的 **atom-map 标签号，1-based**；不是串内书写序号，也不是 0-based 下标。与 `hard_registry/hi.py` I1 的 `reaction_center` 口径一致。
2. 键级变化写成 `(i,j) 旧级→新级`（本文件出现 `2→1` 与 `3→2` 两种）；纯成键/断键不带键级。
3. 下游若需 0-based 或工作几何重排序，必须由同一张映射表机械转换，并在注释中同时写出题源 1-based / 工作序 1-based / 0-based 三套号（照 `hi.py` I1 写法）。
4. 节点字符串重排原子次序后，原子号不变，但 `@`/`@@` 必须重新推导。

## 5. 已知风险与必须核验的点

1. **面不能靠名字。** syn/anti、endo/exo 都是文字约定；必须用 §2.4 的平面 + 有符号位移判据，写入日志与 graph。只写"从 exo 面进攻"不合规。
2. **两面比较的参考必须同一。** 若两面预复合物不同（常见），不得以"复合物 A 对复合物 B"的能量差造优势面；必须先查参考关系，再按 §4.2 的双口径报告。这条是任务书的硬性要求，也是本题最容易出错的地方。
3. **不得借用其他体系数据。** 苯甲腈氧化物、取代降冰片烯、cis-3,4-二氯环丁烯等原文/其他文献的数值与几何，只能作机理背景，不能当本题坐标、能垒或 gold。
4. **原文方法较旧。** 1993 年 Faraday Trans. 的方法与本项目 B3LYP-D3(BJ)/def2-SVP 不可比；文献能垒不引用为 gold，也不预设其 favored 面。
5. **无本地已验证 Cartesian。** 初猜必须由工具从映射 SMILES 生成（3D 嵌入 + 两面/两端取向枚举 + 预复合物优化），**不得手写坐标**。
6. **对称性产生的"伪第二通道"。** C1/C2 等价 ⇒ 两种区域取向可能是对映体而非非对映通道；用 canonical isomeric SMILES 判定后才定边数与 TS 数（§2.5）。
7. **偶极身份漂移。** HCNO 在小体系里容易被优化成 HOCN / 氰酸 / 异氰酸；每个节点和 TS 都要核对 C8–H11 仍在、C8≡N9 键级、N9–O10 单键、净电荷 0。产物里出现"O10 上带 H"即说明滑成别的物种。
8. **刚性骨架的低频模。** 产物为多环刚性分子，仍可能有骨架扭转/整体转动的低模；虚频归属必须做投影检查（排除整体转动/平动伪模），并记录三份额（反应中心对 / 重原子 / 最大单原子位移）。
9. **@ 标签翻转。** 从产物反写、或重排原子次序，会静默翻构型；每次编辑后 RDKit CIP 回读。
10. **单重态闭壳层前提。** 1,3-偶极环加成按协同闭壳层登记；若出现明显双自由基特征（`<S^2>` 升高、不稳定波函数），如实报告并说明该通道在本级别不可信，不以换数收口。
11. **找不到鞍点不等于不存在。** 只能写"在该初猜族/该扫描范围内未找到"，附搜索范围与判据；不得写成"该面不可反应"。

## 6. 不含 gold 声明与正式入库缺口

### 6.1 声明

**本草案不含任何 gold 数值，也不含任何立体化学结论。** 具体地：没有 barrier 数值、没有 ΔΔE‡、没有"哪一面占优"的判断、没有产物的 R/S 或相对构型指派、没有引用文献能垒。§3 的 weight（对称 0.5/0.5）与 §2 的节点字符串只是**结构约定**；§2.3 的 `@`/`@@` 与 §2.4 的 F1/F2 名称都是占位与定义，最终必须由原生日志 + RDKit CIP 回读确认。

### 6.2 正式入库还缺什么

| 缺口 | 补齐方式 |
|---|---|
| 原生日志（输入、几何、能量、频率、程序版本） | 远端按 §1.2 跑 R_ref（+必要时的 R_F1/R_F2）Opt+Freq、每面 TS、双向短 IRC、两端 Opt+Freq；留档到 `results/H_HCNO_NORBORNENE/` |
| 两面 3D 判据的实测记录 | 每面 TS/产物给出 `s(C7)·s(dipole)` 符号 + 原子号 + 几何文件路径（§2.4） |
| 相关一虚频与归属 | 位移净方向与 bond_changes 同向；低频模投影检查（§5.8） |
| 双向 IRC 方向区间 + 端点 Opt/Freq | 两侧短 IRC；末帧无约束 Opt+Freq（0 虚频）+ 片段/构型身份 |
| 参考关系说明 | 是否只有一个预复合物；若有多个，给出各自能量与相对同一参考的双口径（§4.2） |
| 区域取向判定 | RDKit canonical isomeric SMILES 判定两取向是对映体还是非对映体，据此定边数与 TS 数（§2.5） |
| 产物 CIP / 相对桥关系 | 优化后 3D 回读，替代字符串占位；文字名称只作注释 |
| mechanism_graph.json | 按 §2/§3 落图（节点、bond_changes 1-based、channel、competing、racemic、conformational、对称 weight），写入 `results/H_HCNO_NORBORNENE/` |
| 题面与生成器 | 新题身份建议 `HM1`（M 族在现有 hard registry 文件划分中未占用），不沿用 HL1 的 ID、不搬旧值；旧 HL1 归档 |
| 可算性判定 | 须有两面各自的"一虚频 + 双向方向 + 两端 0 虚频"才允许下结论；单面证据不足以判定"可算/不可算" |

> 明确：本草案不承诺本题一定能闭合。若某面在合理初猜族内拿不到合格鞍点，按既有纪律如实记录失败（搜索范围 + 判据），不填数、不以扫描峰或正常退出代替验收。
