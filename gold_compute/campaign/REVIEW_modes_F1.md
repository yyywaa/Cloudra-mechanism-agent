# 独立审稿报告 — TS 虚模归属核查（GROUP F1）

审稿人：small_mol (a-4)，独立于产出者（只读核查）。
日期：2026-09-18
范围（本组）：**F1, HA1, NU6**；另按要求重点复核 **HL1_E2 / NA5_E2 / NA5_E3 / NA5_E4 / HG2_E1 / HG2_EM1**，并顺带排查 HL1_E1 / HL1_E5。
问题：每条边的 TS 唯一虚频，是否确实落在该步声明的成/断键**重原子**上（而非旁观水/离子的软模或孤立质子模）。

## 方法（可复现）
1. 逐边从 `gold_compute/edge_barriers/computed/<TASK>.json` 取 `ts_log` 与该步描述。
2. 只认 ORCA 日志中**最后一个** `VIBRATIONAL FREQUENCIES` 块（OptTS 作业另有一个初始 Hessian 块，已排除；本报告写出的虚频均取末块，并与 JSON 记录值逐一吻合）。
3. 取该块后 `NORMAL MODES` 矩阵的**第 6 号模态列**（前 6 列为平动/转动，全零）。ORCA 打印的是 d/√m（按 1/√m 加权），故真实笛卡尔振幅 = 打印值 × √m；本报告按真实振幅计算参与度。
4. 归属判据：(a) 重原子参与占比；(b) 关键成/断键对的位移投影 frac = (v_b − v_a)·(a→b 单位向量) / |v_b − v_a|（|frac|→1 表示该键沿自身轴伸缩，即该键就是反应坐标）。
5. 几何统一取**末次 freq 之前最后一个** CARTESIAN COORDINATES 块（= 收敛 TS），以避免输入猜测量误导。

工程说明（偏差记录）：F1/HA1/NU6 之外的大日志（HL1/NA5/HG2，10–24 MB）超过 `read` 的 2 MiB 上限，改用 `sed -n 'a,bp'` 机械抽取行区间后在程序内做数值解析（`log_parser` 不提供 normal-mode 位移）。未修改任何既有产物。

## 总体判定
- 本组 **F1、HA1(E1/EM1)、NU6(E1/E2)** 共 5 条边的 TS 虚模**全部落在声明的重原子反应坐标**上，置信度均为高；**未发现软旁观模冒充 TS**。
- 重点复核的 6 条边（HL1_E2、NA5_E2/E3/E4、HG2_E1/EM1）**虚模归属全部正确**；其中 NA5_E2/E3、HL1_E2 因涉及质子/氢迁移而 H 占比高，但已用"质子桥 + 双端投影"证明确为反应坐标，非旁观软模。
- 唯一真正被判定为"软旁观模"的是 **HL1_E5（-653.06）**（水 H 主导，重原子 10.6%），与既有 JSON 的 null 判定一致；**HL1_E1（-1791.63）** 是真实但**不属于该步**的 O→N 质子转移模。
