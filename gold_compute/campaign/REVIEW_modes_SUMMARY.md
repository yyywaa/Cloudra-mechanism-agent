# TS 虚模身份独立复核 — 汇总（4 组审稿）

更新：2026-09-18（Coordinator 汇总）。审稿人均为**独立新会话** small_mol(a-4)，只读，未改任何 computed/*.json、未跑 QM。

## 方法（口径已统一）
- 只认 ORCA **最后一个** VIBRATIONAL 块（初始/工作 Hessian 块含 1–8 个虚频，一律不计）；每条边末块 **n_imag=1**。
- 位移取末块 NORMAL MODES 的笛卡尔分量；**约定已标定**：用 NY3_E2 的 O–H 伸缩(3690.75 cm⁻¹)测得 H:O 振幅比=16.4≈m_O/m_H(15.87)，证明 ORCA 打印的是**真实物理位移**（非质量加权本征矢）。
- 判据 = **动能参与度 m·x²/Σm·x²** + 键轴投影；判定"虚模主导原子是否落在该步声明的成/断键重原子"。

## 结果：全部有值 TS 通过（无软旁观模冒充）
| 组 | 边 | 结果 |
|---|---|---|
| F1/HA1/NU6 | F1_E1, HA1_E1/EM1, NU6_E1/E2 | 5/5 符合，高 |
| NU3/NY3/NU5 | NU3_E1/E2a/E2b, NY3_E2, NU5_E2/E4 | 6/6 符合（NU3_E2a 中） |
| HA6/HG2 | HA6_E1/EM1, HG2_E1/EM1 | 4/4 符合，高 |

**要点**
- 重原子主导、无歧义：HA6 两条(C2–C5 各≈.8)、HG2 两条(C2/C4/O5/C7)、NU5_E2(C1–C12)、NU5_E4(Mumm)、NA5_E4(C1–C10,投 .999)、HL1_E2(N5/C3/C2 71%)。
- 质子转移步（虚模本就应质子主导）：NA5_E2(H2 43%)、NA5_E3(H14 84%，真反应质子，非旁观)、NU3_E2a(H7 88%)。
- **HL1_E2 的旁观水比例分歧已解决**：用物理位移×√m 的 3 组一致得**水仅 ~9–10%（次要）**；另 1 组的"≈1/3"是归一化口径差异造成的假象。结论：HL1_E2 是**有效 Beckmann 坐标**，水污染次要。
- **非有值/已拒**：HL1_E5 −653.06（H₃O⁺ 旁观软模，H 占 89%）、NA5_E5 −56.48（旁观水软模）、HL1_E1/job531 −1791.63（真 O→N 肟互变异构 PT，但非声明步）——与 JSON 的 null/unresolved 判定一致。

## 需保留的 caveat
1. **NU3_E2a**（−1021.55）：88% 动能在单质子；声明的 P–O 成环重原子分量**未进入虚模**（IRC 仍连通 adduct↔oxaphosphatane）→ 中置信；若要"协同成环"证据需额外验证。
2. **HL1_E2**（−304.17）：模式身份成立，但 IRC **反端未回 I1**（回一相关极小值）→ 连通性 caveat 保留。
3. **NY3_E2**（−159.06）：软频率，但 ~50% 动能在声明的 O2/O5/C3 → 中高。
4. NA5_E4（−363.63）：**模式身份符合**，但 IRC 两端回 I3 → 连通性未证（非生产性 TS），二者需分开评。
