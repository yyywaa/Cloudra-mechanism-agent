## 结论

**这个候选的唯一虚频和局部 IRC 几何变化支持甲酸根捕获腈鎓的 C–O 成键方向。完整科学验收未通过，不能回填 Gold 能垒。**

未通过的原因是：反应物侧端点优化没有收敛，且几何滑向甲酸根另一只氧成键的产物样结构；产物侧独立 Opt/Freq 尚未计算，两侧经极小值验证的方向区间证明仍缺失。不是仅凭 IRC 达到原生上限就拒收，也不是因为虚频不对应反应。

本次验证只读取已完成产物，导出振动动画并计算几何量，没有启动新 QM、提高迭代上限或重交失败作业。

## 1 原子与来源

反应：`C[N+]#CCO.O=C[O-] → CN=C(CO)OC=O`，15 原子，q0/m1，CPCM(DCM)。方法保持 B3LYP-D3BJ/def2-SVP、RIJCOSX、def2/J、TightSCF。

以下编号均为反应物/本地 QM XYZ 的 **1-based 原子序**，不是 ORCA 输入的 0-based 编号：

- C3：腈鎓捕获碳；N2：相邻氮。
- O14：当前声明与候选中甲酸根进攻氧；O12：甲酸根另一只氧；C13：甲酸根碳。
- O5—H11：原醇羟基，用于核对是否发生质子转移。

产物源文件按声明中“产物索引 → 反应物索引”的完整映射重排后比较，未凭元素序猜对应关系。

原始计算：本地作业 1 OptTS、2 Freq、3 IRC、4 第一侧端点 Opt。原反应物参考来自历史作业 93。已有 101 扫描只提供初猜几何，不将其低级别能量用于正式能垒。

## 2 虚频不是仅数了一下

最终 `frequency.hess` 给出 45 个模式，只有 mode 6 为负：**−159.011817 cm⁻¹**。使用安装中的 `orca_pltvib` 导出 mode 6 的原生 20 帧动画，并读取同一 Hessian 的正规模式矩阵。

- 所有原子对的距离导数中，**C3—O14 的绝对值最大**。
- 原生动画中，C3—O14 在 **1.747–2.945 Å** 范围变化；另一只氧 C3—O12 仅在 **2.699–2.748 Å** 范围变化。
- 动画中原 O5—H11 键仍为 **0.976–1.028 Å**。结合实际 IRC，它支持 C–O 捕获相关位移，不能将此模式主要解释为完整质子转移。
- 动画振幅是可视化诊断，不是能量扫描或真实 IRC。正规模式正负号任意。
- Hessian 和频率输入的几何仅有刚性平移；去平移后最大坐标差 **1.56×10⁻⁸ Å**，两两距离最大差 **2.87×10⁻⁸ Å**。模式与当前 TS 几何相符。

单一虚频还需检查位移方向，符合 [ORCA 官方 TS 搜索说明](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/optimizations_TS.html)；这里的判断依据是实际 Hessian 和逐帧坐标。

- Forward 有 14 帧，目标 C–O 拉远，N–C 回到腈鎓三键附近；原生标记 IRC 收敛。连接关系识别为 `C[N+]#CCO.O=C[O-]`，现有严格反应物身份检查通过。

- Backward 达到原生迭代上限而未完全收敛。这提供局部方向证据，不能当作已经得到极小值；也不能仅凭达到上限认定方向错误。
- 两向 O5—H11 都保留，进一步支持本候选的捕获相关性。

## 4 第一侧端点为何不能收

端点 Opt 从 Forward 末帧开始。原生默认 50 个循环后，日志明确警告几何优化未收敛。末次收敛表五项均为 NO：

| 指标 | 实际 | 原生阈值 |
| --- | ---: | ---: |
| 能量变化 / Eh | −0.0000667896 | 0.0000050000 |
| RMS 梯度 / Eh·Bohr⁻¹ | 0.0004956601 | 0.0001000000 |
| 最大梯度 / Eh·Bohr⁻¹ | 0.0018123123 | 0.0003000000 |
| RMS 步长 / Bohr | 0.0195283366 | 0.0020000000 |
| 最大步长 / Bohr | 0.0489549158 | 0.0040000000 |

优化过程中发生的变化：

- C3—O14 从 **2.7136 → 2.9499 Å**。
- C3—O12 从 **2.7108 → 1.4147 Å**，另一只甲酸根氧靠近并形成产物样连接。
- N2—C3 从 **1.1507 → 1.2595 Å**。

RDKit 对末帧识别出与加成产物相同的未标记连接式，但这只是几何感知；现有严格反应物身份门禁报 **3–12 近片间接触，连接关系无法确证**。因此不能把末帧标成反应物极小值，更不能跳过频率检查。

“优化滑向另一氧成键”不证明整体反应无垒，也不证明 TS 无效。它说明这个 Forward 接触构型尚未给出可接受的反应物侧极小值关联。
