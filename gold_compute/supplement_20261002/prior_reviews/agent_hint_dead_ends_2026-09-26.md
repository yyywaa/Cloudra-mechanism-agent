# Gold agent 需要人工科学提示的案例复盘

记录日期：2026-09-26。范围：本轮八个 normal gold agent 中，用户在对话里明确指出的问题，以及随后可核对的计算或审计结果。这里的“死胡同”指 agent 在提示前持续沿用、但无法给出合格机理证据的搜索方向；不等于证明该方向在所有方法下都不可能。远端状态以本日核查时的记录为准，运行中作业的结论会变化。

## 结论

最明显的四类漏检是：**把机理图当成待执行清单而非待验证假设**；**没有先构造关键环状氢键/离子配位构象**；**扫描只盯指定坐标，没有逐帧核对实际反应**；**遇到可能的双自由基/多参考区域仍继续用常规单参考 DFT 扫描**。频率、IRC 等事后闸门挡住了一些错误数值，却没有及时阻止错误路线消耗新的计算。用户在 NI1、NU5、NY3、NU8 上提供的提示，改变的是搜索假设，而不是普通参数微调。

## 用户提出的跨题规则

1. **扫描先用较便宜的半经验方法找路径，再对候选点做约定 DFT 验证。** 用户原话：“我建议它们在扫描时不要用dft，多用半经验方法。” 这纠正了把大量 DFT 扫描当探索工具的成本问题，但半经验扫描本身不是 gold 证据。远端没有独立安装的 xTB/CREST；某些 ORCA xTB＋溶剂组合不可用，因此每题仍须先检查可执行的方法，不能在报告中假称已用半经验筛过。
2. **RC 失败时可讨论多分子起点，但必须先证明结合弱。** 用户原话：“RC做不出来的话可以改机理图为多分子，但前提是结合能比较小。” 需要同一方法和溶剂口径下的分离片段、候选复合物能量及搜索记录；“结合能比较小”的阈值用户未给出，不能由 agent 自定。NU5 已找到 0 虚频 RC，不能借此规则改成分离反应物参照态。
3. **不要把科学诊断字段塞进题面。** 用户追问“题面怎么会有这种字段？？”指出了把求解者应自行识别的多参考/不可算性质直接暴露给题目的风险。NU8 转入 IMP 后，应保留诚实的不可达标注和评分语义，同时检查面向答题 agent 的文字是否泄露诊断结论。
4. **IMP 不再配 S 对照题。** 用户明确取消全部 IMP 对照题，理由是这些对照题也未必可算。这是题库设计裁决，与 NU8 第二阶段的 TS 是否存在是两件事。

## 其他四个 agent 的边界

- **NR4（Wolff 重排）**：氢迁移步有经验证的 4.34 kcal/mol 能垒；脱氮步扫描显示上坡、未见可用 TS，因此保留 `null`。这是一条已明确报告的异常，不能把 `null` 当成计算遗漏自动重试。
- **NR1（pinacol 重排）**：目标重排步经 TS、频率、IRC 得到 20.21 kcal/mol，但计算显示可稳定的碳正离子/离子对中间体，机理是分步的；E1/E3 本轮未重新计算。需避免把单个 E2 的成功包装成全图已回填。
- **NQ1（Claisen）与 NQ5（oxy-Cope/互变）**：本轮报告已完成相应目标步骤，没有记录到上述类型的用户科学提示或当前搜索死胡同。不应为了“八题齐整”虚构故障。

## 人工提示暴露出的系统缺口

1. **起算前的机理审查不足。** 反应物、溶剂/水、可能的接力参与者、预期成断键与题图拆边，需要作为假设核对；NI1 和 NU5 都是在多次失败后才改假设。
2. **初猜没有证明包含欲找的局部结构。** 对环状 TS，应在提交 OptTS 前实际核对环闭合、氢键距离和拟断/成键，而不是只写“考虑六元环”。NY3 的审计明确表明旧种子从未预组织关键环。
3. **扫描结果缺少逐帧化学核验。** 报告应列出指定坐标之外发生变化的键和氢迁移，并区分受限扫描点、自由优化极小值、TS、IRC 端点。NY3 的 E3 和 NU8 的“丙烯样”末帧都暴露了此缺口。
4. **方法适用性与止损审查太晚。** 连续无合格 TS、路径转入不同键连或出现双自由基疑虑时，应先重新审查电子结构方法和题目归档，而不是继续相同方法的扫描。NU8 是最明显的成本案例。
5. **运行状态与科学完成被混淆。** Agent 标记完成并不表示后台 QM 作业及证据链完成；NI1、NU5 在本次核查时仍各有 IRC 作业运行。报告应按“端点、TS、频率、IRC、图更新”逐项判定，而非按 agent 终态。
6. **解释未给用户足够上下文。** 用户连续追问“这是不是分步”“图里到底是什么反应”“扫描在扫什么”，说明先前汇报没有先说明反应物、目标成断键、受限坐标及为何采用该方法。NU8 的丙烯判断尤其是证据越界；这既是 agent 产物问题，也是对用户汇报的审查失误。

## 2026-09-27 跟进：NI1 半经验三维扫描

用户进一步要求以半经验方法联合扫描 C–N 成键和两段水接力质子转移，寻找三者同一步发生的第一步协同垒。远端默认 ORCA 5.0.2 缺少 xTB 执行组件，且 xTB 不支持 CPCM；agent 经隔离的临时节点配置，成功用 ORCA 6.1.0 的 GFN2-xTB/ALPB(water) 跑通小测试（作业 492），每次提交后恢复原节点注册表。

作业 493 完成 **3×3×3＝27 点**的三维受限松弛扫描，分别改变水 O–H(来自胺)、水 H–羰基 O、C–N 距离。报告称所有网格点保持六元环；两段质子转移的协同区域比单独转移角点更有利，而 C–N 成键先于质子接力的网格点能量更低。最有希望的候选帧再用原定 DFT/CPCM(水) 无约束 TS 优化（作业 495），得到的 1 虚频仅 **−131.29 cm⁻¹**，接力相关振动占比 **0.52%**，属于水松动伪鞍点；没有得到独立的“C–N 成键＋双质子接力”协同 TS。此前作业 476 所验证的“先 C–N 成键，后双质子接力”路径仍是现有证据支持的结果。

**限定：**27 点粗网格和一次 DFT 候选优化只能说明本次搜索未找到三者同一步的鞍点，不能证明任何构象下都不存在。半经验扫描能量不是 gold 能垒。远端 `NI1/REPORT.md` 已记录输入、日志和该结论；本次定时跟进已停用。
