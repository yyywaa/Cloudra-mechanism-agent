## 三、使用步骤

### 步骤 1：核对信息
打开 `01_软件著作权登记申请表_填写信息.md`，核对著作权人、申请人、联系方式等信息是否完整无误。

### 步骤 2：在线填报
1. 访问中国版权保护中心官网：https://www.ccopyright.com.cn
2. 完成账号注册和实名认证
3. 选择“计算机软件著作权登记申请”
4. 按 `01_软件著作权登记申请表_填写信息.md` 中的内容逐项填写
5. 提交后打印带条形码的申请表

### 步骤 3：打印材料
- 申请表（在线打印，带条形码）
- `06_LaTeX排版/01_源程序_前30页.pdf`（A4 单面打印，第 1-30 页）
- `06_LaTeX排版/02_源程序_后30页.pdf`（A4 单面打印，第 1611-1640 页）
- `06_LaTeX排版/03_使用说明书.pdf`（A4 单面打印，共 7 页）
- `06_LaTeX排版/05_合作开发协议.pdf`（全体著作权人签字）
- 各著作权人身份证明文件复印件

### 步骤 4：签字盖章
- 个人申请：全体著作权人在申请表与《合作开发协议》上签字
- 企业申请：在申请表第 2 页加盖公章

### 步骤 5：装订递交
按 `05_申请材料检查清单.md` 逐项检查后，左侧装订，邮寄或现场递交。
