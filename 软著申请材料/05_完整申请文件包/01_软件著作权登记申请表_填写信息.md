## 二、软件用途与技术特点

### 2.1 软件用途（300字以内）

本软件是一款面向有机小分子反应机理研究的自主计算Agent系统。以事件驱动运行时协调总控Agent与领域子Agent，从反应物出发自主提出机理假设，并自动完成原子映射、构象采样、过渡态搜索、虚频确认、IRC路径连通与热化学等计算环节；以机理图承载物种状态与转化关系，配套几何与电子结构感知工具、计算任务调度、危险操作审批及过程材料留存，支撑均相有机机理解析。

### 2.2 技术特点（300字以内）

1. 事件驱动运行时内核：事件日志、事件总线与命令总线分离，先事件后状态，多 Agent 真并发、可取消、崩溃自动重试。
2. 固定轮次推理管道：权限、DAG、目标三阶段可插拔策略，LLM 输出 token 级流式推送，推理过程持久化。
3. 多 Agent 协作：Coordinator 调度领域子 Agent，支持蜂群批量调度、AgentHub 论坛与统一信箱。
4. 机理证据图编排：机理草稿、阶段契约、调用复核收件箱与交付覆盖率审计，支撑有机小分子机理自主计算闭环。
5. 几何与电子感知与安全体系：结构化工具感知分子结构、禁止手写坐标；五级权限模型、人工审批流、YOLO 自动审批守卫及坐标/命令习惯/委派专项守卫。
6. 持久化：SQLite 事件日志增量重放，不可变产物快照与 SHA-256 备份校验。
