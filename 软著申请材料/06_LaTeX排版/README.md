# Cloudra 软著申请材料 LaTeX 排版（打印递交版）

本目录是软著申请的**最终打印递交版本**，全部由 tectonic（XeTeX 引擎）+ ctex 宏包编译，A4 排版、页眉含软件名称/版本/页码。

## 文件清单

| 文件 | 内容 | 页数 |
|------|------|------|
| `01_源程序_前30页.pdf` | 源程序第 1-30 页（每页 52 行带行号） | 30 |
| `02_源程序_后30页.pdf` | 源程序第 1611-1640 页（真实代码尾部） | 30 |
| `03_使用说明书.pdf` | 软件使用说明书（含目录） | 7 |
| `04_申请表填写信息.pdf` | 申请表信息汇总（多人著作权人） | 5 |
| `05_合作开发协议.pdf` | 合作开发协议（全体著作权人签字用） | 2 |

## 编译方法

```bash
# tectonic 安装在 conda 环境（一次性配置）：
conda create -y -n tectonic -c conda-forge tectonic

# 重新编译全部：
for f in 0*.tex; do ~/anaconda3/envs/tectonic/bin/tectonic "$f"; done
```

- `01/02` 源程序 tex 由 `scripts/gen_copyright_source.py` 自动生成（从 `cloudra/` 代码重建），改代码后重跑脚本即可。
- `03/04/05` 为手写文档；内容变更时手动编辑对应 `.tex` 后重编。
- 中文字体使用系统文泉驿正黑（WenQuanYi Zen Hei），等宽字体使用 DejaVu Sans Mono。
