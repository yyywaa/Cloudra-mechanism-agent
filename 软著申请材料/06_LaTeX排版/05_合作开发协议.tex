\section*{第一条\quad 协议目的}
甲方、乙方、丙方（及丁方）基于平等自愿、诚实信用原则，就共同开发“Cloudra自主有机小分子机理计算Agent软件”（以下简称“本软件”）事宜达成一致，签订本协议，明确各方权利与义务，并作为向中国版权保护中心申请计算机软件著作权登记的依据。

\section*{第二条\quad 软件开发概况}
\begin{itemize}[itemsep=4pt]
  \item 软件全称：Cloudra自主有机小分子机理计算Agent软件
  \item 软件简称：Cloudra
  \item 版本号：0.1.0rc1
  \item 开发完成日期：2026年9月23日
\end{itemize}

\section*{第三条\quad 各方职责分工}
\begin{itemize}[itemsep=4pt]
  \item 甲方（杨程驿）：负责软件总体设计、核心代码编写与系统集成；
  \item 乙方（陈雨舟）：负责软件功能测试、缺陷验证与反馈；
  \item 丙方（曹熙蕊）：负责软件使用说明书编写与文档整理；
  \item 丁方（曾如晗）：负责科研方法技能包（skill）写作与产品资料整理。
\end{itemize}

\section*{第四条\quad 权利归属}
\begin{enumerate}[itemsep=4pt]
  \item 本软件的著作权由全体协议方\textbf{共同享有}，各方均为著作权人。
  \item 软件著作权登记证书上记载的著作权人为全体协议方；著作权人顺序为：杨程驿、陈雨舟、曹熙蕊、曾如晗。
  \item 任何一方不得未经其他各方书面同意，单独转让、许可或处分其在本软件中的权利份额。
  \item 本软件用于科研、竞赛（大学生创新创业训练计划等）及学术用途时，各方均有权使用，无需另行付费。
  \item 软件对外开源、商业化或作其他重大处分，须经全体协议方协商一致。
\end{enumerate}

\section*{第五条\quad 保密条款}
各方对开发过程中接触到的技术资料与个人信息负有保密义务；法律法规要求披露或经全体协议方同意的除外。

\section*{第六条\quad 争议解决}
本协议履行中发生的争议，各方应友好协商解决；协商不成的，任何一方可向有管辖权的人民法院提起诉讼。

\section*{第七条\quad 其他}
\begin{enumerate}[itemsep=4pt]
  \item 本协议一式肆份，各方各执一份，具有同等法律效力。
  \item 本协议自全体协议方签字之日起生效。
  \item 本协议未尽事宜，由各方协商后签订补充协议，补充协议与本协议具有同等效力。
\end{enumerate}
