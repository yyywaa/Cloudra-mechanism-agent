这是**模型选择问题，不是机理不可能**。

## 1. 体系
- 反应：**DMDO + 乙烯 → 丙酮 + 环氧乙烷**（协同单步氧转移，spiro TS）
- SMILES：`CC1(C)OO1.C=C >> CC(C)=O.C1CO1`
- **charge 0 / multiplicity 1**；**7 个重原子**（DMDO 的 C3O2 + 乙烯 C2），共 **17 原子**；无离子、无质子转移预平衡。

## 2. 映射（bond_changes 的 1-based 口径，与 O2 种子的原子序一致）
`mapped_reactants = "[CH3:1][C:2]1([CH3:3])[O:4][O:5]1.[CH2:6]=[CH2:7]"`
| 映射号 | 原子 | 角色 |
| --- | --- | --- |
| 1 | DMDO 甲基 C | 旁观，随后成丙酮甲基 |
| 2 | DMDO 环碳（缩酮碳） | 成丙酮羰基碳；C2–O4 断、C2=O5 成 |
| 3 | DMDO 另一个甲基 C | 旁观，随后成丙酮甲基 |
| 4 | **转移氧（过氧端 O）** | **成 O4–C6、O4–C7**；断 O4–O5 |
| 5 | 留在丙酮上的氧 | **成 C2=O5** |
| 6 | 乙烯 C | 成 O4–C6；C6=C7 → 单键 |
| 7 | 乙烯 C | 成 O4–C7；C6=C7 → 单键 |

| 边 | 起点 → 终点 | 键变化（映射号，**预期值；实际以生成器差集为准**） | 类型 |

节点：
- **RC**：`CC1(C)OO1.C=C`（dot-joined 单 complex；**受约束复合物**，O4–C1 冻结 2.800 Å，见 §5）
- **P**：`CC(C)=O.C1CO1`

> **订正（主协调 14:2x）**：氧转移后 O4 要脱离环去桥联 C6/C7，**C2–O4 必须断**，本行先前漏写；`bond_changes` **由生成器从相邻步映射 SMILES 差集自动推导、不手填**，上表只作预期——若生成器输出里没有 [2,4] 断裂，说明 out SMILES 写错（很可能 O4 仍挂在 C2 上）。
> **模数**：17 原子 ⇒ **3N−6 = 45 模（15 组 `Frequencies --`）**，O2 的频率断言用 **45**（不是候选 1 的 39）。
